**C02 Q08 R03 まとめて点検する**

学ぶこと: 条件（もし〜なら）、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

```blocks
player.onChat("q08r03", function () {
    let repaired = 0
    let found1 = blocks.testForBlock(GLOWSTONE, pos(-4, 2, 12))
    if (!found1) {
        blocks.place(GLOWSTONE, pos(-4, 2, 12))
        repaired += 1
    }
    let found2 = blocks.testForBlock(GLOWSTONE, pos(0, 2, 12))
    if (!found2) {
        blocks.place(GLOWSTONE, pos(0, 2, 12))
        repaired += 1
    }
    let found3 = blocks.testForBlock(GLOWSTONE, pos(4, 2, 12))
    if (!found3) {
        blocks.place(GLOWSTONE, pos(4, 2, 12))
        repaired += 1
    }
    player.say("直した数: " + repaired)
})
```
