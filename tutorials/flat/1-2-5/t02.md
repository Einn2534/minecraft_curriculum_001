## T002 Agentを動かしてみよう！

**T002 Agentを動かしてみよう！**

「開始位置へ」を押したら、新しいプロジェクトで作ろう。いまは歩いたりジャンプしたりできないよ。Agentがゴールすると、また歩けるよ。

1. 「チャットコマンド agent を入力した時」（プレイヤー）を置こう。

2. チャットコマンド「agent」の中に、「エージェントを ~0 ~0 ~0 へ 東 (Xのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

3. チャットコマンド「agent」の中に、「エージェントを 前 に 3 ブロック移動させる」（エージェント）をつなごう。

4. チャットコマンド「agent」の中に、「エージェントの向きを 左 に変える」（エージェント）をつなごう。

5. チャットコマンド「agent」の中に、「エージェントを 前 に 2 ブロック移動させる」（エージェント）をつなごう。

向きの「左」は、ひだりまわりのことだよ。緑の実行ボタンを押し、Tキーのチャットで agent と入力しよう。金の床に着くと「T002 クリア！」が出るよ。

次は工房NPCの「次のステージ」でQ01のR01をはじめよう。Cキーで今のRだけの作り方を見よう。

ヒントは電球を押してみよう。

```blocks
player.onChat("agent", function () {
    agent.teleport(pos(0, 0, 0), EAST)
    agent.move(FORWARD, 3)
    agent.turn(LEFT_TURN)
    agent.move(FORWARD, 2)
})
```
