## C06 Q28 R02 矢のイベント

**C06 Q28 R02 矢のイベント**

矢を放ったときに、的のまんなかを金に変えよう。

完成するもの: 弓を使うと反応する3つの的

学ぶこと: 矢を放ったときのイベント、順番に動かす、変数（値を覚える箱）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に eventOrigin と入力して「OK」を押すと、eventOrigin のブロックが出るよ。

3. 「変数eventOriginを「プレイヤーの位置」（プレイヤー）にする」（変数）をつなごう。

4. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に eventReady と入力して「OK」を押すと、eventReady のブロックが出るよ。

5. 「変数eventReadyを偽にする」（変数）をつなごう。

6. 「チャットコマンド q28r02 を入力した時」（プレイヤー）を置こう。

7. チャットコマンド「q28r02」の中に、「変数eventOriginを「プレイヤーの位置」（プレイヤー）にする」（変数）をつなごう。

8. チャットコマンド「q28r02」の中に、「変数eventReadyを真にする」（変数）をつなごう。

9. 「プレイヤーが矢を放った時」（プレイヤー）を、チャットコマンドの外に置こう。

10. イベントの中に、「もし eventReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

11. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に eventPoint1 と入力して「OK」を押すと、eventPoint1 のブロックが出るよ。

12. 条件の「なら」の中に、「変数eventPoint1を「eventOrigin + ~0 ~2 ~13」（ポジション）にする」（変数）をつなごう。

13. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に eventPoint2 と入力して「OK」を押すと、eventPoint2 のブロックが出るよ。

14. 条件の「なら」の中に、「変数eventPoint2を「eventOrigin + ~0 ~2 ~13」（ポジション）にする」（変数）をつなごう。

15. 条件の「なら」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

16. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は eventPoint1、「範囲の終わり」は eventPoint2 にするよ。

17. 緑の実行ボタンを押して、Tキーのチャットで q28r02 と入力しよう。

18. 入口の金の床から、用意した弓で矢を放とう。矢を放ったイベントで的の色が変わるよ。

19. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q28r02", function () {
    eventOrigin = player.position()
    eventReady = true
})
player.onArrowShot(function () {
    if (eventReady) {
        let eventPoint1 = positions.add(eventOrigin, pos(0, 2, 13))
        let eventPoint2 = positions.add(eventOrigin, pos(0, 2, 13))
        blocks.fill(GOLD_BLOCK, eventPoint1, eventPoint2, FillOperation.Replace)
    }
})

```
