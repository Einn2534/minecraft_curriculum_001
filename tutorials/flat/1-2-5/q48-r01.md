## C10 Q48 R01 2つから選ぶ

**C10 Q48 R01 2つから選ぶ**

くじで花を選び、2か所に植えよう。

完成するもの: 種類をくじ引きで選ぶ花壇

学ぶこと: 乱数（くじ引き）、順番に動かす、変数（値を覚える箱）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q48r01 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に flowers と入力して「OK」を押すと、flowers のブロックが出るよ。

4. チャットコマンド「q48r01」の中に、「変数flowersを「配列を作成」に ポピー、タンポポ を順に入れるにする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に choice1 と入力して「OK」を押すと、choice1 のブロックが出るよ。

6. チャットコマンド「q48r01」の中に、「変数choice1を「ランダムな数字を選択: 0 から 1 まで」（計算）にする」（変数）をつなごう。

7. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に flower1 と入力して「OK」を押すと、flower1 のブロックが出るよ。

8. チャットコマンド「q48r01」の中に、「変数flower1を「flowersのchoice1番目の値」にする」（変数）をつなごう。

9. チャットコマンド「q48r01」の中に、「flower1 を~-4 ~0 ~13 に置く」（ブロック）をつなごう。

10. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に choice2 と入力して「OK」を押すと、choice2 のブロックが出るよ。

11. チャットコマンド「q48r01」の中に、「変数choice2を「ランダムな数字を選択: 0 から 1 まで」（計算）にする」（変数）をつなごう。

12. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に flower2 と入力して「OK」を押すと、flower2 のブロックが出るよ。

13. チャットコマンド「q48r01」の中に、「変数flower2を「flowersのchoice2番目の値」にする」（変数）をつなごう。

14. チャットコマンド「q48r01」の中に、「flower2 を~0 ~0 ~13 に置く」（ブロック）をつなごう。

15. 緑の実行ボタンを押して、Tキーのチャットで q48r01 と入力しよう。

16. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q48r01", function () {
    let flowers = [POPPY, YELLOW_FLOWER]
    let choice1 = randint(0, 1)
    let flower1 = flowers[choice1]
    blocks.place(flower1, pos(-4, 0, 13))
    let choice2 = randint(0, 1)
    let flower2 = flowers[choice2]
    blocks.place(flower2, pos(0, 0, 13))
})

```
