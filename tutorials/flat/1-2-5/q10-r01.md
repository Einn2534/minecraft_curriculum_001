## C02 Q10 R01 1区間の迷宮の出口

**C02 Q10 R01 1区間の迷宮の出口**

1つの位置を指定して、ゴールへ移動しよう。

完成するもの: 迷宮の出口の道とゴール

学ぶこと: 順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q10r01 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q10r01」の中に、「~-6 ~0 ~12 にテレポートする」（プレイヤー）をつなごう。

4. チャットコマンド「q10r01」の中に、「コマンド "function grandfort/course/arrival/r028" を 実行する」（プレイヤー）をつなごう。

5. 緑の実行ボタンを押して、Tキーのチャットで q10r01 と入力しよう。

6. 「ゴールに到着！」が出たら、緑の道で工房NPCへ戻ろう。到着の記録は残るよ。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q10r01", function () {
    player.teleport(pos(-6, 0, 12))
    player.execute("function grandfort/course/arrival/r028")
})

```
