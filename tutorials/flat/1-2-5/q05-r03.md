## C01 Q05 R03 宝物と照合

**C01 Q05 R03 宝物と照合**

宝物の番号が2なら、金庫の中を明るくしよう。

完成するもの: 番号を照合すると金の扉が開く王家の金庫

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q05r03 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に treasure と入力して「OK」を押すと、treasure のブロックが出るよ。

4. チャットコマンド「q05r03」の中に、「変数treasureを2にする」（変数）をつなごう。

5. チャットコマンド「q05r03」の中に、「もし treasure  =  2 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 条件の「なら」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

7. いまつないだ「ブロックを並べる」の材料を「グロウストーン」にしよう。「範囲の始まり」は ~-1 ~1 ~12、「範囲の終わり」は ~1 ~1 ~12 にするよ。

8. 緑の実行ボタンを押して、Tキーのチャットで q05r03 と入力しよう。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q05r03", function () {
    let treasure = 2
    if (treasure == 2) {
        blocks.fill(GLOWSTONE, pos(-1, 1, 12), pos(1, 1, 12), FillOperation.Replace)
    }
})

```
