## C01 Q02 R03 交互の模様

**C01 Q02 R03 交互の模様**

見本の続きに、赤い模様を3個付けよう。

完成するもの: 玉座へ続く左右対称の床の紋章

学ぶこと: 見本の模様と位置、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q02r03 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q02r03」の中に、「赤色の羊毛 を~-2 ~0 ~11 に置く」（ブロック）をつなごう。

4. チャットコマンド「q02r03」の中に、「赤色の羊毛 を~-2 ~0 ~13 に置く」（ブロック）をつなごう。

5. チャットコマンド「q02r03」の中に、「赤色の羊毛 を~-1 ~0 ~10 に置く」（ブロック）をつなごう。

6. 緑の実行ボタンを押して、Tキーのチャットで q02r03 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q02r03", function () {
    blocks.place(RED_WOOL, pos(-2, 0, 11))
    blocks.place(RED_WOOL, pos(-2, 0, 13))
    blocks.place(RED_WOOL, pos(-1, 0, 10))
})

```
