## 課題

Agentが鐘を正しい順番と回数で鳴らす

工房中心から [[-4.0, 1, 1], [-3.0, 1, 1], [-2.0, 1, 1], [-1.0, 1, 1], [0.0, 1, 1], [1.0, 1, 1], [2.0, 1, 1], [3.0, 1, 1]] の位置に銅ブロックを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q07 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q07", function () {
    agent.setSlot(1)
    agent.teleport(pos(-4.0, 1, 10), EAST)
    for (let i = 0; i < 8; i++) {
        agent.place(DOWN)
        agent.move(FORWARD, 1)
    }
})
```
