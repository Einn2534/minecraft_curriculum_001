# Q53 灌漑路の掘削

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

一定間隔で水路を掘り、端まで来たら次列へ移る

工房中心から [[-5, 1, 3], [0, 1, 5], [5, 1, 3]] の位置に青色のコンクリートを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q53 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q53", function () {
    agent.setSlot(1)
    agent.teleport(pos(-5, 1, 12), EAST)
    agent.place(DOWN)
    agent.teleport(pos(0, 1, 14), EAST)
    agent.place(DOWN)
    agent.teleport(pos(5, 1, 12), EAST)
    agent.place(DOWN)
})
```
