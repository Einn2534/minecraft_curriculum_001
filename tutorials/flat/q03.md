# Q03 衛兵巡回試験

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

標識ブロックを検知しながら決められた巡回路を一周する

Agentを奥の金ブロック中央へ移動します。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q03 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q03", function () {
    agent.setSlot(1)
    agent.teleport(pos(-8, 0, 1), SOUTH)
    agent.move(FORWARD, 12)
    agent.turn(LEFT_TURN)
    agent.move(FORWARD, 9)
})
```
