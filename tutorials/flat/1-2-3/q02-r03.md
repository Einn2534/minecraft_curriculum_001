## C01 Q02 R03 交互の模様

**C01 Q02 R03 交互の模様**

用意した白い下地に赤い模様を8個付けよう。

完成するもの: 玉座へ続く左右対称の床の紋章

学ぶこと: 見本の模様と位置、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q02r03 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q02r03」に、「赤色の羊毛 を~-2 ~0 ~11 に置く」（ブロック）をつなごう。

4. 中のチャットコマンド「q02r03」に、「赤色の羊毛 を~-2 ~0 ~13 に置く」（ブロック）をつなごう。

5. 中のチャットコマンド「q02r03」に、「赤色の羊毛 を~-1 ~0 ~10 に置く」（ブロック）をつなごう。

6. 中のチャットコマンド「q02r03」に、「赤色の羊毛 を~-1 ~0 ~14 に置く」（ブロック）をつなごう。

7. 中のチャットコマンド「q02r03」に、「赤色の羊毛 を~1 ~0 ~10 に置く」（ブロック）をつなごう。

8. 中のチャットコマンド「q02r03」に、「赤色の羊毛 を~1 ~0 ~14 に置く」（ブロック）をつなごう。

9. 中のチャットコマンド「q02r03」に、「赤色の羊毛 を~2 ~0 ~11 に置く」（ブロック）をつなごう。

10. 中のチャットコマンド「q02r03」に、「赤色の羊毛 を~2 ~0 ~13 に置く」（ブロック）をつなごう。

11. 緑の実行ボタンを押して、Tキーのチャットで q02r03 と入力しよう。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q02r03", function () {
    blocks.place(RED_WOOL, pos(-2, 0, 11))
    blocks.place(RED_WOOL, pos(-2, 0, 13))
    blocks.place(RED_WOOL, pos(-1, 0, 10))
    blocks.place(RED_WOOL, pos(-1, 0, 14))
    blocks.place(RED_WOOL, pos(1, 0, 10))
    blocks.place(RED_WOOL, pos(1, 0, 14))
    blocks.place(RED_WOOL, pos(2, 0, 11))
    blocks.place(RED_WOOL, pos(2, 0, 13))
})
```
