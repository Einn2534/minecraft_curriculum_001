## C07 Q33 R03 会計を関数にする

**C07 Q33 R03 会計を関数にする**

値段を計算する関数と表示する関数を分けよう。

完成するもの: 値段と個数を計算して表示する商人の会計台

学ぶこと: 関数（まとめた手順）と引数、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を price_q33r03 にしよう。数字の入力を price、quantity の順で追加しよう。

3. 中の関数「price_q33r03」に、「もし quantity >= 3 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

4. 中の条件の「なら」に、「変数priceを-1だけ増やす」（変数）をつなごう。

5. 中の関数「price_q33r03」に、「戻る price * quantity」（関数）をつなごう。

6. 「関数を作成する...」（関数）で名前を show_q33r03 にしよう。数字の入力を total の順で追加しよう。

7. 中の関数「show_q33r03」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

8. 中のくり返し（item）に、「金ブロック を~-4 + item ~0 ~12 に置く」（ブロック）をつなごう。

9. 「チャットコマンド q33r03 を入力した時」（プレイヤー）を置こう。

10. 中のチャットコマンド「q33r03」に、「変数totalを「呼び出し price_q33r03」に 4、2 を入れるにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

11. 中のチャットコマンド「q33r03」に、「呼び出し show_q33r03」に total を入れる（関数）をつなごう。

12. 中のチャットコマンド「q33r03」に、「ビルダー: 位置 ~-5 ~1 ~13 へテレポート」（ビルダー）をつなごう。

13. 中のチャットコマンド「q33r03」に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

14. 中のチャットコマンド「q33r03」に、「ビルダー: 位置 ~5 ~1 ~13 へテレポート」（ビルダー）をつなごう。

15. 中のチャットコマンド「q33r03」に、「ビルダー: 印を付けた場所からブロック オークの板材 で埋める」（ビルダー）をつなごう。

16. 緑の実行ボタンを押して、Tキーのチャットで q33r03 と入力しよう。

17. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function price_q33r03(price: number, quantity: number): number {
    if (quantity >= 3) {
        price += -1
    }
    return price * quantity
}
function show_q33r03(total: number) {
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
}
player.onChat("q33r03", function () {
    let total = price_q33r03(4, 2)
    show_q33r03(total)
    builder.teleportTo(pos(-5, 1, 13))
    builder.mark()
    builder.teleportTo(pos(5, 1, 13))
    builder.fill(PLANKS_OAK)
})

```
