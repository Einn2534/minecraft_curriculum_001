## C12 Q57 R03 リストで誘導する

**C12 Q57 R03 リストで誘導する**

左の囲いの牛を右へ移そう。ほかの工房の動物は動かさないよ。

完成するもの: 牛と羊を別の囲いへ分ける牧場

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を guide_q57r03_cow にしよう。数字の入力を x の順で追加しよう。

3. 中の関数「guide_q57r03_cow」に、「「ある位置から一定の範囲内にいる「すべての ウシ」 位置~-5 ~0 ~13 半径3」 を~x ~0 ~13 にテレポートさせる」（モブ）をつなごう。

4. 「関数を作成する...」（関数）で名前を guide_q57r03_sheep にしよう。数字の入力を x の順で追加しよう。

5. 中の関数「guide_q57r03_sheep」に、「「ある位置から一定の範囲内にいる「すべての 羊」 位置~0 ~0 ~6 半径3」 を~x ~0 ~15 にテレポートさせる」（モブ）をつなごう。

6. 「チャットコマンド q57r03 を入力した時」（プレイヤー）を置こう。

7. 中のチャットコマンド「q57r03」に、「変数cowDestinationsを「配列を作成」に 5 を順に入れるにする」（変数）をつなごう。 cowDestinations がなければ「変数を追加する...」で作ろう。

8. 中のチャットコマンド「q57r03」に、「配列cowDestinationsの値を変数xに入れてくりかえす」（ループ）をつなごう。

9. 中の配列cowDestinationsのくり返し（x）に、「呼び出し guide_q57r03_cow」に x を入れる（関数）をつなごう。

10. 中のチャットコマンド「q57r03」に、「変数sheepDestinationsを「配列を作成」に 0 を順に入れるにする」（変数）をつなごう。 sheepDestinations がなければ「変数を追加する...」で作ろう。

11. 中のチャットコマンド「q57r03」に、「配列sheepDestinationsの値を変数xに入れてくりかえす」（ループ）をつなごう。

12. 中の配列sheepDestinationsのくり返し（x）に、「呼び出し guide_q57r03_sheep」に x を入れる（関数）をつなごう。

13. 緑の実行ボタンを押して、Tキーのチャットで q57r03 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function guide_q57r03_cow(x: number) {
    mobs.teleportToPosition(mobs.near(mobs.entitiesByType(COW), pos(-5, 0, 13), 3), pos(x, 0, 13))
}
function guide_q57r03_sheep(x: number) {
    mobs.teleportToPosition(mobs.near(mobs.entitiesByType(SHEEP), pos(0, 0, 6), 3), pos(x, 0, 15))
}
player.onChat("q57r03", function () {
    let cowDestinations = [5]
    for (let x of cowDestinations) {
        guide_q57r03_cow(x)
    }
    let sheepDestinations = [0]
    for (let x of sheepDestinations) {
        guide_q57r03_sheep(x)
    }
})

```
