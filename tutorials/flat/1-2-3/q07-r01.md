## C02 Q07 R01 小さな鐘

**C02 Q07 R01 小さな鐘**

台の上に音符ブロックを置いて鐘を作ろう。

完成するもの: 音符ブロックが並ぶ鐘楼とチャットで鳴る旋律

学ぶこと: 順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q07r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q07r01」に、「ブロックを並べる」（ブロック）をつなごう。石レンガを選び、「範囲の始まり」を ~-2 ~0 ~12、「範囲の終わり」を ~2 ~0 ~12、「モード」を「置き換え (replace)」にしよう。

4. 中のチャットコマンド「q07r01」に、「ブロックを並べる」（ブロック）をつなごう。音符ブロックを選び、「範囲の始まり」を ~0 ~1 ~12、「範囲の終わり」を ~0 ~1 ~12、「モード」を「置き換え (replace)」にしよう。

5. 緑の実行ボタンを押して、Tキーのチャットで q07r01 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q07r01", function () {
    blocks.fill(STONE_BRICKS, pos(-2, 0, 12), pos(2, 0, 12), FillOperation.Replace)
    blocks.fill(NOTE_BLOCK, pos(0, 1, 12), pos(0, 1, 12), FillOperation.Replace)
})

```
