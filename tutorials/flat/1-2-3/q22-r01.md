## C05 Q22 R01 1つの在庫

**C05 Q22 R01 1つの在庫**

Agentの1番の持ち物を数え、金の棒にして表示しよう。

完成するもの: 荷物の数に合わせて積む港の荷役台

学ぶこと: 変数（数を入れる箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q22r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q22r01」に、「変数totalを「エージェントのスロット番号1 のアイテムの数」にする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q22r01」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

5. 中のくり返し（item）に、「金ブロック を~-4 + item ~0 ~12 に置く」（ブロック）をつなごう。

6. 緑の実行ボタンを押して、Tキーのチャットで q22r01 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q22r01", function () {
    let total = agent.getItemCount(1)
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
})

```
