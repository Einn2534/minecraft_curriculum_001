## C12 Q58 R03 繁殖計画ボード

**C12 Q58 R03 繁殖計画ボード**

牛6頭から作れる3組を計算し、計画ボードを表示しよう。

完成するもの: 親の組数と必要なえさを計算する繁殖計画の牧場

学ぶこと: 変数（数を入れる箱）、割り算・余り、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を pairs_q58r03 にしよう。数字の入力を heads の順で追加しよう。

3. 中の関数「pairs_q58r03」に、「メッセージ 「文字列をつなげる」に "組に入らない頭数: " と (heads % 2) を入れる を 送信する」（プレイヤー）をつなごう。

4. 中の関数「pairs_q58r03」に、「戻る 「整数の÷」に heads と 2 を入れる」（関数）をつなごう。

5. 「チャットコマンド q58r03 を入力した時」（プレイヤー）を置こう。

6. 中のチャットコマンド「q58r03」に、「「ある位置から一定の範囲内にいる「すべての ウシ」 位置~-5 ~0 ~13 半径3」」（モブ）をつなごう。

7. 中のチャットコマンド「q58r03」に、「変数countを6にする」（変数）をつなごう。 count がなければ「変数を追加する...」で作ろう。

8. 中のチャットコマンド「q58r03」に、「くりかえしcount回」（ループ）をつなごう。

9. 中のcount回のくり返しに、「ウシ を~-5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

10. 中のチャットコマンド「q58r03」に、「変数headsを6にする」（変数）をつなごう。 heads がなければ「変数を追加する...」で作ろう。

11. 中のチャットコマンド「q58r03」に、「変数totalを「呼び出し pairs_q58r03」に heads を入れるにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

12. 中のチャットコマンド「q58r03」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

13. 中のくり返し（item）に、「金ブロック を~2 + item ~0 ~11 に置く」（ブロック）をつなごう。

14. 中のチャットコマンド「q58r03」に、「変数xを0～2に変えてくりかえす」（ループ）をつなごう。

15. 中のくり返し（x）に、「干草の俵 を~(x + 3) ~0 ~12 に置く」（ブロック）をつなごう。

16. 緑の実行ボタンを押して、Tキーのチャットで q58r03 と入力しよう。

17. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function pairs_q58r03(heads: number): number {
    player.say("組に入らない頭数: " + (heads % 2))
    return Math.idiv(heads, 2)
}
player.onChat("q58r03", function () {
    mobs.kill(mobs.near(mobs.entitiesByType(COW), pos(-5, 0, 13), 3))
    let count = 6
    for (let number = 0; number < count; number++) {
        mobs.spawn(COW, pos(-5, 0, 13))
    }
    let heads = 6
    let total = pairs_q58r03(heads)
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(2 + item, 0, 11))
    }
    for (let x = 0; x <= 2; x++) {
        blocks.place(HAY_BLOCK, pos((x + 3), 1 - 1, 3 + 9))
    }
})

```
