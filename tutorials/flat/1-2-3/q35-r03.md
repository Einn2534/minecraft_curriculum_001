## C07 Q35 R03 リストで誘導する

**C07 Q35 R03 リストで誘導する**

左の囲いの村人を右へ移そう。ほかの工房の動物は動かさないよ。

完成するもの: 村人を分けて通路を空ける市場

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を guide_q35r03_villager にしよう。数字の入力を x の順で追加しよう。

3. 中の関数「guide_q35r03_villager」に、「「ある位置から一定の範囲内にいる「すべての 村人」 位置~-5 ~0 ~13 半径3」 を~x ~0 ~13 にテレポートさせる」（モブ）をつなごう。

4. 「チャットコマンド q35r03 を入力した時」（プレイヤー）を置こう。

5. 中のチャットコマンド「q35r03」に、「変数villagerDestinationsを「配列を作成」に 5 を順に入れるにする」（変数）をつなごう。 villagerDestinations がなければ「変数を追加する...」で作ろう。

6. 中のチャットコマンド「q35r03」に、「配列villagerDestinationsの値を変数xに入れてくりかえす」（ループ）をつなごう。

7. 中の配列villagerDestinationsのくり返し（x）に、「呼び出し guide_q35r03_villager」に x を入れる（関数）をつなごう。

8. 緑の実行ボタンを押して、Tキーのチャットで q35r03 と入力しよう。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function guide_q35r03_villager(x: number) {
    mobs.teleportToPosition(mobs.near(mobs.entitiesByType(VILLAGER), pos(-5, 0, 13), 3), pos(x, 0, 13))
}
player.onChat("q35r03", function () {
    let villagerDestinations = [5]
    for (let x of villagerDestinations) {
        guide_q35r03_villager(x)
    }
})

```
