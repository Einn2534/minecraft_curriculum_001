## C02 Q06 R03 王家の飾り

**C02 Q06 R03 王家の飾り**

真ん中の柱と金の飾りを付けよう。

完成するもの: 色ガラスで復元した城の窓

学ぶこと: 順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q06r03 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q06r03」に、「ブロックを並べる」（ブロック）をつなごう。金ブロックを選び、「範囲の始まり」を ~0 ~0 ~13、「範囲の終わり」を ~0 ~4 ~13、「モード」を「置き換え (replace)」にしよう。

4. 中のチャットコマンド「q06r03」に、「ブロックを並べる」（ブロック）をつなごう。金ブロックを選び、「範囲の始まり」を ~-1 ~3 ~13、「範囲の終わり」を ~1 ~3 ~13、「モード」を「置き換え (replace)」にしよう。

5. 緑の実行ボタンを押して、Tキーのチャットで q06r03 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q06r03", function () {
    blocks.fill(GOLD_BLOCK, pos(0, 0, 13), pos(0, 4, 13), FillOperation.Replace)
    blocks.fill(GOLD_BLOCK, pos(-1, 3, 13), pos(1, 3, 13), FillOperation.Replace)
})
```
