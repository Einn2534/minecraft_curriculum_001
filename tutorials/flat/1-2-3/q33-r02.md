## C07 Q33 R02 まとめ買い

**C07 Q33 R02 まとめ買い**

単価3・個数3なら1円引きの単価2で計算しよう。

完成するもの: 値段と個数を計算して表示する商人の会計台

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q33r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q33r02」に、「変数priceを3にする」（変数）をつなごう。 price がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q33r02」に、「変数quantityを3にする」（変数）をつなごう。 quantity がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q33r02」に、「もし quantity >= 3 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 中の条件の「なら」に、「変数priceを-1だけ増やす」（変数）をつなごう。

7. 中のチャットコマンド「q33r02」に、「変数totalをprice * quantityにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

8. 中のチャットコマンド「q33r02」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

9. 中のくり返し（item）に、「金ブロック を~-4 + item ~0 ~12 に置く」（ブロック）をつなごう。

10. 緑の実行ボタンを押して、Tキーのチャットで q33r02 と入力しよう。

11. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q33r02", function () {
    let price = 3
    let quantity = 3
    if (quantity >= 3) {
        price += -1
    }
    let total = price * quantity
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
})

```
