## C10 Q49 R01 1区間の郵便の経路

**C10 Q49 R01 1区間の郵便の経路**

Agentを曲がり角に沿って金のゴールへ動かそう。

完成するもの: 郵便の経路の道とゴール

学ぶこと: 順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q49r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q49r01」に、「エージェントを ~-6 ~0 ~9 へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

4. 中のチャットコマンド「q49r01」に、「エージェントを 「エージェントの位置」 へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

5. 中のチャットコマンド「q49r01」に、「エージェントを 前 に 3 ブロック移動させる」（エージェント）をつなごう。

6. 緑の実行ボタンを押して、Tキーのチャットで q49r01 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q49r01", function () {
    agent.teleport(pos(-6, 0, 9), SOUTH)
    agent.teleport(agent.getPosition(), SOUTH)
    agent.move(FORWARD, 3)
```
