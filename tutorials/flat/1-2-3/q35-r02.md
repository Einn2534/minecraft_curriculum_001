## C07 Q35 R02 種類で選ぶ

**C07 Q35 R02 種類で選ぶ**

左の囲いの村人を右へ移そう。ほかの工房の動物は動かさないよ。

完成するもの: 村人を分けて通路を空ける市場

学ぶこと: 種類と場所で選ぶ、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q35r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q35r02」に、「もし 「金ブロック が~-5 ~-1 ~13 に存在する」  かつ  「空気 が~5 ~0 ~13 に存在する」 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

4. 中の条件の「なら」に、「「ある位置から一定の範囲内にいる「すべての 村人」 位置~-5 ~0 ~13 半径3」 を~5 ~0 ~13 にテレポートさせる」（モブ）をつなごう。

5. 緑の実行ボタンを押して、Tキーのチャットで q35r02 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q35r02", function () {
    if (blocks.testForBlock(GOLD_BLOCK, pos(-5, -1, 13)) && blocks.testForBlock(AIR, pos(5, 0, 13))) {
        mobs.teleportToPosition(mobs.near(mobs.entitiesByType(VILLAGER), pos(-5, 0, 13), 3), pos(5, 0, 13))
    }
})
```
