## C05 Q24 R03 手すりと屋根

**C05 Q24 R03 手すりと屋根**

引数で長さを指定し、手すりと屋根を仕上げよう。

完成するもの: 荷車が渡れる幅の広い橋

学ぶこと: 配列（順番のあるリスト）、Builder

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q24r03 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q24r03」に、「変数heightsを「配列を作成」に 3 を順に入れるにする」（変数）をつなごう。 heights がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q24r03」に、「配列heightsの値を変数heightに入れてくりかえす」（ループ）をつなごう。

5. 中の配列heightsのくり返し（height）に、「ブロックを並べる」（ブロック）をつなごう。オークの板材を選び、「範囲の始まり」を ~-3 ~height - 1 ~8、「範囲の終わり」を ~-3 ~height - 1 ~16、「モード」を「置き換え (replace)」にしよう。

6. 中の配列heightsのくり返し（height）に、「ブロックを並べる」（ブロック）をつなごう。オークの板材を選び、「範囲の始まり」を ~3 ~height - 1 ~8、「範囲の終わり」を ~3 ~height - 1 ~16、「モード」を「置き換え (replace)」にしよう。

7. 中のチャットコマンド「q24r03」に、「ビルダー: 位置 ~-3 ~3 ~8 へテレポート」（ビルダー）をつなごう。

8. 中のチャットコマンド「q24r03」に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

9. 中のチャットコマンド「q24r03」に、「ビルダー: 位置 ~3 ~3 ~16 へテレポート」（ビルダー）をつなごう。

10. 中のチャットコマンド「q24r03」に、「ビルダー: 印を付けた場所からブロック オークの板材 で埋める」（ビルダー）をつなごう。

11. 緑の実行ボタンを押して、Tキーのチャットで q24r03 と入力しよう。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q24r03", function () {
    let heights = [3]
    for (let height of heights) {
        blocks.fill(PLANKS_OAK, pos(-3, height - 1, 8), pos(-3, height - 1, 16), FillOperation.Replace)
        blocks.fill(PLANKS_OAK, pos(3, height - 1, 8), pos(3, height - 1, 16), FillOperation.Replace)
    }
    builder.teleportTo(pos(-3, 3, 8))
    builder.mark()
    builder.teleportTo(pos(3, 3, 16))
    builder.fill(PLANKS_OAK)
})

```
