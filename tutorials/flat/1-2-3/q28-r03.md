## C06 Q28 R03 ランダムな的

**C06 Q28 R03 ランダムな的**

矢を放つたび、3つの的のどれかを金に変えよう。

完成するもの: 弓を使うと反応する3つの的

学ぶこと: 配列（順番のあるリスト）、乱数（くじ引き）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「変数eventOriginを「プレイヤーの位置」にする」（変数）をつなごう。 eventOrigin がなければ「変数を追加する...」で作ろう。

3. 「変数eventReadyを偽にする」（変数）をつなごう。 eventReady がなければ「変数を追加する...」で作ろう。

4. 「チャットコマンド q28r03 を入力した時」（プレイヤー）を置こう。

5. 中のチャットコマンド「q28r03」に、「変数eventOriginを「プレイヤーの位置」にする」（変数）をつなごう。

6. 中のチャットコマンド「q28r03」に、「変数eventReadyを真にする」（変数）をつなごう。

7. 中のチャットコマンド「q28r03」に、「ブロックを並べる」（ブロック）をつなごう。白色の羊毛を選び、「範囲の始まり」を ~-6 ~1 ~14、「範囲の終わり」を ~-4 ~3 ~14、「モード」を「置き換え (replace)」にしよう。

8. 中のチャットコマンド「q28r03」に、「ブロックを並べる」（ブロック）をつなごう。白色の羊毛を選び、「範囲の始まり」を ~4 ~1 ~14、「範囲の終わり」を ~6 ~3 ~14、「モード」を「置き換え (replace)」にしよう。

9. 「プレイヤーが矢を放った時」（プレイヤー）を、チャットコマンドの外に置こう。

10. 中のイベントに、「もし eventReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

11. 中の条件の「なら」に、「変数placesを「配列を作成」に -5、0、5 を順に入れるにする」（変数）をつなごう。 places がなければ「変数を追加する...」で作ろう。

12. 中の条件の「なら」に、「変数indexを「ランダムな数字を選択: 0 から 「配列の長さ places」 - 1 まで」にする」（変数）をつなごう。 index がなければ「変数を追加する...」で作ろう。

13. 中の条件の「なら」に、「変数xを「placesのindex番目の値」にする」（変数）をつなごう。 x がなければ「変数を追加する...」で作ろう。

14. 中の条件の「なら」に、「金ブロック を「eventOrigin + ~x ~2 ~13」 に置く」（ブロック）をつなごう。

15. 緑の実行ボタンを押して、Tキーのチャットで q28r03 と入力しよう。

16. 入口の金の床から、用意した弓で矢を放とう。矢を放ったイベントで的の色が変わるよ。

17. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q28r03", function () {
    eventOrigin = player.position()
    eventReady = true
    blocks.fill(WOOL, pos(-6, 1, 14), pos(-4, 3, 14), FillOperation.Replace)
    blocks.fill(WOOL, pos(4, 1, 14), pos(6, 3, 14), FillOperation.Replace)
})
player.onArrowShot(function () {
    if (eventReady) {
        let places = [-5, 0, 5]
        let index = randint(0, places.length - 1)
        let x = places[index]
        blocks.place(GOLD_BLOCK, positions.add(eventOrigin, pos(x, 2, 13)))
    }
})

```
