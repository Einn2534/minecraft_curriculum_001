## C05 Q22 R03 棚へ運ぶ計画

**C05 Q22 R03 棚へ運ぶ計画**

リストから3つの在庫を合計し、棚を完成させよう。

完成するもの: 荷物の数に合わせて積む港の荷役台

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を stock_q22r03 にしよう。数字の入力を lastSlot の順で追加しよう。

3. 中の関数「stock_q22r03」に、「変数slotsを「配列を作成」に 1、2、3 を順に入れるにする」（変数）をつなごう。 slots がなければ「変数を追加する...」で作ろう。

4. 中の関数「stock_q22r03」に、「変数totalを0にする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

5. 中の関数「stock_q22r03」に、「配列slotsの値を変数slotに入れてくりかえす」（ループ）をつなごう。

6. 中の配列slotsのくり返し（slot）に、「もし slot <= lastSlot なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

7. 中の条件の「なら」に、「変数totalを「エージェントのスロット番号slot のアイテムの数」だけ増やす」（変数）をつなごう。

8. 中の関数「stock_q22r03」に、「戻る total」（関数）をつなごう。

9. 「チャットコマンド q22r03 を入力した時」（プレイヤー）を置こう。

10. 中のチャットコマンド「q22r03」に、「変数totalを「呼び出し stock_q22r03」に 3 を入れるにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

11. 中のチャットコマンド「q22r03」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

12. 中のくり返し（item）に、「金ブロック を~-4 + item ~0 ~12 に置く」（ブロック）をつなごう。

13. 中のチャットコマンド「q22r03」に、「ビルダー: 位置 ~-5 ~1 ~13 へテレポート」（ビルダー）をつなごう。

14. 中のチャットコマンド「q22r03」に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

15. 中のチャットコマンド「q22r03」に、「ビルダー: 位置 ~5 ~1 ~13 へテレポート」（ビルダー）をつなごう。

16. 中のチャットコマンド「q22r03」に、「ビルダー: 印を付けた場所からブロック オークの板材 で埋める」（ビルダー）をつなごう。

17. 緑の実行ボタンを押して、Tキーのチャットで q22r03 と入力しよう。

18. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function stock_q22r03(lastSlot: number): number {
    let slots = [1, 2, 3]
    let total = 0
    for (let slot of slots) {
        if (slot <= lastSlot) {
            total += agent.getItemCount(slot)
        }
    }
    return total
}
player.onChat("q22r03", function () {
    let total = stock_q22r03(3)
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
    builder.teleportTo(pos(-5, 1, 13))
    builder.mark()
    builder.teleportTo(pos(5, 1, 13))
    builder.fill(PLANKS_OAK)
})

```
