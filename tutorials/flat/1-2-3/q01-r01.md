## C01 Q01 R01 旗柱を立てよう

**C01 Q01 R01 旗柱を立てよう**

石の台の上に、木の旗柱を6段立てよう。

完成するもの: 旗柱・赤い旗・金の王家の印がついた王旗

学ぶこと: 順番に動かす、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q01r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q01r01」に、「ブロックを並べる」（ブロック）をつなごう。石レンガを選び、「範囲の始まり」を ~-1 ~0 ~11、「範囲の終わり」を ~1 ~0 ~13、「モード」を「置き換え (replace)」にしよう。

4. 中のチャットコマンド「q01r01」に、「エージェントのスロット番号 1 を 有効にする」（エージェント）をつなごう。

5. 中のチャットコマンド「q01r01」に、「エージェントを ~-1 ~1 ~12 へ 東 (Xのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

6. 中のチャットコマンド「q01r01」に、「くりかえし6回」（ループ）をつなごう。

7. 中の6回のくり返しに、「エージェントに 前 へ 置かせる」（エージェント）をつなごう。

8. 中の6回のくり返しに、「エージェントを 上 に 1 ブロック移動させる」（エージェント）をつなごう。

9. 緑の実行ボタンを押して、Tキーのチャットで q01r01 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q01r01", function () {
    blocks.fill(STONE_BRICKS, pos(-1, 0, 11), pos(1, 0, 13), FillOperation.Replace)
    agent.setSlot(1)
    agent.teleport(pos(-1, 1, 12), EAST)
    for (let step = 0; step < 6; step++) {
        agent.place(FORWARD)
        agent.move(UP, 1)
    }
})

```
