## C03 Q11 R02 2区間の座標のゴール

**C03 Q11 R02 2区間の座標のゴール**

自分を曲がり角に沿って金のゴールへ動かそう。

完成するもの: 座標のゴールの道とゴール

学ぶこと: 移動する位置、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q11r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q11r02」に、「変数originを「プレイヤーの位置」にする」（変数）をつなごう。 origin がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q11r02」に、「「origin + ~-6 ~0 ~13」 にテレポートする」（プレイヤー）をつなごう。

5. 中のチャットコマンド「q11r02」に、「「origin + ~4 ~0 ~13」 にテレポートする」（プレイヤー）をつなごう。

6. 中のチャットコマンド「q11r02」に、「コマンド "function grandfort/course/arrival/r032" を 実行する」（プレイヤー）をつなごう。

7. 緑の実行ボタンを押して、Tキーのチャットで q11r02 と入力しよう。

8. 「ゴールに到着！」が出たら、緑の道で工房NPCへ戻ろう。到着の記録は残るよ。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q11r02", function () {
    let origin = player.position()
    player.teleport(positions.add(origin, pos(-6, 0, 13)))
    player.teleport(positions.add(origin, pos(4, 0, 13)))
    player.execute("function grandfort/course/arrival/r032")
})

```
