## C10 Q46 R01 1軒へ配達

**C10 Q46 R01 1軒へ配達**

Agentを動かし、1つ目の配達台にケーキを届けよう。

完成するもの: パン屋から3つの配達先へ運ぶ配達路

学ぶこと: 座標、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q46r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q46r01」に、「エージェントを ~-4 ~2 ~12 へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

4. 中のチャットコマンド「q46r01」に、「ケーキ を~-4 ~1 ~12 に置く」（ブロック）をつなごう。

5. 緑の実行ボタンを押して、Tキーのチャットで q46r01 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q46r01", function () {
        agent.teleport(pos(-4, 2, 3 + 9), SOUTH)
        blocks.place(CAKE, pos(-4, 2 - 1, 3 + 9))
})
```
