## C07 Q34 R02 リストから選ぶ

**C07 Q34 R02 リストから選ぶ**

用意した安全な候補から、くじ引きで1か所を選ぼう。

完成するもの: くじ引きで小包を隠す倉庫

学ぶこと: 配列（順番のあるリスト）、乱数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q34r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q34r02」に、「変数placesを「配列を作成」に -4、0、4 を順に入れるにする」（変数）をつなごう。 places がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q34r02」に、「変数indexを「ランダムな数字を選択: 0 から 「配列の長さ places」 - 1 まで」にする」（変数）をつなごう。 index がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q34r02」に、「変数xを「placesのindex番目の値」にする」（変数）をつなごう。 x がなければ「変数を追加する...」で作ろう。

6. 中のチャットコマンド「q34r02」に、「チェスト を~x ~0 ~13 に置く」（ブロック）をつなごう。

7. 緑の実行ボタンを押して、Tキーのチャットで q34r02 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q34r02", function () {
    let places = [-4, 0, 4]
    let index = randint(0, places.length - 1)
    let x = places[index]
    blocks.place(CHEST, pos(x, 0, 13))
})

```
