## C11 Q54 R03 3本の果樹

**C11 Q54 R03 3本の果樹**

リストとくり返しで3本目を作り、赤い実を飾ろう。

完成するもの: 間隔を計算して植える王立果樹園

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を part_q54r03_1 にしよう。

3. 中の関数「part_q54r03_1」に、「ブロックを並べる」（ブロック）をつなごう。オークの原木を選び、「範囲の始まり」を ~4 ~0 ~12、「範囲の終わり」を ~4 ~3 ~12、「モード」を「置き換え (replace)」にしよう。

4. 「チャットコマンド q54r03 を入力した時」（プレイヤー）を置こう。

5. 中のチャットコマンド「q54r03」に、「呼び出し part_q54r03_1」（関数）をつなごう。

6. 中のチャットコマンド「q54r03」に、「ビルダー: 位置 ~3 ~4 ~11 へテレポート」（ビルダー）をつなごう。

7. 中のチャットコマンド「q54r03」に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

8. 中のチャットコマンド「q54r03」に、「ビルダー: 位置 ~5 ~5 ~13 へテレポート」（ビルダー）をつなごう。

9. 中のチャットコマンド「q54r03」に、「ビルダー: 印を付けた場所からブロック 樫の葉 で埋める」（ビルダー）をつなごう。

10. 中のチャットコマンド「q54r03」に、「変数placesを「配列を作成」に -4、0、4 を順に入れるにする」（変数）をつなごう。 places がなければ「変数を追加する...」で作ろう。

11. 中のチャットコマンド「q54r03」に、「配列placesの値を変数xに入れてくりかえす」（ループ）をつなごう。

12. 中の配列placesのくり返し（x）に、「赤色の羊毛 を~x ~4 ~11 に置く」（ブロック）をつなごう。

13. 緑の実行ボタンを押して、Tキーのチャットで q54r03 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

    blocks.fill(LOG_OAK, pos(4, 0, 12), pos(4, 3, 12), FillOperation.Replace)
}
player.onChat("q54r03", function () {

    builder.teleportTo(pos(3, 4, 11))

        blocks.place(RED_WOOL, pos(x, 4, 11))
    }
