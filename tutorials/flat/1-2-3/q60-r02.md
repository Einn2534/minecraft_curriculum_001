## C12 Q60 R02 2か所の在庫

**C12 Q60 R02 2か所の在庫**

残りの在庫を調べ、2か所へ順番に補充しよう。

完成するもの: 在庫を調べてえさ置き場へ補充する牧場の巡回

学ぶこと: 配列（順番のあるリスト）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q60r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q60r02」に、「変数destinationsを「配列を作成」に 「配列を作成」に -4、2、3 を順に入れる、「配列を作成」に 0、2、6 を順に入れる を順に入れるにする」（変数）をつなごう。 destinations がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q60r02」に、「配列destinationsの値を変数destinationに入れてくりかえす」（ループ）をつなごう。

5. 中の配列destinationsのくり返し（destination）に、「エージェントを ~「destinationの0番目の値」 ~「destinationの1番目の値」 ~「destinationの2番目の値」 + 9 へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

6. 中の配列destinationsのくり返し（destination）に、「もし 「エージェントのスロット番号1 のアイテムの数」 > 0 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

7. 中の条件の「なら」に、「エージェントのスロット番号 1 を 有効にする」（エージェント）をつなごう。

8. 中の条件の「なら」に、「エージェントに 下 へ 置かせる」（エージェント）をつなごう。

9. 緑の実行ボタンを押して、Tキーのチャットで q60r02 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q60r02", function () {
    let destinations = [[-4, 2, 3], [0, 2, 6]]
    for (let destination of destinations) {
        agent.teleport(pos(destination[0], destination[1], destination[2] + 9), SOUTH)
        if (agent.getItemCount(1) > 0) {
            agent.setSlot(1)
            agent.place(DOWN)
        }
    }
})

```
