## C01 Q03 R02 2区間の衛兵の巡回

**C01 Q03 R02 2区間の衛兵の巡回**

Agentを曲がり角に沿って金のゴールへ動かそう。

完成するもの: 衛兵の巡回の道とゴール

学ぶこと: くり返し、向きを変える

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q03r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q03r02」に、「エージェントを ~-6 ~0 ~9 へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

4. 中のチャットコマンド「q03r02」に、「エージェントを 「エージェントの位置」 へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

5. 中のチャットコマンド「q03r02」に、「くりかえし4回」（ループ）をつなごう。

6. 中の4回のくり返しに、「エージェントを 前 に 1 ブロック移動させる」（エージェント）をつなごう。

7. 中のチャットコマンド「q03r02」に、「エージェントを 「エージェントの位置」 へ 東 (Xのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

8. 中のチャットコマンド「q03r02」に、「くりかえし10回」（ループ）をつなごう。

9. 中の10回のくり返しに、「エージェントを 前 に 1 ブロック移動させる」（エージェント）をつなごう。

10. 緑の実行ボタンを押して、Tキーのチャットで q03r02 と入力しよう。

11. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q03r02", function () {
    agent.teleport(pos(-6, 0, 9), SOUTH)
    agent.teleport(agent.getPosition(), SOUTH)
    for (let step = 0; step < 4; step++) {
        agent.move(FORWARD, 1)
    }
    agent.teleport(agent.getPosition(), EAST)
    for (let step = 0; step < 10; step++) {
        agent.move(FORWARD, 1)
    }
})

```
