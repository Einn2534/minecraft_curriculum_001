## C03 Q14 R02 天候を読もう

**C03 Q14 R02 天候を読もう**

今の天候を読んで、晴れは金・雨は青・雷は赤で表示しよう。

完成するもの: 天候を読み、晴れ・雨・雷を色で表示する気象台

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q14r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q14r02」に、「変数valueを「現在の天気」にする」（変数）をつなごう。 value がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q14r02」に、「変数colorを金ブロックにする」（変数）をつなごう。 color がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q14r02」に、「もし value  =  Weather.Rain なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 中の条件の「なら」に、「変数colorを青色の羊毛にする」（変数）をつなごう。

7. 中のチャットコマンド「q14r02」に、「でなければもし value  =  Weather.Thunder なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 中の条件の「なら」に、「変数colorを赤色の羊毛にする」（変数）をつなごう。

9. 中のチャットコマンド「q14r02」に、「color を~0 ~3 ~12 に置く」（ブロック）をつなごう。

10. 中のチャットコマンド「q14r02」に、「メッセージ 「文字列をつなげる」に "今の値: " と value を入れる を 送信する」（プレイヤー）をつなごう。

11. 緑の実行ボタンを押して、Tキーのチャットで q14r02 と入力しよう。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q14r02", function () {
    let value = gameplay.weatherQuery()
    let color = GOLD_BLOCK
    if (value == Weather.Rain) {
        color = BLUE_WOOL
    } else if (value == Weather.Thunder) {
        color = RED_WOOL
    }
    blocks.place(color, pos(0, 3, 12))
    player.say("今の値: " + value)
})

```
