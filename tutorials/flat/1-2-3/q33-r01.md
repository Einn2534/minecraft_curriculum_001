## C07 Q33 R01 かけ算で計算

**C07 Q33 R01 かけ算で計算**

単価2・個数2の代金を金の棒グラフで表示しよう。

完成するもの: 値段と個数を計算して表示する商人の会計台

学ぶこと: 変数（数を入れる箱）、かけ算

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q33r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q33r01」に、「変数priceを2にする」（変数）をつなごう。 price がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q33r01」に、「変数quantityを2にする」（変数）をつなごう。 quantity がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q33r01」に、「変数totalをprice * quantityにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

6. 中のチャットコマンド「q33r01」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

7. 中のくり返し（item）に、「金ブロック を~-4 + item ~0 ~12 に置く」（ブロック）をつなごう。

8. 緑の実行ボタンを押して、Tキーのチャットで q33r01 と入力しよう。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q33r01", function () {
    let price = 2
    let quantity = 2
    let total = price * quantity
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
})

```
