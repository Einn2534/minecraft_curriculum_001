## C04 Q18 R03 対称な飾り

**C04 Q18 R03 対称な飾り**

四すみの位置をリストにして、光る飾りを付けよう。

完成するもの: 水盤・柱・左右対称の飾りがある噴水

学ぶこと: 配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q18r03 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q18r03」に、「変数cornersを「配列を作成」に ~-3 ~1 ~9、~3 ~1 ~9、~-3 ~1 ~15、~3 ~1 ~15 を順に入れるにする」（変数）をつなごう。 corners がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q18r03」に、「配列cornersの値を変数cornerに入れてくりかえす」（ループ）をつなごう。

5. 中の配列cornersのくり返し（corner）に、「グロウストーン をcorner に置く」（ブロック）をつなごう。

6. 緑の実行ボタンを押して、Tキーのチャットで q18r03 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q18r03", function () {
    let corners = [pos(-3, 1, 9), pos(3, 1, 9), pos(-3, 1, 15), pos(3, 1, 15)]
    for (let corner of corners) {
        blocks.place(GLOWSTONE, corner)
    }
})
```
