## C10 Q48 R01 2つから選ぶ

**C10 Q48 R01 2つから選ぶ**

花壇の各場所に、ポピーかタンポポをくじ引きで植えよう。

完成するもの: 種類をくじ引きで選ぶ花壇

学ぶこと: 乱数（くじ引き）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q48r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q48r01」に、「もし 「ランダムな数字を選択: 0 から 1 まで」  =  0 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

4. 中の条件の「なら」に、「ポピー を~-4 ~0 ~13 に置く」（ブロック）をつなごう。

5. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

6. 中の「でなければ」に、「タンポポ を~-4 ~0 ~13 に置く」（ブロック）をつなごう。

7. 中のチャットコマンド「q48r01」に、「もし 「ランダムな数字を選択: 0 から 1 まで」  =  0 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 中の条件の「なら」に、「ポピー を~0 ~0 ~13 に置く」（ブロック）をつなごう。

9. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

10. 中の「でなければ」に、「タンポポ を~0 ~0 ~13 に置く」（ブロック）をつなごう。

11. 緑の実行ボタンを押して、Tキーのチャットで q48r01 と入力しよう。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q48r01", function () {

    }

    } else {

    }
})
```
