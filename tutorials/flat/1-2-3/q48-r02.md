## C10 Q48 R02 リストから選ぶ

**C10 Q48 R02 リストから選ぶ**

花壇の各場所に、ポピーかタンポポをくじ引きで植えよう。

完成するもの: 種類をくじ引きで選ぶ花壇

学ぶこと: 配列（順番のあるリスト）、乱数

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q48r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q48r02」に、「変数placesを「配列を作成」に -4、0、4 を順に入れるにする」（変数）をつなごう。 places がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q48r02」に、「配列placesの値を変数xに入れてくりかえす」（ループ）をつなごう。

5. 中の配列placesのくり返し（x）に、「もし 「ランダムな数字を選択: 0 から 1 まで」  =  0 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 中の条件の「なら」に、「ポピー を~x ~0 ~13 に置く」（ブロック）をつなごう。

7. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

8. 中の「でなければ」に、「タンポポ を~x ~0 ~13 に置く」（ブロック）をつなごう。

9. 緑の実行ボタンを押して、Tキーのチャットで q48r02 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q48r02", function () {
    let places = [-4, 0, 4]
    for (let x of places) {
        if (randint(0, 1) == 0) {
            blocks.place(POPPY, pos(x, 0, 13))
        } else {
            blocks.place(YELLOW_FLOWER, pos(x, 0, 13))
        }
    }
})

```
