## C07 Q34 R01 2つから選ぶ

**C07 Q34 R01 2つから選ぶ**

用意した安全な候補から、くじ引きで1か所を選ぼう。

完成するもの: くじ引きで小包を隠す倉庫

学ぶこと: 乱数（くじ引き）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q34r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q34r01」に、「変数xを-4にする」（変数）をつなごう。 x がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q34r01」に、「もし 「ランダムな数字を選択: 0 から 1 まで」  =  1 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

5. 中の条件の「なら」に、「変数xを0にする」（変数）をつなごう。

6. 中のチャットコマンド「q34r01」に、「チェスト を~x ~0 ~13 に置く」（ブロック）をつなごう。

7. 緑の実行ボタンを押して、Tキーのチャットで q34r01 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q34r01", function () {
    let x = -4
    if (randint(0, 1) == 1) {
        x = 0
    }
    blocks.place(CHEST, pos(x, 0, 13))
})
```
