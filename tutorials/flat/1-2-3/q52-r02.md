## C11 Q52 R02 小麦を植える

**C11 Q52 R02 小麦を植える**

耕した土へ小麦の苗を植えよう。

完成するもの: Agentが耕して種を植える畑

学ぶこと: 条件（もし〜なら）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q52r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q52r02」に、「変数pointsを「配列を作成」に ~-2 ~-1 ~11、~-2 ~-1 ~12、~-2 ~-1 ~13、~-2 ~-1 ~14 を順に入れるにする」（変数）をつなごう。 points がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q52r02」に、「配列pointsの値を変数pointに入れてくりかえす」（ループ）をつなごう。

5. 中の配列pointsのくり返し（point）に、「エージェントを 「point + ~0 ~1 ~0」 へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

6. 中の配列pointsのくり返し（point）に、「エージェントに 下 を 耕させる」（エージェント）をつなごう。

7. 中の配列pointsのくり返し（point）に、「もし 「耕地 がpoint に存在する」 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 中の条件の「なら」に、「作物 を「point + ~0 ~1 ~0」 に置く」（ブロック）をつなごう。

9. 緑の実行ボタンを押して、Tキーのチャットで q52r02 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

player.onChat("q52r02", function () {
    let points = [pos(-2, -1, 11), pos(-2, -1, 12), pos(-2, -1, 13), pos(-2, -1, 14)]
    for (let point of points) {
        agent.teleport(positions.add(point, pos(0, 1, 0)), SOUTH)
        agent.till(DOWN)
        if (blocks.testForBlock(FARMLAND, point)) {
            blocks.place(CROPS, positions.add(point, pos(0, 1, 0)))
        }
    }
})
