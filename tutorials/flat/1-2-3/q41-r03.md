## C09 Q41 R03 面をまとめて点検する

**C09 Q41 R03 面をまとめて点検する**

丸石がないところを調べて直そう。

完成するもの: 穴のない石畳

学ぶこと: くり返し、直した数を数える

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を check_q41r03_1 にしよう。

3. 中の関数「check_q41r03_1」に、「変数repairedを0にする」（変数）をつなごう。 repaired がなければ「変数を追加する...」で作ろう。

4. 中の関数「check_q41r03_1」に、「変数pointsを「配列を作成」に ~-3 ~-1 ~12、~-3 ~-1 ~13、~-3 ~-1 ~14、~0 ~-1 ~12、~0 ~-1 ~13、~0 ~-1 ~14、~3 ~-1 ~12、~3 ~-1 ~13、~3 ~-1 ~14 を順に入れるにする」（変数）をつなごう。 points がなければ「変数を追加する...」で作ろう。

5. 中の関数「check_q41r03_1」に、「配列pointsの値を変数pointに入れてくりかえす」（ループ）をつなごう。

6. 中の配列pointsのくり返し（point）に、「もし 「丸石 がpoint に存在する」 ではない なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

7. 中の条件の「なら」に、「丸石 をpoint に置く」（ブロック）をつなごう。

8. 中の条件の「なら」に、「変数repairedを1だけ増やす」（変数）をつなごう。

9. 中の関数「check_q41r03_1」に、「戻る repaired」（関数）をつなごう。

10. 「チャットコマンド q41r03 を入力した時」（プレイヤー）を置こう。

11. 中のチャットコマンド「q41r03」に、「変数repairedを「呼び出し check_q41r03_1」にする」（変数）をつなごう。 repaired がなければ「変数を追加する...」で作ろう。

12. 中のチャットコマンド「q41r03」に、「メッセージ 「文字列をつなげる」に "直した数: " と repaired を入れる を 送信する」（プレイヤー）をつなごう。

13. 緑の実行ボタンを押して、Tキーのチャットで q41r03 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function check_q41r03_1(): number {
    let repaired = 0
    let points = [pos(-3, -1, 12), pos(-3, -1, 13), pos(-3, -1, 14), pos(0, -1, 12), pos(0, -1, 13), pos(0, -1, 14), pos(3, -1, 12), pos(3, -1, 13), pos(3, -1, 14)]
    for (let point of points) {
        if (!blocks.testForBlock(COBBLESTONE, point)) {
            blocks.place(COBBLESTONE, point)
            repaired += 1
        }
    }
    return repaired
}
player.onChat("q41r03", function () {
    let repaired = check_q41r03_1()
    player.say("直した数: " + repaired)
})

```
