## C05 Q25 R03 開く・閉じる

**C05 Q25 R03 開く・閉じる**

openで開いて判定し、closeで閉じてもう一度判定しよう。

完成するもの: 開く・閉じるを切り替える2つの水門

学ぶこと: 状態を記録する、関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前のコードは保存しておこう。この課題では新しいプロジェクトを使うよ。門を開く用と閉じる用のチャットコマンドを作ろう。

2. 「変数gateOriginを「プレイヤーの位置」にする」（変数）をつなごう。 gateOrigin がなければ「変数を追加する...」で作ろう。

3. 「変数gateReadyを偽にする」（変数）をつなごう。 gateReady がなければ「変数を追加する...」で作ろう。

4. 「関数を作成する...」（関数）で名前を gates_q25r03 にしよう。数字の入力を material の順で追加しよう。

5. 中の関数「gates_q25r03」に、「ブロックを並べる」（ブロック）をつなごう。materialを選び、「範囲の始まり」を 「gateOrigin + ~-4 ~0 ~13」、「範囲の終わり」を 「gateOrigin + ~-2 ~1 ~13」、「モード」を「置き換え (replace)」にしよう。

6. 中の関数「gates_q25r03」に、「ブロックを並べる」（ブロック）をつなごう。materialを選び、「範囲の始まり」を 「gateOrigin + ~2 ~0 ~13」、「範囲の終わり」を 「gateOrigin + ~4 ~1 ~13」、「モード」を「置き換え (replace)」にしよう。

7. 「チャットコマンド q25r03open を入力した時」（プレイヤー）を置こう。

8. 中のチャットコマンド「q25r03open」に、「変数gateOriginを「プレイヤーの位置」にする」（変数）をつなごう。

9. 中のチャットコマンド「q25r03open」に、「変数gateReadyを真にする」（変数）をつなごう。

10. 中のチャットコマンド「q25r03open」に、「もし gateReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

11. 中の条件の「なら」に、「呼び出し gates_q25r03」に 空気 を入れる（関数）をつなごう。

12. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

13. 中の「でなければ」に、「メッセージ "先に入口の金の床でopenを動かそう。" を 送信する」（プレイヤー）をつなごう。

14. 「チャットコマンド q25r03close を入力した時」（プレイヤー）を置こう。

15. 中のチャットコマンド「q25r03close」に、「もし gateReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

16. 中の条件の「なら」に、「呼び出し gates_q25r03」に ガラス を入れる（関数）をつなごう。

17. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

18. 中の「でなければ」に、「メッセージ "先に入口の金の床でopenを動かそう。" を 送信する」（プレイヤー）をつなごう。

19. 緑の実行ボタンを押して、Tキーのチャットで q25r03open と入力しよう。

20. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let gateOrigin = player.position()
let gateReady = false
function gates_q25r03(material: number) {
    blocks.fill(material, positions.add(gateOrigin, pos(-4, 0, 13)), positions.add(gateOrigin, pos(-2, 1, 13)), FillOperation.Replace)
    blocks.fill(material, positions.add(gateOrigin, pos(2, 0, 13)), positions.add(gateOrigin, pos(4, 1, 13)), FillOperation.Replace)
}
player.onChat("q25r03open", function () {
    gateOrigin = player.position()
    gateReady = true
    if (gateReady) {
        gates_q25r03(AIR)
    } else {
        player.say("先に入口の金の床でopenを動かそう。")
    }
})
player.onChat("q25r03close", function () {
    if (gateReady) {
        gates_q25r03(GLASS)
    } else {
        player.say("先に入口の金の床でopenを動かそう。")
    }
})

```
