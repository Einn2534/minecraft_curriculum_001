## C06 Q29 R03 操作する道具

**C06 Q29 R03 操作する道具**

棒を右クリックすると金の救助信号を出そう。

完成するもの: 色を選んで発信できる緊急信号旗

学ぶこと: 道具を使ったときのイベント、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「変数eventOriginを「プレイヤーの位置」にする」（変数）をつなごう。 eventOrigin がなければ「変数を追加する...」で作ろう。

3. 「変数eventReadyを偽にする」（変数）をつなごう。 eventReady がなければ「変数を追加する...」で作ろう。

4. 「チャットコマンド q29r03 を入力した時」（プレイヤー）を置こう。

5. 中のチャットコマンド「q29r03」に、「変数eventOriginを「プレイヤーの位置」にする」（変数）をつなごう。

6. 中のチャットコマンド「q29r03」に、「変数eventReadyを真にする」（変数）をつなごう。

7. 「次の棒|が使われた時」（プレイヤー）を、チャットコマンドの外に置こう。

8. 中のイベントに、「もし eventReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

9. 中の条件の「なら」に、「ブロックを並べる」（ブロック）をつなごう。金ブロックを選び、「範囲の始まり」を 「eventOrigin + ~2 ~4 ~13」、「範囲の終わり」を 「eventOrigin + ~3 ~4 ~13」、「モード」を「置き換え (replace)」にしよう。

10. 緑の実行ボタンを押して、Tキーのチャットで q29r03 と入力しよう。

11. 入口の金の床で、用意した棒を持って右クリックしよう。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q29r03", function () {
    eventOrigin = player.position()
    eventReady = true
})
player.onItemInteracted(STICK, function () {
    if (eventReady) {
        blocks.fill(GOLD_BLOCK, positions.add(eventOrigin, pos(2, 4, 13)), positions.add(eventOrigin, pos(3, 4, 13)), FillOperation.Replace)
    }
})

```
