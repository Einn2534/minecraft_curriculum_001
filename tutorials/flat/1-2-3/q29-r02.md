## C06 Q29 R02 色を選ぶ

**C06 Q29 R02 色を選ぶ**

チャットの数字で赤・黄・青の信号を選ぼう。

完成するもの: 色を選んで発信できる緊急信号旗

学ぶこと: 条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q29r02 を入力した時」（プレイヤー）を置こう。＋で数字の入力「signal」を追加しよう。

3. 中のチャットコマンド「q29r02」に、「変数colorを赤色の羊毛にする」（変数）をつなごう。 color がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q29r02」に、「もし signal  =  2 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

5. 中の条件の「なら」に、「変数colorを黄色の羊毛にする」（変数）をつなごう。

6. 中のチャットコマンド「q29r02」に、「でなければもし signal  =  3 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

7. 中の条件の「なら」に、「変数colorを青色の羊毛にする」（変数）をつなごう。

8. 中のチャットコマンド「q29r02」に、「ブロックを並べる」（ブロック）をつなごう。colorを選び、「範囲の始まり」を ~1 ~3 ~13、「範囲の終わり」を ~4 ~5 ~13、「モード」を「置き換え (replace)」にしよう。

9. 緑の実行ボタンを押して、Tキーのチャットで q29r02 2 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q29r02", function (signal) {
    let color = RED_WOOL
    if (signal == 2) {
        color = YELLOW_WOOL
    } else if (signal == 3) {
        color = BLUE_WOOL
    }
    blocks.fill(color, pos(1, 3, 13), pos(4, 5, 13), FillOperation.Replace)
})

```
