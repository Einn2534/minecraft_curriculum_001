## C04 Q20 R01 時計塔

**C04 Q20 R01 時計塔**

石の塔に金の時計の針を付けよう。

完成するもの: 時刻を読み、同じ色の表示を出す中央と左右の時計塔

学ぶこと: くり返し、高さ

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q20r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q20r01」に、「ブロックを並べる」（ブロック）をつなごう。石レンガを選び、「範囲の始まり」を ~-2 ~0 ~13、「範囲の終わり」を ~2 ~4 ~14、「モード」を「置き換え (replace)」にしよう。

4. 中のチャットコマンド「q20r01」に、「変数yを0～2に変えてくりかえす」（ループ）をつなごう。

5. 中のくり返し（y）に、「金ブロック を~0 ~(y + 3) - 1 ~12 に置く」（ブロック）をつなごう。

6. 緑の実行ボタンを押して、Tキーのチャットで q20r01 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q20r01", function () {
    blocks.fill(STONE_BRICKS, pos(-2, 0, 13), pos(2, 4, 14), FillOperation.Replace)
    for (let y = 0; y <= 2; y++) {
        blocks.place(GOLD_BLOCK, pos(0, (y + 3) - 1, 3 + 9))
    }
})

```
