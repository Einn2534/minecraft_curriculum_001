## C11 Q51 R02 面積を計算

**C11 Q51 R02 面積を計算**

幅5・長さ4の区画を作り、同じ変数で面積を計算して伝えよう。

完成するもの: 面積を計算して区画を作る畑

学ぶこと: 変数（数を入れる箱）、二重のくり返し、かけ算

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q51r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q51r02」に、「変数widthを5にする」（変数）をつなごう。 width がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q51r02」に、「変数lengthを4にする」（変数）をつなごう。 length がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q51r02」に、「変数startXを-3にする」（変数）をつなごう。 startX がなければ「変数を追加する...」で作ろう。

6. 中のチャットコマンド「q51r02」に、「変数startZを2にする」（変数）をつなごう。 startZ がなければ「変数を追加する...」で作ろう。

7. 中のチャットコマンド「q51r02」に、「変数rowを0～length - 1に変えてくりかえす」（ループ）をつなごう。

8. 中のくり返し（row）に、「変数columnを0～width - 1に変えてくりかえす」（ループ）をつなごう。

9. 中のくり返し（column）に、「土 を~startX + column ~-1 ~startZ + row + 9 に置く」（ブロック）をつなごう。

10. 中のチャットコマンド「q51r02」に、「メッセージ 「文字列をつなげる」に "面積: " と (width * length) を入れる を 送信する」（プレイヤー）をつなごう。

11. 緑の実行ボタンを押して、Tキーのチャットで q51r02 と入力しよう。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q51r02", function () {
    let width = 5
    let length = 4
    let startX = -3
    let startZ = 2
    for (let row = 0; row < length; row++) {
        for (let column = 0; column < width; column++) {
            blocks.place(DIRT, pos(startX + column, -1, startZ + row + 9))
        }
    }
    player.say("面積: " + (width * length))
})

```
