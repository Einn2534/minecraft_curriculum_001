## C02 Q07 R02 鐘を並べる

**C02 Q07 R02 鐘を並べる**

音符ブロックを5個並べて、チャットから鐘の音を鳴らそう。

完成するもの: 音符ブロックが並ぶ鐘楼とチャットで鳴る旋律

学ぶこと: くり返し、音を鳴らす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q07r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q07r02」に、「変数xを0～4に変えてくりかえす」（ループ）をつなごう。

4. 中のくり返し（x）に、「音符ブロック を~(x + -2) ~1 ~12 に置く」（ブロック）をつなごう。

5. 中のチャットコマンド「q07r02」に、「変数noteを0～2に変えてくりかえす」（ループ）をつなごう。

6. 中のくり返し（note）に、「コマンド 「文字列をつなげる」に "playsound note.bell @s ~ ~ ~ 1 " と (1 + (note % 3)) を入れる を 実行する」（プレイヤー）をつなごう。

7. 中のくり返し（note）に、「一時停止（ミリ秒） 300」（ループ）をつなごう。

8. 緑の実行ボタンを押して、Tキーのチャットで q07r02 と入力しよう。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q07r02", function () {
    for (let x = 0; x <= 4; x++) {
        blocks.place(NOTE_BLOCK, pos((x + -2), 2 - 1, 3 + 9))
    }
    for (let note = 0; note < 3; note++) {
        player.execute("playsound note.bell @s ~ ~ ~ 1 " + (1 + (note % 3)))
        loops.pause(300)
    }
})

```
