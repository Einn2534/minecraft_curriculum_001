## C11 Q53 R02 支流をつなぐ

**C11 Q53 R02 支流をつなぐ**

水路から左右の支流をつなごう。

完成するもの: 畑へ水を届ける灌漑路

学ぶこと: 関数（まとめた手順）、座標、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を part_q53r02_1 にしよう。

3. 中の関数「part_q53r02_1」に、「ブロックを並べる」（ブロック）をつなごう。水を選び、「範囲の始まり」を ~-3 ~-1 ~13、「範囲の終わり」を ~3 ~-1 ~13、「モード」を「置き換え (replace)」にしよう。

4. 「チャットコマンド q53r02 を入力した時」（プレイヤー）を置こう。

5. 中のチャットコマンド「q53r02」に、「呼び出し part_q53r02_1」（関数）をつなごう。

6. 緑の実行ボタンを押して、Tキーのチャットで q53r02 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function part_q53r02_1() {
    blocks.fill(WATER, pos(-3, -1, 13), pos(3, -1, 13), FillOperation.Replace)
}
player.onChat("q53r02", function () {
    part_q53r02_1()
})

```
