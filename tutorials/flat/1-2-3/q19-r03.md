## C04 Q19 R03 2つのグループ

**C04 Q19 R03 2つのグループ**

村人とニワトリを別々に呼び、人数と頭数の合計をグラフと照らし合わせよう。

完成するもの: 呼んだ人数と金の棒グラフを照らし合わせる市民調査所

学ぶこと: 配列（順番のあるリスト）、集計・足し算

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q19r03 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q19r03」に、「「ある位置から一定の範囲内にいる「すべての ニワトリ」 位置~5 ~0 ~13 半径3」」（モブ）をつなごう。

4. 中のチャットコマンド「q19r03」に、「変数countを2にする」（変数）をつなごう。 count がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q19r03」に、「くりかえしcount回」（ループ）をつなごう。

6. 中のcount回のくり返しに、「ニワトリ を~5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

7. 中のチャットコマンド「q19r03」に、「変数groupsを「配列を作成」に 3、2 を順に入れるにする」（変数）をつなごう。 groups がなければ「変数を追加する...」で作ろう。

8. 中のチャットコマンド「q19r03」に、「変数totalを0にする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

9. 中のチャットコマンド「q19r03」に、「配列groupsの値を変数groupに入れてくりかえす」（ループ）をつなごう。

10. 中の配列groupsのくり返し（group）に、「変数totalをgroupだけ増やす」（変数）をつなごう。

11. 中のチャットコマンド「q19r03」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

12. 中のくり返し（item）に、「金ブロック を~0 + item ~0 ~10 に置く」（ブロック）をつなごう。

13. 緑の実行ボタンを押して、Tキーのチャットで q19r03 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q19r03", function () {
    mobs.kill(mobs.near(mobs.entitiesByType(CHICKEN), pos(5, 0, 13), 3))
    let count = 2
    for (let number = 0; number < count; number++) {
        mobs.spawn(CHICKEN, pos(5, 0, 13))
    }
    let groups = [3, 2]
    let total = 0
    for (let group of groups) {
        total += group
    }
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(0 + item, 0, 10))
    }
})

```
