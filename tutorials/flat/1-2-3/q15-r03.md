## C03 Q15 R03 印刷する手順をまとめる

**C03 Q15 R03 印刷する手順をまとめる**

表示板に「AR」の形を描こう。見本の足りないくり返しと位置を直そう。

完成するもの: 直した魔導書の文字

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を print_q15r03 にしよう。数字の入力を startX の順で追加しよう。

3. 中の関数「print_q15r03」に、「ブロックを並べる」（ブロック）をつなごう。空気を選び、「範囲の始まり」を ~-6 ~1 ~14、「範囲の終わり」を ~6 ~6 ~14、「モード」を「置き換え (replace)」にしよう。

4. 中の関数「print_q15r03」に、「変数lettersを「配列を作成」に "0100110"、"1010101"、"1110110"、"1010101"、"1010101" を順に入れるにする」（変数）をつなごう。 letters がなければ「変数を追加する...」で作ろう。

5. 中の関数「print_q15r03」に、「変数rowを0～「配列の長さ letters」 - 1に変えてくりかえす」（ループ）をつなごう。

6. 中のくり返し（row）に、「変数columnを0～「「文字列lettersのrow番目の値」の長さ」 - 1に変えてくりかえす」（ループ）をつなごう。

7. 中のくり返し（column）に、「もし 「文字列 「lettersのrow番目の値」 の column 番目の文字」  =  "1" なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 中の条件の「なら」に、「金ブロック を~startX + column ~5 - row ~14 に置く」（ブロック）をつなごう。

9. 「チャットコマンド q15r03 を入力した時」（プレイヤー）を置こう。

10. 中のチャットコマンド「q15r03」に、「呼び出し print_q15r03」に -6 を入れる（関数）をつなごう。

11. 中のチャットコマンド「q15r03」に、「ブロックを並べる」（ブロック）をつなごう。オークの板材を選び、「範囲の始まり」を ~-7 ~0 ~14、「範囲の終わり」を ~6 ~0 ~14、「モード」を「置き換え (replace)」にしよう。

12. 緑の実行ボタンを押して、Tキーのチャットで q15r03 と入力しよう。

13. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

デバッグは、間違いを見つけて直すことだよ。下のブロック見本は、最後の列が足りず、高さも1段ずれているよ。まず試して、くり返しの終わりと高さを直そう。電球に直した完成例があるよ。

```blocks
function print_q15r03(startX: number) {
    blocks.fill(AIR, pos(-6, 1, 14), pos(6, 6, 14), FillOperation.Replace)
    let letters = ["0100110", "1010101", "1110110", "1010101", "1010101"]
    for (let row = 0; row < letters.length; row++) {
        for (let column = 0; column < letters[row].length - 1; column++) {
            if (letters[row].charAt(column) == "1") {
                blocks.place(GOLD_BLOCK, pos(startX + column, 6 - row, 14))
            }
        }
    }
}
player.onChat("q15r03", function () {
    print_q15r03(-6)
    blocks.fill(PLANKS_OAK, pos(-7, 0, 14), pos(6, 0, 14), FillOperation.Replace)
})
```
