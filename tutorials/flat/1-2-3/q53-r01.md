## C11 Q53 R01 水路を掘る

**C11 Q53 R01 水路を掘る**

土を掘って、畑の横に水路を作ろう。

完成するもの: 畑へ水を届ける灌漑路

学ぶこと: くり返し、土を水へ変える

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q53r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q53r01」に、「変数zを0～6に変えてくりかえす」（ループ）をつなごう。

4. 中のくり返し（z）に、「水 を~-3 ~-1 ~(z + 1) + 9 に置く」（ブロック）をつなごう。

5. 緑の実行ボタンを押して、Tキーのチャットで q53r01 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q53r01", function () {
    for (let z = 0; z <= 6; z++) {
        blocks.place(WATER, pos(-3, 0 - 1, (z + 1) + 9))
    }
})

```
