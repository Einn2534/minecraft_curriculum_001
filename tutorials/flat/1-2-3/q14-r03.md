## C03 Q14 R03 予報パネル

**C03 Q14 R03 予報パネル**

天候の色を3か所へ表示して、観測台を完成させよう。

完成するもの: 天候を読み、晴れ・雨・雷を色で表示する気象台

学ぶこと: 条件（もし〜なら）、関数（まとめた手順）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を part_q14r03_2 にしよう。

3. 中の関数「part_q14r03_2」に、「ブロックを並べる」（ブロック）をつなごう。オークの板材を選び、「範囲の始まり」を ~-3 ~4 ~12、「範囲の終わり」を ~3 ~4 ~14、「モード」を「置き換え (replace)」にしよう。

4. 「チャットコマンド q14r03 を入力した時」（プレイヤー）を置こう。

5. 中のチャットコマンド「q14r03」に、「変数valueを「現在の天気」にする」（変数）をつなごう。 value がなければ「変数を追加する...」で作ろう。

6. 中のチャットコマンド「q14r03」に、「変数colorを金ブロックにする」（変数）をつなごう。 color がなければ「変数を追加する...」で作ろう。

7. 中のチャットコマンド「q14r03」に、「もし value  =  Weather.Rain なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 中の条件の「なら」に、「変数colorを青色の羊毛にする」（変数）をつなごう。

9. 中のチャットコマンド「q14r03」に、「でなければもし value  =  Weather.Thunder なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

10. 中の条件の「なら」に、「変数colorを赤色の羊毛にする」（変数）をつなごう。

11. 中のチャットコマンド「q14r03」に、「変数displaysを「配列を作成」に -1、0、1 を順に入れるにする」（変数）をつなごう。 displays がなければ「変数を追加する...」で作ろう。

12. 中のチャットコマンド「q14r03」に、「配列displaysの値を変数xに入れてくりかえす」（ループ）をつなごう。

13. 中の配列displaysのくり返し（x）に、「color を~x ~3 ~12 に置く」（ブロック）をつなごう。

14. 中のチャットコマンド「q14r03」に、「メッセージ 「文字列をつなげる」に "今の値: " と value を入れる を 送信する」（プレイヤー）をつなごう。

15. 中のチャットコマンド「q14r03」に、「呼び出し part_q14r03_2」（関数）をつなごう。

16. 緑の実行ボタンを押して、Tキーのチャットで q14r03 と入力しよう。

17. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function part_q14r03_2() {
    blocks.fill(PLANKS_OAK, pos(-3, 4, 12), pos(3, 4, 14), FillOperation.Replace)
}
player.onChat("q14r03", function () {
    let value = gameplay.weatherQuery()
    let color = GOLD_BLOCK
    if (value == Weather.Rain) {
        color = BLUE_WOOL
    } else if (value == Weather.Thunder) {
        color = RED_WOOL
    }
    let displays = [-1, 0, 1]
    for (let x of displays) {
        blocks.place(color, pos(x, 3, 12))
    }
    player.say("今の値: " + value)
    part_q14r03_2()
})

```
