## C02 Q10 R03 3区間の迷宮の出口

**C02 Q10 R03 3区間の迷宮の出口**

自分を曲がり角に沿って金のゴールへ動かそう。

完成するもの: 迷宮の出口の道とゴール

学ぶこと: 配列（順番のあるリスト）、座標を足す、関数（まとめた手順）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を travel_q10r03 にしよう。

3. 中の関数「travel_q10r03」に、「変数originを「プレイヤーの位置」にする」（変数）をつなごう。 origin がなければ「変数を追加する...」で作ろう。

4. 中の関数「travel_q10r03」に、「変数destinationsを「配列を作成」に ~-6 ~0 ~14、~6 ~0 ~14、~6 ~0 ~16 を順に入れるにする」（変数）をつなごう。 destinations がなければ「変数を追加する...」で作ろう。

5. 中の関数「travel_q10r03」に、「配列destinationsの値を変数destinationに入れてくりかえす」（ループ）をつなごう。

6. 中の配列destinationsのくり返し（destination）に、「「origin + destination」 にテレポートする」（プレイヤー）をつなごう。

7. 「チャットコマンド q10r03 を入力した時」（プレイヤー）を置こう。

8. 中のチャットコマンド「q10r03」に、「呼び出し travel_q10r03」（関数）をつなごう。

9. 中のチャットコマンド「q10r03」に、「コマンド "function grandfort/course/arrival/r030" を 実行する」（プレイヤー）をつなごう。

10. 緑の実行ボタンを押して、Tキーのチャットで q10r03 と入力しよう。

11. 「ゴールに到着！」が出たら、緑の道で工房NPCへ戻ろう。到着の記録は残るよ。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function travel_q10r03() {
    let origin = player.position()
    let destinations = [pos(-6, 0, 14), pos(6, 0, 14), pos(6, 0, 16)]
    for (let destination of destinations) {
        player.teleport(positions.add(origin, destination))
    }
}
player.onChat("q10r03", function () {
    travel_q10r03()
    player.execute("function grandfort/course/arrival/r030")
})

```
