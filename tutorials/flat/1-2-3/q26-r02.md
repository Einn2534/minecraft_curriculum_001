## C06 Q26 R02 列を点検する

**C06 Q26 R02 列を点検する**

石レンガがないところを調べて直そう。

完成するもの: 穴と弱い部分を直した城壁

学ぶこと: 条件（もし〜なら）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q26r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q26r02」に、「変数pointsを「配列を作成」に ~-2 ~0 ~12、~-2 ~1 ~12、~0 ~0 ~12、~0 ~1 ~12、~2 ~0 ~12、~2 ~1 ~12 を順に入れるにする」（変数）をつなごう。 points がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q26r02」に、「配列pointsの値を変数pointに入れてくりかえす」（ループ）をつなごう。

5. 中の配列pointsのくり返し（point）に、「もし 「石レンガ がpoint に存在する」 ではない なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 中の条件の「なら」に、「石レンガ をpoint に置く」（ブロック）をつなごう。

7. 緑の実行ボタンを押して、Tキーのチャットで q26r02 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q26r02", function () {
    let points = [pos(-2, 0, 12), pos(-2, 1, 12), pos(0, 0, 12), pos(0, 1, 12), pos(2, 0, 12), pos(2, 1, 12)]
    for (let point of points) {
        if (!blocks.testForBlock(STONE_BRICKS, point)) {
            blocks.place(STONE_BRICKS, point)
        }
    }
})

```
