## C11 Q54 R02 同じ間隔の木

**C11 Q54 R02 同じ間隔の木**

間隔4で2本目の木を作ろう。

完成するもの: 間隔を計算して植える王立果樹園

学ぶこと: かけ算で間隔を計算、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q54r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q54r02」に、「変数gapを4にする」（変数）をつなごう。 gap がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q54r02」に、「変数treeNumberを1にする」（変数）をつなごう。 treeNumber がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q54r02」に、「変数treeXを-4 + gap * treeNumberにする」（変数）をつなごう。 treeX がなければ「変数を追加する...」で作ろう。

6. 中のチャットコマンド「q54r02」に、「ブロックを並べる」（ブロック）をつなごう。オークの原木を選び、「範囲の始まり」を ~treeX ~0 ~12、「範囲の終わり」を ~treeX ~3 ~12、「モード」を「置き換え (replace)」にしよう。

7. 中のチャットコマンド「q54r02」に、「ビルダー: 位置 ~treeX - 1 ~4 ~11 へテレポート」（ビルダー）をつなごう。

8. 中のチャットコマンド「q54r02」に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

9. 中のチャットコマンド「q54r02」に、「ビルダー: 位置 ~treeX + 1 ~5 ~13 へテレポート」（ビルダー）をつなごう。

10. 中のチャットコマンド「q54r02」に、「ビルダー: 印を付けた場所からブロック 樫の葉 で埋める」（ビルダー）をつなごう。

11. 緑の実行ボタンを押して、Tキーのチャットで q54r02 と入力しよう。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q54r02", function () {
    let gap = 4
    let treeNumber = 1
    let treeX = -4 + gap * treeNumber
    blocks.fill(LOG_OAK, pos(treeX, 0, 12), pos(treeX, 3, 12), FillOperation.Replace)
    builder.teleportTo(pos(treeX - 1, 4, 11))
    builder.mark()
    builder.teleportTo(pos(treeX + 1, 5, 13))
    builder.fill(LEAVES_OAK)
})

```
