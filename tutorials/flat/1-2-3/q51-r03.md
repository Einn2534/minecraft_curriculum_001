## C11 Q51 R03 道と2区画

**C11 Q51 R03 道と2区画**

幅と長さを引数にした関数で、道を挟んだ2つの畑を作ろう。

完成するもの: 面積を計算して区画を作る畑

学ぶこと: 関数（まとめた手順）と引数、二重のくり返し

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を plot_q51r03 にしよう。数字の入力を width、length、startX、startZ の順で追加しよう。

3. 中の関数「plot_q51r03」に、「変数rowを0～length - 1に変えてくりかえす」（ループ）をつなごう。

4. 中のくり返し（row）に、「変数columnを0～width - 1に変えてくりかえす」（ループ）をつなごう。

5. 中のくり返し（column）に、「土 を~startX + column ~-1 ~startZ + row + 9 に置く」（ブロック）をつなごう。

6. 「関数を作成する...」（関数）で名前を part_q51r03_3 にしよう。

7. 中の関数「part_q51r03_3」に、「ブロックを並べる」（ブロック）をつなごう。丸石を選び、「範囲の始まり」を ~2 ~-1 ~10、「範囲の終わり」を ~2 ~-1 ~15、「モード」を「置き換え (replace)」にしよう。

8. 「チャットコマンド q51r03 を入力した時」（プレイヤー）を置こう。

9. 中のチャットコマンド「q51r03」に、「呼び出し plot_q51r03」に 5、4、-3、2 を入れる（関数）をつなごう。

10. 中のチャットコマンド「q51r03」に、「呼び出し plot_q51r03」に 3、4、3、2 を入れる（関数）をつなごう。

11. 中のチャットコマンド「q51r03」に、「呼び出し part_q51r03_3」（関数）をつなごう。

12. 緑の実行ボタンを押して、Tキーのチャットで q51r03 と入力しよう。

13. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function plot_q51r03(width: number, length: number, startX: number, startZ: number) {
    for (let row = 0; row < length; row++) {
        for (let column = 0; column < width; column++) {
            blocks.place(DIRT, pos(startX + column, -1, startZ + row + 9))
        }
    }
}
function part_q51r03_3() {
    blocks.fill(COBBLESTONE, pos(2, -1, 10), pos(2, -1, 15), FillOperation.Replace)
}
player.onChat("q51r03", function () {
    plot_q51r03(5, 4, -3, 2)
    plot_q51r03(3, 4, 3, 2)
    part_q51r03_3()
})

```
