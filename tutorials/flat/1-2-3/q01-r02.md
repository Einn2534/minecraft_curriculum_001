## C01 Q01 R02 旗の布を広げよう

**C01 Q01 R02 旗の布を広げよう**

旗柱の右に、赤い旗の布と青いふちを付けよう。

完成するもの: 旗柱・赤い旗・金の王家の印がついた王旗

学ぶこと: 高さと横の位置、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q01r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q01r02」に、「ブロックを並べる」（ブロック）をつなごう。赤色の羊毛を選び、「範囲の始まり」を ~1 ~4 ~12、「範囲の終わり」を ~4 ~6 ~12、「モード」を「置き換え (replace)」にしよう。

4. 中のチャットコマンド「q01r02」に、「ブロックを並べる」（ブロック）をつなごう。青色の羊毛を選び、「範囲の始まり」を ~1 ~3 ~12、「範囲の終わり」を ~4 ~3 ~12、「モード」を「置き換え (replace)」にしよう。

5. 緑の実行ボタンを押して、Tキーのチャットで q01r02 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q01r02", function () {
    blocks.fill(RED_WOOL, pos(1, 4, 12), pos(4, 6, 12), FillOperation.Replace)
    blocks.fill(BLUE_WOOL, pos(1, 3, 12), pos(4, 3, 12), FillOperation.Replace)
})

```
