## C12 Q58 R02 親を2組

**C12 Q58 R02 親を2組**

牛を4頭にし、2組分のえさ置き場を用意しよう。

完成するもの: 親の組数と必要なえさを計算する繁殖計画の牧場

学ぶこと: 変数（数を入れる箱）、割り算・組数

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q58r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q58r02」に、「「ある位置から一定の範囲内にいる「すべての ウシ」 位置~-5 ~0 ~13 半径3」」（モブ）をつなごう。

4. 中のチャットコマンド「q58r02」に、「変数countを4にする」（変数）をつなごう。 count がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q58r02」に、「くりかえしcount回」（ループ）をつなごう。

6. 中のcount回のくり返しに、「ウシ を~-5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

7. 中のチャットコマンド「q58r02」に、「変数headsを4にする」（変数）をつなごう。 heads がなければ「変数を追加する...」で作ろう。

8. 中のチャットコマンド「q58r02」に、「変数totalを「整数の÷」に heads と 2 を入れるにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

9. 中のチャットコマンド「q58r02」に、「メッセージ 「文字列をつなげる」に "組に入らない頭数: " と (heads % 2) を入れる を 送信する」（プレイヤー）をつなごう。

10. 中のチャットコマンド「q58r02」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

11. 中のくり返し（item）に、「金ブロック を~2 + item ~0 ~11 に置く」（ブロック）をつなごう。

12. 中のチャットコマンド「q58r02」に、「変数xを0～1に変えてくりかえす」（ループ）をつなごう。

13. 中のくり返し（x）に、「干草の俵 を~(x + 3) ~0 ~12 に置く」（ブロック）をつなごう。

14. 緑の実行ボタンを押して、Tキーのチャットで q58r02 と入力しよう。

15. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q58r02", function () {
    mobs.kill(mobs.near(mobs.entitiesByType(COW), pos(-5, 0, 13), 3))
    let count = 4
    for (let number = 0; number < count; number++) {
        mobs.spawn(COW, pos(-5, 0, 13))
    }
    let heads = 4
    let total = Math.idiv(heads, 2)
    player.say("組に入らない頭数: " + (heads % 2))
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(2 + item, 0, 11))
    }
    for (let x = 0; x <= 1; x++) {
        blocks.place(HAY_BLOCK, pos((x + 3), 1 - 1, 3 + 9))
    }
})

```
