## C05 Q23 R02 列で分ける

**C05 Q23 R02 列で分ける**

見本の金と鉄を調べ、同じ種類を右の棚に分けよう。

完成するもの: 色と素材で分けた倉庫

学ぶこと: 条件（もし〜なら）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q23r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q23r02」に、「変数pointsを「配列を作成」に ~-5 ~0 ~10、~-5 ~0 ~11、~-5 ~0 ~12 を順に入れるにする」（変数）をつなごう。 points がなければ「変数を追加する...」で作ろう。

4. 中のチャットコマンド「q23r02」に、「配列pointsの値を変数pointに入れてくりかえす」（ループ）をつなごう。

5. 中の配列pointsのくり返し（point）に、「もし 「金ブロック がpoint に存在する」 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 中の条件の「なら」に、「金ブロック を~4 ~0 ~「point の z(南北) 座標」 に置く」（ブロック）をつなごう。

7. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

8. 中の「でなければ」に、「鉄ブロック を~4 ~0 ~「point の z(南北) 座標」 に置く」（ブロック）をつなごう。

9. 緑の実行ボタンを押して、Tキーのチャットで q23r02 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q23r02", function () {
    let points = [pos(-5, 0, 10), pos(-5, 0, 11), pos(-5, 0, 12)]
    for (let point of points) {
        if (blocks.testForBlock(GOLD_BLOCK, point)) {
            blocks.place(GOLD_BLOCK, pos(4, 0, point.getValue(Axis.Z)))
        } else {
            blocks.place(IRON_BLOCK, pos(4, 0, point.getValue(Axis.Z)))
        }
    }
})

```
