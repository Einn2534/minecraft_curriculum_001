## C02 Q07 R03 旋律をくり返す

**C02 Q07 R03 旋律をくり返す**

鐘楼の屋根を付け、3つの高さの音を2回鳴らそう。

完成するもの: 音符ブロックが並ぶ鐘楼とチャットで鳴る旋律

学ぶこと: 関数（まとめた手順）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を part_q07r03_1 にしよう。

3. 中の関数「part_q07r03_1」に、「ブロックを並べる」（ブロック）をつなごう。オークの板材を選び、「範囲の始まり」を ~-3 ~3 ~12、「範囲の終わり」を ~3 ~3 ~12、「モード」を「置き換え (replace)」にしよう。

4. 「チャットコマンド q07r03 を入力した時」（プレイヤー）を置こう。

5. 中のチャットコマンド「q07r03」に、「呼び出し part_q07r03_1」（関数）をつなごう。

6. 中のチャットコマンド「q07r03」に、「変数melodyを「配列を作成」に 1、2、3 を順に入れるにする」（変数）をつなごう。 melody がなければ「変数を追加する...」で作ろう。

7. 中のチャットコマンド「q07r03」に、「くりかえし2回」（ループ）をつなごう。

8. 中の2回のくり返しに、「配列melodyの値を変数pitchに入れてくりかえす」（ループ）をつなごう。

9. 中の配列melodyのくり返し（pitch）に、「コマンド 「文字列をつなげる」に "playsound note.bell @s ~ ~ ~ 1 " と pitch を入れる を 実行する」（プレイヤー）をつなごう。

10. 中の配列melodyのくり返し（pitch）に、「一時停止（ミリ秒） 300」（ループ）をつなごう。

11. 中のチャットコマンド「q07r03」に、「ブロックを並べる」（ブロック）をつなごう。オークの原木を選び、「範囲の始まり」を ~-3 ~1 ~12、「範囲の終わり」を ~-3 ~2 ~12、「モード」を「置き換え (replace)」にしよう。

12. 中のチャットコマンド「q07r03」に、「ブロックを並べる」（ブロック）をつなごう。オークの原木を選び、「範囲の始まり」を ~3 ~1 ~12、「範囲の終わり」を ~3 ~2 ~12、「モード」を「置き換え (replace)」にしよう。

13. 緑の実行ボタンを押して、Tキーのチャットで q07r03 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function part_q07r03_1() {
    blocks.fill(PLANKS_OAK, pos(-3, 3, 12), pos(3, 3, 12), FillOperation.Replace)
}
player.onChat("q07r03", function () {
    part_q07r03_1()
    let melody = [1, 2, 3]
    for (let times = 0; times < 2; times++) {
        for (let pitch of melody) {
            player.execute("playsound note.bell @s ~ ~ ~ 1 " + pitch)
            loops.pause(300)
        }
    }
    blocks.fill(LOG_OAK, pos(-3, 1, 12), pos(-3, 2, 12), FillOperation.Replace)
    blocks.fill(LOG_OAK, pos(3, 1, 12), pos(3, 2, 12), FillOperation.Replace)
})

```
