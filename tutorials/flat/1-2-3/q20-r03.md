## C04 Q20 R03 時計をそろえる

**C04 Q20 R03 時計をそろえる**

真ん中と左右の小さな時計を同じ時刻の色にそろえよう。

完成するもの: 時刻を読み、同じ色の表示を出す中央と左右の時計塔

学ぶこと: 関数（まとめた手順）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「関数を作成する...」（関数）で名前を part_q20r03_2 にしよう。

3. 中の関数「part_q20r03_2」に、「ブロックを並べる」（ブロック）をつなごう。石レンガを選び、「範囲の始まり」を ~-4 ~0 ~13、「範囲の終わり」を ~-4 ~2 ~13、「モード」を「置き換え (replace)」にしよう。

4. 「関数を作成する...」（関数）で名前を part_q20r03_3 にしよう。

5. 中の関数「part_q20r03_3」に、「ブロックを並べる」（ブロック）をつなごう。石レンガを選び、「範囲の始まり」を ~4 ~0 ~13、「範囲の終わり」を ~4 ~2 ~13、「モード」を「置き換え (replace)」にしよう。

6. 「チャットコマンド q20r03 を入力した時」（プレイヤー）を置こう。

7. 中のチャットコマンド「q20r03」に、「変数valueを「現在の時間」にする」（変数）をつなごう。 value がなければ「変数を追加する...」で作ろう。

8. 中のチャットコマンド「q20r03」に、「変数colorを白色の羊毛にする」（変数）をつなごう。 color がなければ「変数を追加する...」で作ろう。

9. 中のチャットコマンド「q20r03」に、「もし value >= 12000 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

10. 中の条件の「なら」に、「変数colorを青色の羊毛にする」（変数）をつなごう。

11. 中のチャットコマンド「q20r03」に、「変数displaysを「配列を作成」に -4、0、4 を順に入れるにする」（変数）をつなごう。 displays がなければ「変数を追加する...」で作ろう。

12. 中のチャットコマンド「q20r03」に、「配列displaysの値を変数xに入れてくりかえす」（ループ）をつなごう。

13. 中の配列displaysのくり返し（x）に、「color を~x ~1 ~12 に置く」（ブロック）をつなごう。

14. 中のチャットコマンド「q20r03」に、「メッセージ 「文字列をつなげる」に "今の値: " と value を入れる を 送信する」（プレイヤー）をつなごう。

15. 中のチャットコマンド「q20r03」に、「呼び出し part_q20r03_2」（関数）をつなごう。

16. 中のチャットコマンド「q20r03」に、「呼び出し part_q20r03_3」（関数）をつなごう。

17. 緑の実行ボタンを押して、Tキーのチャットで q20r03 と入力しよう。

18. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

function part_q20r03_2() {
    blocks.fill(STONE_BRICKS, pos(-4, 0, 13), pos(-4, 2, 13), FillOperation.Replace)
}
function part_q20r03_3() {
    blocks.fill(STONE_BRICKS, pos(4, 0, 13), pos(4, 2, 13), FillOperation.Replace)
}
player.onChat("q20r03", function () {
    let value = gameplay.timeQuery(TimeQuery.DayTime)
    let color = WOOL
    if (value >= 12000) {
        color = BLUE_WOOL
    }
    let displays = [-4, 0, 4]
    for (let x of displays) {
        blocks.place(color, pos(x, 1, 12))
    }
    player.say("今の値: " + value)
    part_q20r03_2()
    part_q20r03_3()
})
