## C07 Q31 R01 床とカウンター

**C07 Q31 R01 床とカウンター**

変数で幅を決め、床とカウンターを作ろう。

完成するもの: カウンターと屋根のある露店

学ぶこと: 変数（数を入れる箱）、Builder、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q31r01 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q31r01」に、「ビルダー: 位置 ~-3 ~0 ~10 へテレポート」（ビルダー）をつなごう。

4. 中のチャットコマンド「q31r01」に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

5. 中のチャットコマンド「q31r01」に、「変数widthを7にする」（変数）をつなごう。 width がなければ「変数を追加する...」で作ろう。

6. 中のチャットコマンド「q31r01」に、「ビルダー: 位置 ~-3 + width - 1 ~0 ~15 へテレポート」（ビルダー）をつなごう。

7. 中のチャットコマンド「q31r01」に、「ビルダー: 印を付けた場所からブロック オークの板材 で埋める」（ビルダー）をつなごう。

8. 中のチャットコマンド「q31r01」に、「ブロックを並べる」（ブロック）をつなごう。石レンガを選び、「範囲の始まり」を ~-2 ~1 ~11、「範囲の終わり」を ~2 ~1 ~11、「モード」を「置き換え (replace)」にしよう。

9. 緑の実行ボタンを押して、Tキーのチャットで q31r01 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q31r01", function () {
    builder.teleportTo(pos(-3, 0, 10))
    builder.mark()
    let width = 7
    builder.teleportTo(pos(-3 + width - 1, 0, 15))
    builder.fill(PLANKS_OAK)
    blocks.fill(STONE_BRICKS, pos(-2, 1, 11), pos(2, 1, 11), FillOperation.Replace)
})

```
