## C04 Q19 R02 人数の表示

**C04 Q19 R02 人数の表示**

村人を3人呼び、同じ人数の金の棒グラフを作って照らし合わせよう。

完成するもの: 呼んだ人数と金の棒グラフを照らし合わせる市民調査所

学ぶこと: 変数（数を入れる箱）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

位置に計算式があるときは、「計算」から同じ記号のブロックを入れよう。変数の名前は、説明と同じつづりにするよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q19r02 を入力した時」（プレイヤー）を置こう。

3. 中のチャットコマンド「q19r02」に、「「ある位置から一定の範囲内にいる「すべての 村人」 位置~-5 ~0 ~13 半径3」」（モブ）をつなごう。

4. 中のチャットコマンド「q19r02」に、「変数countを3にする」（変数）をつなごう。 count がなければ「変数を追加する...」で作ろう。

5. 中のチャットコマンド「q19r02」に、「くりかえしcount回」（ループ）をつなごう。

6. 中のcount回のくり返しに、「村人 を~-5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

7. 中のチャットコマンド「q19r02」に、「変数priceを3にする」（変数）をつなごう。 price がなければ「変数を追加する...」で作ろう。

8. 中のチャットコマンド「q19r02」に、「変数quantityを1にする」（変数）をつなごう。 quantity がなければ「変数を追加する...」で作ろう。

9. 中のチャットコマンド「q19r02」に、「変数totalをprice * quantityにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

10. 中のチャットコマンド「q19r02」に、「変数itemを0～total - 1に変えてくりかえす」（ループ）をつなごう。

11. 中のくり返し（item）に、「金ブロック を~2 + item ~0 ~13 に置く」（ブロック）をつなごう。

12. 緑の実行ボタンを押して、Tキーのチャットで q19r02 と入力しよう。

13. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q19r02", function () {
    mobs.kill(mobs.near(mobs.entitiesByType(VILLAGER), pos(-5, 0, 13), 3))
    let count = 3
    for (let number = 0; number < count; number++) {
        mobs.spawn(VILLAGER, pos(-5, 0, 13))
    }
    let price = 3
    let quantity = 1
    let total = price * quantity
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(2 + item, 0, 13))
    }
})

```
