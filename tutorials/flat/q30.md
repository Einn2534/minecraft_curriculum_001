# Q30 防衛柵の展開

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

長さと向きを変えて再利用できる柵建築関数を作る

工房中心から [[-4, 1, -1], [-2, 1, 1], [0, 1, -1], [2, 1, 1], [4, 1, -1]] の位置に金ブロックを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q30 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q30", function () {
    agent.setSlot(1)
    agent.teleport(pos(-4, 1, 8), EAST)
    agent.place(DOWN)
    agent.teleport(pos(-2, 1, 10), EAST)
    agent.place(DOWN)
    agent.teleport(pos(0, 1, 8), EAST)
    agent.place(DOWN)
    agent.teleport(pos(2, 1, 10), EAST)
    agent.place(DOWN)
    agent.teleport(pos(4, 1, 8), EAST)
    agent.place(DOWN)
})
```
