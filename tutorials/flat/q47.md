# Q47 煙突安全検査

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

煙突上部の塞がりを検知し、安全な高さまで除去する

工房中心から [[-5, 1, 3], [0, 1, 5], [5, 1, 3]] の位置に銅ブロックを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q47 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q47", function () {
    agent.setSlot(1)
    agent.teleport(pos(-5, 1, 12), EAST)
    agent.place(DOWN)
    agent.teleport(pos(0, 1, 14), EAST)
    agent.place(DOWN)
    agent.teleport(pos(5, 1, 12), EAST)
    agent.place(DOWN)
})
```
