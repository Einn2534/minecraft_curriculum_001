# T02 Agentを動かす

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

先に工房NPCの「開始位置へ」を押し、自分は動かずに作ります。Agentを自分の位置・東向きへ呼び、前進3 → 左旋回 → 前進2で金ブロックの中央へ移動させてください。

緑の実行ボタンを押し、ゲームのチャットで agent と入力します。到着したらNPCの「Agentの到着を確認」を押してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("agent", function () {
    agent.teleport(pos(0, 0, 0), EAST)
    agent.move(FORWARD, 3)
    agent.turn(LEFT_TURN)
    agent.move(FORWARD, 2)
})
```
