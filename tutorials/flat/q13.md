## 課題

入力した短い文字を壁へブロックで印刷する

工房中心から [[-3.0, 1, 1], [-2.0, 1, 1], [-1.0, 1, 1], [0.0, 1, 1], [1.0, 1, 1], [2.0, 1, 1]] の位置に青色のコンクリートを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q13 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q13", function () {
    agent.setSlot(1)
    agent.teleport(pos(-3.0, 1, 10), EAST)
    for (let i = 0; i < 6; i++) {
        agent.place(DOWN)
        agent.move(FORWARD, 1)
    }
})
```
