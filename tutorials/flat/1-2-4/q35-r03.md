## C07 Q35 R03 安全を確かめて移す

**C07 Q35 R03 安全を確かめて移す**

目印と、移す先が空いていることを確かめてから移そう。

完成するもの: 村人を分けて通路を空ける市場

学ぶこと: 順番に動かす、変数（値を覚える箱）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q35r03 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q35r03」の中に、「変数villagerTypeを「すべての 村人」（モブ）にする」（変数）をつなごう。 villagerType がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q35r03」の中に、「変数villagerGroupを「ある位置から一定の範囲内にいるvillagerType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。 villagerGroup がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q35r03」の中に、「変数villagerMarkerを「金ブロック が~-5 ~-1 ~13 に存在する」（ブロック）にする」（変数）をつなごう。 villagerMarker がなければ「変数を追加する...」で作ろう。

6. チャットコマンド「q35r03」の中に、「変数villagerSafeを「空気 が~5 ~0 ~13 に存在する」（ブロック）にする」（変数）をつなごう。 villagerSafe がなければ「変数を追加する...」で作ろう。

7. チャットコマンド「q35r03」の中に、「変数villagerReadyをvillagerMarker  かつ  villagerSafeにする」（変数）をつなごう。 villagerReady がなければ「変数を追加する...」で作ろう。

8. チャットコマンド「q35r03」の中に、「もし villagerReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

9. 条件の「なら」の中に、「villagerGroup を~5 ~0 ~13 にテレポートさせる」（モブ）をつなごう。

10. 緑の実行ボタンを押して、Tキーのチャットで q35r03 と入力しよう。

11. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q35r03", function () {
    let villagerType = mobs.entitiesByType(VILLAGER)
    let villagerGroup = mobs.near(villagerType, pos(-5, 0, 13), 3)
    let villagerMarker = blocks.testForBlock(GOLD_BLOCK, pos(-5, -1, 13))
    let villagerSafe = blocks.testForBlock(AIR, pos(5, 0, 13))
    let villagerReady = villagerMarker && villagerSafe
    if (villagerReady) {
        mobs.teleportToPosition(villagerGroup, pos(5, 0, 13))
    }
})
```
