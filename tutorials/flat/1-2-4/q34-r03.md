## C07 Q34 R03 選んだ場所を調べる

**C07 Q34 R03 選んだ場所を調べる**

5つの候補から選び、空いている場所か確かめよう。

完成するもの: くじ引きで小包を隠す倉庫

学ぶこと: 条件（もし〜なら）、順番に動かす、変数（値を覚える箱）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q34r03 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q34r03」の中に、「変数placesを「配列を作成」に -6、-3、0、3、6 を順に入れるにする」（変数）をつなごう。 places がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q34r03」の中に、「変数choiceを「ランダムな数字を選択: 0 から 4 まで」（計算）にする」（変数）をつなごう。 choice がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q34r03」の中に、「変数xを「placesのchoice番目の値」にする」（変数）をつなごう。 x がなければ「変数を追加する...」で作ろう。

6. チャットコマンド「q34r03」の中に、「変数safeを「空気 が~x ~0 ~13 に存在する」（ブロック）にする」（変数）をつなごう。 safe がなければ「変数を追加する...」で作ろう。

7. チャットコマンド「q34r03」の中に、「もし safe なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 条件の「なら」の中に、「チェスト を~x ~0 ~13 に置く」（ブロック）をつなごう。

9. 緑の実行ボタンを押して、Tキーのチャットで q34r03 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q34r03", function () {
    let places = [-6, -3, 0, 3, 6]
    let choice = randint(0, 4)
    let x = places[choice]
    let safe = blocks.testForBlock(AIR, pos(x, 0, 13))
    if (safe) {
        blocks.place(CHEST, pos(x, 0, 13))
    }
})

```
