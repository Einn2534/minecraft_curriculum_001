## C10 Q48 R02 3つから選ぶ

**C10 Q48 R02 3つから選ぶ**

3か所にくじで選んだ花を植えよう。

完成するもの: 種類をくじ引きで選ぶ花壇

学ぶこと: 乱数、順番に動かす、変数（値を覚える箱）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q48r02 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q48r02」の中に、「変数flowersを「配列を作成」に ポピー、タンポポ を順に入れるにする」（変数）をつなごう。 flowers がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q48r02」の中に、「変数choice1を「ランダムな数字を選択: 0 から 1 まで」（計算）にする」（変数）をつなごう。 choice1 がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q48r02」の中に、「変数flower1を「flowersのchoice1番目の値」にする」（変数）をつなごう。 flower1 がなければ「変数を追加する...」で作ろう。

6. チャットコマンド「q48r02」の中に、「flower1 を~-4 ~0 ~13 に置く」（ブロック）をつなごう。

7. チャットコマンド「q48r02」の中に、「変数choice2を「ランダムな数字を選択: 0 から 1 まで」（計算）にする」（変数）をつなごう。 choice2 がなければ「変数を追加する...」で作ろう。

8. チャットコマンド「q48r02」の中に、「変数flower2を「flowersのchoice2番目の値」にする」（変数）をつなごう。 flower2 がなければ「変数を追加する...」で作ろう。

9. チャットコマンド「q48r02」の中に、「flower2 を~0 ~0 ~13 に置く」（ブロック）をつなごう。

10. チャットコマンド「q48r02」の中に、「変数choice3を「ランダムな数字を選択: 0 から 1 まで」（計算）にする」（変数）をつなごう。 choice3 がなければ「変数を追加する...」で作ろう。

11. チャットコマンド「q48r02」の中に、「変数flower3を「flowersのchoice3番目の値」にする」（変数）をつなごう。 flower3 がなければ「変数を追加する...」で作ろう。

12. チャットコマンド「q48r02」の中に、「flower3 を~4 ~0 ~13 に置く」（ブロック）をつなごう。

13. 緑の実行ボタンを押して、Tキーのチャットで q48r02 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q48r02", function () {
    let flowers = [POPPY, YELLOW_FLOWER]
    let choice1 = randint(0, 1)
    let flower1 = flowers[choice1]
    blocks.place(flower1, pos(-4, 0, 13))
    let choice2 = randint(0, 1)
    let flower2 = flowers[choice2]
    blocks.place(flower2, pos(0, 0, 13))
    let choice3 = randint(0, 1)
    let flower3 = flowers[choice3]
    blocks.place(flower3, pos(4, 0, 13))
})
```
