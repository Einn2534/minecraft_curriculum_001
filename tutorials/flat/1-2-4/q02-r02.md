## C01 Q02 R02 金の十字

**C01 Q02 R02 金の十字**

金の十字を2つの範囲で作ろう。

完成するもの: 玉座へ続く左右対称の床の紋章

学ぶこと: 対称な形、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q02r02 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q02r02」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

4. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~-2 ~0 ~12、「範囲の終わり」は ~2 ~0 ~12 にするよ。

5. チャットコマンド「q02r02」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

6. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~0 ~0 ~10、「範囲の終わり」は ~0 ~0 ~14 にするよ。

7. 緑の実行ボタンを押して、Tキーのチャットで q02r02 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q02r02", function () {
    blocks.fill(GOLD_BLOCK, pos(-2, 0, 12), pos(2, 0, 12), FillOperation.Replace)
    blocks.fill(GOLD_BLOCK, pos(0, 0, 10), pos(0, 0, 14), FillOperation.Replace)
})
```
