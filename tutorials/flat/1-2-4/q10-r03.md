## C02 Q10 R03 3区間の迷宮の出口

**C02 Q10 R03 3区間の迷宮の出口**

はじめの位置から3か所を順にたどり、ゴールへ移動しよう。

完成するもの: 迷宮の出口の道とゴール

学ぶこと: 座標を足す、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q10r03 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q10r03」の中に、「変数originを「プレイヤーの位置」（プレイヤー）にする」（変数）をつなごう。 origin がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q10r03」の中に、「変数stop1を「origin + ~-6 ~0 ~14」（位置）にする」（変数）をつなごう。 stop1 がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q10r03」の中に、「stop1 にテレポートする」（プレイヤー）をつなごう。

6. チャットコマンド「q10r03」の中に、「変数stop2を「origin + ~6 ~0 ~14」（位置）にする」（変数）をつなごう。 stop2 がなければ「変数を追加する...」で作ろう。

7. チャットコマンド「q10r03」の中に、「stop2 にテレポートする」（プレイヤー）をつなごう。

8. チャットコマンド「q10r03」の中に、「変数stop3を「origin + ~6 ~0 ~16」（位置）にする」（変数）をつなごう。 stop3 がなければ「変数を追加する...」で作ろう。

9. チャットコマンド「q10r03」の中に、「stop3 にテレポートする」（プレイヤー）をつなごう。

10. チャットコマンド「q10r03」の中に、「コマンド "function grandfort/course/arrival/r030" を 実行する」（プレイヤー）をつなごう。

11. 緑の実行ボタンを押して、Tキーのチャットで q10r03 と入力しよう。

12. 「ゴールに到着！」が出たら、緑の道で工房NPCへ戻ろう。到着の記録は残るよ。

13. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q10r03", function () {
    let origin = player.position()
    let stop1 = positions.add(origin, pos(-6, 0, 14))
    player.teleport(stop1)
    let stop2 = positions.add(origin, pos(6, 0, 14))
    player.teleport(stop2)
    let stop3 = positions.add(origin, pos(6, 0, 16))
    player.teleport(stop3)
    player.execute("function grandfort/course/arrival/r030")
})

```
