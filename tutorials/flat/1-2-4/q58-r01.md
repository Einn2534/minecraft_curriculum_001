## C12 Q58 R01 親を1組

**C12 Q58 R01 親を1組**

同じ囲いに牛を2頭呼び、親の1組を作ろう。

完成するもの: 親の組数と必要なえさを計算する繁殖計画の牧場

学ぶこと: 変数（数を入れる箱）、Mobを呼ぶ、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q58r01 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q58r01」の中に、「変数cowTypeを「すべての ウシ」（モブ）にする」（変数）をつなごう。 cowType がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q58r01」の中に、「変数cowGroupを「ある位置から一定の範囲内にいるcowType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。 cowGroup がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q58r01」の中に、「cowGroup」（モブ）をつなごう。

6. チャットコマンド「q58r01」の中に、「くりかえし2回」（ループ）をつなごう。

7. 2回のくり返しの中に、「ウシ を~-5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

8. 緑の実行ボタンを押して、Tキーのチャットで q58r01 と入力しよう。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q58r01", function () {
    let cowType = mobs.entitiesByType(COW)
    let cowGroup = mobs.near(cowType, pos(-5, 0, 13), 3)
    mobs.kill(cowGroup)
    for (let number = 0; number < 2; number++) {
        mobs.spawn(COW, pos(-5, 0, 13))
    }
})

```
