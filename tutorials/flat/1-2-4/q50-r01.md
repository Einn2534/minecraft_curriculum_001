## C10 Q50 R01 2つから選ぶ

**C10 Q50 R01 2つから選ぶ**

2つの候補をリストに入れ、くじで1つ選ぼう。

完成するもの: 安全な場所から選ぶAgentかくれんぼ

学ぶこと: 乱数（くじ引き）、順番に動かす、変数（値を覚える箱）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q50r01 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q50r01」の中に、「変数placesを「配列を作成」に -4、0 を順に入れるにする」（変数）をつなごう。 places がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q50r01」の中に、「変数choiceを「ランダムな数字を選択: 0 から 1 まで」（計算）にする」（変数）をつなごう。 choice がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q50r01」の中に、「変数xを「placesのchoice番目の値」にする」（変数）をつなごう。 x がなければ「変数を追加する...」で作ろう。

6. チャットコマンド「q50r01」の中に、「エージェントを ~x ~0 ~13 へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

7. 緑の実行ボタンを押して、Tキーのチャットで q50r01 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q50r01", function () {
    let places = [-4, 0]
    let choice = randint(0, 1)
    let x = places[choice]
    agent.teleport(pos(x, 0, 13), SOUTH)
})
```
