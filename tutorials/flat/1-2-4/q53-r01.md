## C11 Q53 R01 水路を掘る

**C11 Q53 R01 水路を掘る**

範囲を指定して、土の中に水路を作ろう。

完成するもの: 畑へ水を届ける灌漑路

学ぶこと: 土を水へ変える、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q53r01 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q53r01」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

4. いまつないだ「ブロックを並べる」の材料を「水」にしよう。「範囲の始まり」は ~-3 ~-1 ~10、「範囲の終わり」は ~-3 ~-1 ~16 にするよ。

5. 緑の実行ボタンを押して、Tキーのチャットで q53r01 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q53r01", function () {
    blocks.fill(WATER, pos(-3, -1, 10), pos(-3, -1, 16), FillOperation.Replace)
})

```
