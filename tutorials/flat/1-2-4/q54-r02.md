## C11 Q54 R02 同じ間隔の木

**C11 Q54 R02 同じ間隔の木**

間隔4を変数に入れ、2本目の幹の位置を計算しよう。

完成するもの: 間隔を計算して植える王立果樹園

学ぶこと: かけ算で間隔を計算、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q54r02 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q54r02」の中に、「変数gapを4にする」（変数）をつなごう。 gap がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q54r02」の中に、「変数treeXを-4 + gapにする」（変数）をつなごう。 treeX がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q54r02」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

6. いまつないだ「ブロックを並べる」の材料を「オークの原木」にしよう。「範囲の始まり」は ~treeX ~0 ~12、「範囲の終わり」は ~treeX ~3 ~12 にするよ。

7. チャットコマンド「q54r02」の中に、「変数leftXをtreeX - 1にする」（変数）をつなごう。 leftX がなければ「変数を追加する...」で作ろう。

8. チャットコマンド「q54r02」の中に、「変数rightXをtreeX + 1にする」（変数）をつなごう。 rightX がなければ「変数を追加する...」で作ろう。

9. チャットコマンド「q54r02」の中に、「ビルダー: 位置 ~leftX ~4 ~11 へテレポート」（ビルダー）をつなごう。

10. チャットコマンド「q54r02」の中に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

11. チャットコマンド「q54r02」の中に、「ビルダー: 位置 ~rightX ~5 ~13 へテレポート」（ビルダー）をつなごう。

12. チャットコマンド「q54r02」の中に、「ビルダー: 印を付けた場所からブロック 樫の葉 で埋める」（ビルダー）をつなごう。

13. 緑の実行ボタンを押して、Tキーのチャットで q54r02 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q54r02", function () {
    let gap = 4
    let treeX = -4 + gap
    blocks.fill(LOG_OAK, pos(treeX, 0, 12), pos(treeX, 3, 12), FillOperation.Replace)
    let leftX = treeX - 1
    let rightX = treeX + 1
    builder.teleportTo(pos(leftX, 4, 11))
    builder.mark()
    builder.teleportTo(pos(rightX, 5, 13))
    builder.fill(LEAVES_OAK)
})

```
