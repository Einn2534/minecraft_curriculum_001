## C06 Q29 R03 操作する道具

**C06 Q29 R03 操作する道具**

棒を右クリックしたとき、金の救助信号を出そう。

完成するもの: 色を選んで発信できる緊急信号旗

学ぶこと: 道具を使ったときのイベント、順番に動かす、変数（値を覚える箱）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「変数eventOriginを「プレイヤーの位置」（プレイヤー）にする」（変数）をつなごう。 eventOrigin がなければ「変数を追加する...」で作ろう。

3. 「変数eventReadyを偽にする」（変数）をつなごう。 eventReady がなければ「変数を追加する...」で作ろう。

4. 「チャットコマンド q29r03 を入力した時」（プレイヤー）を置こう。

5. チャットコマンド「q29r03」の中に、「変数eventOriginを「プレイヤーの位置」（プレイヤー）にする」（変数）をつなごう。

6. チャットコマンド「q29r03」の中に、「変数eventReadyを真にする」（変数）をつなごう。

7. 「次の棒|が使われた時」（プレイヤー）を、チャットコマンドの外に置こう。

8. イベントの中に、「もし eventReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

9. 条件の「なら」の中に、「変数eventPoint1を「eventOrigin + ~2 ~4 ~13」（位置）にする」（変数）をつなごう。 eventPoint1 がなければ「変数を追加する...」で作ろう。

10. 条件の「なら」の中に、「変数eventPoint2を「eventOrigin + ~3 ~4 ~13」（位置）にする」（変数）をつなごう。 eventPoint2 がなければ「変数を追加する...」で作ろう。

11. 条件の「なら」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

12. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は eventPoint1、「範囲の終わり」は eventPoint2 にするよ。

13. 緑の実行ボタンを押して、Tキーのチャットで q29r03 と入力しよう。

14. 入口の金の床で、用意した棒を持って右クリックしよう。

15. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q29r03", function () {
    eventOrigin = player.position()
    eventReady = true
})
player.onItemInteracted(STICK, function () {
    if (eventReady) {
        let eventPoint1 = positions.add(eventOrigin, pos(2, 4, 13))
        let eventPoint2 = positions.add(eventOrigin, pos(3, 4, 13))
        blocks.fill(GOLD_BLOCK, eventPoint1, eventPoint2, FillOperation.Replace)
    }
})

```
