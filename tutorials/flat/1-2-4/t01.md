## T001 チャットコマンドを使ってみよう！

**T001 チャットコマンドを使ってみよう！**

工房NPCの「開始する」を押したら、新しいプロジェクトで作ろう。

1. 「チャットコマンド hello を入力した時」（プレイヤー）を置こう。

2. 中のチャットコマンド「hello」に、「メッセージ "王都へようこそ！" を 送信する」（プレイヤー）をつなごう。

3. 中のチャットコマンド「hello」に、「コマンド "function t001" を 実行する」（プレイヤー）をつなごう。

さいごのコマンドは、クリアをゲームに知らせる合図だよ。緑の実行ボタンを押し、Tキーのチャットで hello と入力しよう。「T001 クリア！」が出るよ。

次は緑の道をたどって、工房NPCの「入門の続き」→「開始位置へ」。CキーでT002の作り方を見よう。

ヒントは電球を押してみよう。

```blocks
player.onChat("hello", function () {
    player.say("王都へようこそ！")
    player.execute("function t001")
})
```
