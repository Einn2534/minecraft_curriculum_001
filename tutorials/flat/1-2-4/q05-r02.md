## C01 Q05 R02 暗号で開けよう

**C01 Q05 R02 暗号で開けよう**

暗号が7なら、鉄の扉を開けよう。

完成するもの: 番号を照合すると金の扉が開く王家の金庫

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q05r02 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q05r02」の中に、「変数passwordを7にする」（変数）をつなごう。 password がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q05r02」の中に、「もし password  =  7 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

5. 条件の「なら」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

6. いまつないだ「ブロックを並べる」の材料を「空気」にしよう。「範囲の始まり」は ~0 ~0 ~10、「範囲の終わり」は ~0 ~1 ~10 にするよ。

7. 緑の実行ボタンを押して、Tキーのチャットで q05r02 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q05r02", function () {
    let password = 7
    if (password == 7) {
        blocks.fill(AIR, pos(0, 0, 10), pos(0, 1, 10), FillOperation.Replace)
    }
})
```
