## C03 Q12 R02 列で分ける

**C03 Q12 R02 列で分ける**

2つの見本を1つずつ調べて分けよう。

完成するもの: 素材別の錬金棚

学ぶこと: 条件（もし〜なら）、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q12r02 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q12r02」の中に、「変数gold1を「金ブロック が~-5 ~0 ~10 に存在する」（ブロック）にする」（変数）をつなごう。 gold1 がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q12r02」の中に、「もし gold1 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

5. 条件の「なら」の中に、「金ブロック を~4 ~0 ~10 に置く」（ブロック）をつなごう。

6. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

7. 「でなければ」の中に、「鉄ブロック を~4 ~0 ~10 に置く」（ブロック）をつなごう。

8. チャットコマンド「q12r02」の中に、「変数gold2を「金ブロック が~-5 ~0 ~12 に存在する」（ブロック）にする」（変数）をつなごう。 gold2 がなければ「変数を追加する...」で作ろう。

9. チャットコマンド「q12r02」の中に、「もし gold2 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

10. 条件の「なら」の中に、「金ブロック を~4 ~0 ~12 に置く」（ブロック）をつなごう。

11. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

12. 「でなければ」の中に、「鉄ブロック を~4 ~0 ~12 に置く」（ブロック）をつなごう。

13. 緑の実行ボタンを押して、Tキーのチャットで q12r02 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q12r02", function () {
    let gold1 = blocks.testForBlock(GOLD_BLOCK, pos(-5, 0, 10))
    if (gold1) {
        blocks.place(GOLD_BLOCK, pos(4, 0, 10))
    } else {
        blocks.place(IRON_BLOCK, pos(4, 0, 10))
    }
    let gold2 = blocks.testForBlock(GOLD_BLOCK, pos(-5, 0, 12))
    if (gold2) {
        blocks.place(GOLD_BLOCK, pos(4, 0, 12))
    } else {
        blocks.place(IRON_BLOCK, pos(4, 0, 12))
    }
})

```
