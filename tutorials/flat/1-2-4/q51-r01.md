## C11 Q51 R01 長方形の区画

**C11 Q51 R01 長方形の区画**

幅と長さを変数に入れ、1つの範囲で畑を作ろう。

完成するもの: 面積を計算して区画を作る畑

学ぶこと: 変数（数を入れる箱）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q51r01 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q51r01」の中に、「変数widthを3にする」（変数）をつなごう。 width がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q51r01」の中に、「変数lengthを3にする」（変数）をつなごう。 length がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q51r01」の中に、「変数endXを-3 + width - 1にする」（変数）をつなごう。 endX がなければ「変数を追加する...」で作ろう。

6. チャットコマンド「q51r01」の中に、「変数endZを11 + length - 1にする」（変数）をつなごう。 endZ がなければ「変数を追加する...」で作ろう。

7. チャットコマンド「q51r01」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

8. いまつないだ「ブロックを並べる」の材料を「土」にしよう。「範囲の始まり」は ~-3 ~-1 ~11、「範囲の終わり」は ~endX ~-1 ~endZ にするよ。

9. 緑の実行ボタンを押して、Tキーのチャットで q51r01 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q51r01", function () {
    let width = 3
    let length = 3
    let endX = -3 + width - 1
    let endZ = 11 + length - 1
    blocks.fill(DIRT, pos(-3, -1, 11), pos(endX, -1, endZ), FillOperation.Replace)
})

```
