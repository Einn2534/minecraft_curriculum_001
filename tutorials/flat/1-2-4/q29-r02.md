## C06 Q29 R02 色を選ぶ

**C06 Q29 R02 色を選ぶ**

チャットの数字で、赤・黄・青の信号を選ぼう。

完成するもの: 色を選んで発信できる緊急信号旗

学ぶこと: 条件（もし〜なら）、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q29r02 を入力した時」（プレイヤー）を置こう。＋で数字の入力「signal」を追加しよう。

3. チャットコマンド「q29r02」の中に、「変数colorを赤色の羊毛にする」（変数）をつなごう。 color がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q29r02」の中に、「もし signal  =  2 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

5. 条件の「なら」の中に、「変数colorを黄色の羊毛にする」（変数）をつなごう。

6. チャットコマンド「q29r02」の中に、「でなければもし signal  =  3 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

7. 条件の「なら」の中に、「変数colorを青色の羊毛にする」（変数）をつなごう。

8. チャットコマンド「q29r02」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

9. いまつないだ「ブロックを並べる」の材料を「color」にしよう。「範囲の始まり」は ~1 ~3 ~13、「範囲の終わり」は ~4 ~5 ~13 にするよ。

10. 緑の実行ボタンを押して、Tキーのチャットで q29r02 2 と入力しよう。

11. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q29r02", function (signal) {
    let color = RED_WOOL
    if (signal == 2) {
        color = YELLOW_WOOL
    } else if (signal == 3) {
        color = BLUE_WOOL
    }
    blocks.fill(color, pos(1, 3, 13), pos(4, 5, 13), FillOperation.Replace)
})

```
