## C07 Q33 R03 会計台を仕上げる

**C07 Q33 R03 会計台を仕上げる**

別の単価と個数で計算し、会計台とグラフを仕上げよう。

完成するもの: 値段と個数を計算して表示する商人の会計台

学ぶこと: 条件（もし〜なら）、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q33r03 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q33r03」の中に、「変数priceを4にする」（変数）をつなごう。 price がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q33r03」の中に、「変数quantityを2にする」（変数）をつなごう。 quantity がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q33r03」の中に、「もし quantity >= 3 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 条件の「なら」の中に、「変数priceを-1だけ増やす」（変数）をつなごう。

7. チャットコマンド「q33r03」の中に、「変数totalをprice * quantityにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

8. チャットコマンド「q33r03」の中に、「変数endXを-4 + total - 1にする」（変数）をつなごう。 endX がなければ「変数を追加する...」で作ろう。

9. チャットコマンド「q33r03」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

10. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~-4 ~0 ~12、「範囲の終わり」は ~endX ~0 ~12 にするよ。

11. チャットコマンド「q33r03」の中に、「ビルダー: 位置 ~-5 ~1 ~13 へテレポート」（ビルダー）をつなごう。

12. チャットコマンド「q33r03」の中に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

13. チャットコマンド「q33r03」の中に、「ビルダー: 位置 ~5 ~1 ~13 へテレポート」（ビルダー）をつなごう。

14. チャットコマンド「q33r03」の中に、「ビルダー: 印を付けた場所からブロック オークの板材 で埋める」（ビルダー）をつなごう。

15. 緑の実行ボタンを押して、Tキーのチャットで q33r03 と入力しよう。

16. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q33r03", function () {
    let price = 4
    let quantity = 2
    if (quantity >= 3) {
        price += -1
    }
    let total = price * quantity
    let endX = -4 + total - 1
    blocks.fill(GOLD_BLOCK, pos(-4, 0, 12), pos(endX, 0, 12), FillOperation.Replace)
    builder.teleportTo(pos(-5, 1, 13))
    builder.mark()
    builder.teleportTo(pos(5, 1, 13))
    builder.fill(PLANKS_OAK)
})

```
