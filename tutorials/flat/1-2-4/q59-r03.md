## C12 Q59 R03 安全を確かめて移す

**C12 Q59 R03 安全を確かめて移す**

目印と、移す先が空いていることを確かめてから移そう。

完成するもの: 羊を安全な囲いへ誘導する牧場

学ぶこと: 順番に動かす、変数（値を覚える箱）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q59r03 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q59r03」の中に、「変数sheepTypeを「すべての 羊」（モブ）にする」（変数）をつなごう。 sheepType がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q59r03」の中に、「変数sheepGroupを「ある位置から一定の範囲内にいるsheepType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。 sheepGroup がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q59r03」の中に、「変数sheepMarkerを「金ブロック が~-5 ~-1 ~13 に存在する」（ブロック）にする」（変数）をつなごう。 sheepMarker がなければ「変数を追加する...」で作ろう。

6. チャットコマンド「q59r03」の中に、「変数sheepSafeを「空気 が~5 ~0 ~13 に存在する」（ブロック）にする」（変数）をつなごう。 sheepSafe がなければ「変数を追加する...」で作ろう。

7. チャットコマンド「q59r03」の中に、「変数sheepReadyをsheepMarker  かつ  sheepSafeにする」（変数）をつなごう。 sheepReady がなければ「変数を追加する...」で作ろう。

8. チャットコマンド「q59r03」の中に、「もし sheepReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

9. 条件の「なら」の中に、「sheepGroup を~5 ~0 ~13 にテレポートさせる」（モブ）をつなごう。

10. 緑の実行ボタンを押して、Tキーのチャットで q59r03 と入力しよう。

11. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q59r03", function () {
    let sheepType = mobs.entitiesByType(SHEEP)
    let sheepGroup = mobs.near(sheepType, pos(-5, 0, 13), 3)
    let sheepMarker = blocks.testForBlock(GOLD_BLOCK, pos(-5, -1, 13))
    let sheepSafe = blocks.testForBlock(AIR, pos(5, 0, 13))
    let sheepReady = sheepMarker && sheepSafe
    if (sheepReady) {
        mobs.teleportToPosition(sheepGroup, pos(5, 0, 13))
    }
})

```
