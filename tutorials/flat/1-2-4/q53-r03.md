## C11 Q53 R03 渡れる橋

**C11 Q53 R03 渡れる橋**

ビルダーで水路の上に歩ける橋を作ろう。

完成するもの: 畑へ水を届ける灌漑路

学ぶこと: Builder、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q53r03 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q53r03」の中に、「ビルダー: 位置 ~-1 ~0 ~12 へテレポート」（ビルダー）をつなごう。

4. チャットコマンド「q53r03」の中に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

5. チャットコマンド「q53r03」の中に、「ビルダー: 位置 ~1 ~0 ~14 へテレポート」（ビルダー）をつなごう。

6. チャットコマンド「q53r03」の中に、「ビルダー: 印を付けた場所からブロック オークの板材 で埋める」（ビルダー）をつなごう。

7. 緑の実行ボタンを押して、Tキーのチャットで q53r03 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q53r03", function () {
    builder.teleportTo(pos(-1, 0, 12))
    builder.mark()
    builder.teleportTo(pos(1, 0, 14))
    builder.fill(PLANKS_OAK)
})

```
