## C12 Q58 R03 繁殖計画ボード

**C12 Q58 R03 繁殖計画ボード**

6頭の組数と余りを計算し、計画ボードを仕上げよう。

完成するもの: 親の組数と必要なえさを計算する繁殖計画の牧場

学ぶこと: 変数（数を入れる箱）、割り算・余り、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q58r03 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q58r03」の中に、「変数cowTypeを「すべての ウシ」（モブ）にする」（変数）をつなごう。 cowType がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q58r03」の中に、「変数cowGroupを「ある位置から一定の範囲内にいるcowType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。 cowGroup がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q58r03」の中に、「cowGroup」（モブ）をつなごう。

6. チャットコマンド「q58r03」の中に、「くりかえし6回」（ループ）をつなごう。

7. 6回のくり返しの中に、「ウシ を~-5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

8. チャットコマンド「q58r03」の中に、「変数headsを6にする」（変数）をつなごう。 heads がなければ「変数を追加する...」で作ろう。

9. チャットコマンド「q58r03」の中に、「変数totalを「整数の÷」に heads と 2 を入れるにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

10. チャットコマンド「q58r03」の中に、「変数leftOverをheads % 2にする」（変数）をつなごう。 leftOver がなければ「変数を追加する...」で作ろう。

11. チャットコマンド「q58r03」の中に、「メッセージ 「文字列をつなげる」に "組に入らない頭数: " と leftOver を入れる を 送信する」（プレイヤー）をつなごう。

12. チャットコマンド「q58r03」の中に、「変数endXを2 + total - 1にする」（変数）をつなごう。 endX がなければ「変数を追加する...」で作ろう。

13. チャットコマンド「q58r03」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

14. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~2 ~0 ~11、「範囲の終わり」は ~endX ~0 ~11 にするよ。

15. チャットコマンド「q58r03」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

16. いまつないだ「ブロックを並べる」の材料を「干草の俵」にしよう。「範囲の始まり」は ~3 ~0 ~12、「範囲の終わり」は ~5 ~0 ~12 にするよ。

17. 緑の実行ボタンを押して、Tキーのチャットで q58r03 と入力しよう。

18. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q58r03", function () {
    let cowType = mobs.entitiesByType(COW)
    let cowGroup = mobs.near(cowType, pos(-5, 0, 13), 3)
    mobs.kill(cowGroup)
    for (let number = 0; number < 6; number++) {
        mobs.spawn(COW, pos(-5, 0, 13))
    }
    let heads = 6
    let total = Math.idiv(heads, 2)
    let leftOver = heads % 2
    player.say("組に入らない頭数: " + leftOver)
    let endX = 2 + total - 1
    blocks.fill(GOLD_BLOCK, pos(2, 0, 11), pos(endX, 0, 11), FillOperation.Replace)
    blocks.fill(HAY_BLOCK, pos(3, 0, 12), pos(5, 0, 12), FillOperation.Replace)
})

```
