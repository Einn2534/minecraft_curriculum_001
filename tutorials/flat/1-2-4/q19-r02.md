## C04 Q19 R02 人数の表示

**C04 Q19 R02 人数の表示**

村人3人と、同じ数の金の棒グラフを作ろう。

完成するもの: 呼んだ人数と金の棒グラフを照らし合わせる市民調査所

学ぶこと: 変数（数を入れる箱）、くり返し、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q19r02 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q19r02」の中に、「変数villagerTypeを「すべての 村人」（モブ）にする」（変数）をつなごう。 villagerType がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q19r02」の中に、「変数villagerGroupを「ある位置から一定の範囲内にいるvillagerType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。 villagerGroup がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q19r02」の中に、「villagerGroup」（モブ）をつなごう。

6. チャットコマンド「q19r02」の中に、「くりかえし3回」（ループ）をつなごう。

7. 3回のくり返しの中に、「村人 を~-5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

8. チャットコマンド「q19r02」の中に、「変数priceを3にする」（変数）をつなごう。 price がなければ「変数を追加する...」で作ろう。

9. チャットコマンド「q19r02」の中に、「変数quantityを1にする」（変数）をつなごう。 quantity がなければ「変数を追加する...」で作ろう。

10. チャットコマンド「q19r02」の中に、「変数totalをprice * quantityにする」（変数）をつなごう。 total がなければ「変数を追加する...」で作ろう。

11. チャットコマンド「q19r02」の中に、「変数endXを2 + total - 1にする」（変数）をつなごう。 endX がなければ「変数を追加する...」で作ろう。

12. チャットコマンド「q19r02」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

13. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~2 ~0 ~13、「範囲の終わり」は ~endX ~0 ~13 にするよ。

14. 緑の実行ボタンを押して、Tキーのチャットで q19r02 と入力しよう。

15. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q19r02", function () {
    let villagerType = mobs.entitiesByType(VILLAGER)
    let villagerGroup = mobs.near(villagerType, pos(-5, 0, 13), 3)
    mobs.kill(villagerGroup)
    for (let number = 0; number < 3; number++) {
        mobs.spawn(VILLAGER, pos(-5, 0, 13))
    }
    let price = 3
    let quantity = 1
    let total = price * quantity
    let endX = 2 + total - 1
    blocks.fill(GOLD_BLOCK, pos(2, 0, 13), pos(endX, 0, 13), FillOperation.Replace)
})

```
