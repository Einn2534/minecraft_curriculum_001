## C07 Q32 R01 床とカウンター

**C07 Q32 R01 床とカウンター**

幅を変数に入れ、ビルダーで床を作り、カウンターを付けよう。

完成するもの: 幅を変えられる商店

学ぶこと: 変数（数を入れる箱）、Builder、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q32r01 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q32r01」の中に、「変数widthを7にする」（変数）をつなごう。 width がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q32r01」の中に、「変数endXを-3 + width - 1にする」（変数）をつなごう。 endX がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q32r01」の中に、「ビルダー: 位置 ~-3 ~0 ~10 へテレポート」（ビルダー）をつなごう。

6. チャットコマンド「q32r01」の中に、「ビルダー: 印を付ける」（ビルダー）をつなごう。

7. チャットコマンド「q32r01」の中に、「ビルダー: 位置 ~endX ~0 ~15 へテレポート」（ビルダー）をつなごう。

8. チャットコマンド「q32r01」の中に、「ビルダー: 印を付けた場所からブロック オークの板材 で埋める」（ビルダー）をつなごう。

9. チャットコマンド「q32r01」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

10. いまつないだ「ブロックを並べる」の材料を「石レンガ」にしよう。「範囲の始まり」は ~-2 ~1 ~11、「範囲の終わり」は ~2 ~1 ~11 にするよ。

11. 緑の実行ボタンを押して、Tキーのチャットで q32r01 と入力しよう。

12. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q32r01", function () {
    let width = 7
    let endX = -3 + width - 1
    builder.teleportTo(pos(-3, 0, 10))
    builder.mark()
    builder.teleportTo(pos(endX, 0, 15))
    builder.fill(PLANKS_OAK)
    blocks.fill(STONE_BRICKS, pos(-2, 1, 11), pos(2, 1, 11), FillOperation.Replace)
})

```
