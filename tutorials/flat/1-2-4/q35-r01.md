## C07 Q35 R01 近くのグループ

**C07 Q35 R01 近くのグループ**

種類と近さで選び、自分の囲いの動物だけを移そう。

完成するもの: 村人を分けて通路を空ける市場

学ぶこと: 近くのMobを選ぶ、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q35r01 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q35r01」の中に、「変数villagerTypeを「すべての 村人」（モブ）にする」（変数）をつなごう。 villagerType がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q35r01」の中に、「変数villagerGroupを「ある位置から一定の範囲内にいるvillagerType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。 villagerGroup がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q35r01」の中に、「villagerGroup を~5 ~0 ~13 にテレポートさせる」（モブ）をつなごう。

6. 緑の実行ボタンを押して、Tキーのチャットで q35r01 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q35r01", function () {
    let villagerType = mobs.entitiesByType(VILLAGER)
    let villagerGroup = mobs.near(villagerType, pos(-5, 0, 13), 3)
    mobs.teleportToPosition(villagerGroup, pos(5, 0, 13))
})

```
