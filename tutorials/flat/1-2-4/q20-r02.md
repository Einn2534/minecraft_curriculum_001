## C04 Q20 R02 時刻の表示

**C04 Q20 R02 時刻の表示**

時刻を調べ、昼は白・夜は青で表示しよう。

完成するもの: 時刻を読み、同じ色の表示を出す中央と左右の時計塔

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

数の入力に英字の名前があるときは、「変数」からその名前のブロックをはめよう。変数は「変数を追加する...」で、説明と同じつづりの名前を作るよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q20r02 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q20r02」の中に、「変数valueを「現在の時間」（ゲームプレイ）にする」（変数）をつなごう。 value がなければ「変数を追加する...」で作ろう。

4. チャットコマンド「q20r02」の中に、「変数colorを白色の羊毛にする」（変数）をつなごう。 color がなければ「変数を追加する...」で作ろう。

5. チャットコマンド「q20r02」の中に、「もし value >= 12000 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 条件の「なら」の中に、「変数colorを青色の羊毛にする」（変数）をつなごう。

7. チャットコマンド「q20r02」の中に、「color を~0 ~1 ~12 に置く」（ブロック）をつなごう。

8. 緑の実行ボタンを押して、Tキーのチャットで q20r02 と入力しよう。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q20r02", function () {
    let value = gameplay.timeQuery(TimeQuery.DayTime)
    let color = WOOL
    if (value >= 12000) {
        color = BLUE_WOOL
    }
    blocks.place(color, pos(0, 1, 12))
})

```
