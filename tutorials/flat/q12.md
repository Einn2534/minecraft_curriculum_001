# Q12 錬金素材の仕分け

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

Agentのスロット内容と個数を調べ、棚ごとに移し替える

工房中心から [[-4, 1, -1], [-2, 1, 1], [0, 1, -1], [2, 1, 1], [4, 1, -1]] の位置にダークオークの板材を置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q12 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q12", function () {
    agent.setSlot(1)
    agent.teleport(pos(-4, 1, 8), EAST)
    agent.place(DOWN)
    agent.teleport(pos(-2, 1, 10), EAST)
    agent.place(DOWN)
    agent.teleport(pos(0, 1, 8), EAST)
    agent.place(DOWN)
    agent.teleport(pos(2, 1, 10), EAST)
    agent.place(DOWN)
    agent.teleport(pos(4, 1, 8), EAST)
    agent.place(DOWN)
})
```
