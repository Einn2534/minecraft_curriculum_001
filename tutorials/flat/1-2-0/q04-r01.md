## C01 Q04 R01 橋の床

**C01 Q04 R01 橋の床**

川を渡る木の橋の床を作ろう。

完成するもの: 川を渡る木の橋・手すり・開く門

学ぶこと: くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q04r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。オークの板で pos(-2, 0, 8) から pos(2, 0, 16) まで作ろう。

3. 緑の実行ボタンを押して、Tキーのチャットで q04r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q04r01", function () {
    for (let x = 0; x <= 4; x++) {
        for (let z = 0; z <= 8; z++) {
            blocks.place(PLANKS_OAK, pos((x + -2), 1 - 1, (z + -1) + 9))
        }
    }
})

```
