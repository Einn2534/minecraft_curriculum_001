## C05 Q21 R03 面を点検して片付ける

**C05 Q21 R03 面を点検して片付ける**

指定のオークの原木を調べ、Agentでこわして集めよう。

完成するもの: 漂流物を取り除いた運河

学ぶこと: 二重のくり返し、安全な場所だけをこわす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q21r03 に変えよう。

2. 調べる手順を関数にまとめよう。位置のリストをくり返し、横と奥、または横と高さの2つのくり返しを組み合わせよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q21r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

function check_q21r03_1(x: number, y: number, z: number) {
    agent.teleport(pos(x, y - 1, z + 8), SOUTH)
    if (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
}
player.onChat("q21r03", function () {
    let xValues = [-3, -2, -1, 0, 1, 2, 3]
    let zValues = [3, 4, 5]
    for (let x of xValues) {
        for (let z of zValues) {
            check_q21r03_1(x, 1, z)
        }
    }
})
