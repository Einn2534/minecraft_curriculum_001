## C07 Q32 R03 窓と飾り

**C07 Q32 R03 窓と飾り**

左右の窓と看板を別の関数に分けて完成させよう。

完成するもの: 幅を変えられる商店

学ぶこと: 関数（まとめた手順）と引数、手順を部品に分ける、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q32r03 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。ガラスで pos(-3, 1, 12) から pos(-3, 2, 14) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。ガラスで pos(3, 1, 12) から pos(3, 2, 14) まで作ろう。

4. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。金ブロックで pos(-1, 3, 10) から pos(1, 3, 10) まで作ろう。

5. 緑の実行ボタンを押して、Tキーのチャットで q32r03 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
