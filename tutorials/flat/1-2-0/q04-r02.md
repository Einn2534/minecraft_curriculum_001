## C01 Q04 R02 橋の手すり

**C01 Q04 R02 橋の手すり**

橋の両側に手すりを足そう。

完成するもの: 川を渡る木の橋・手すり・開く門

学ぶこと: くり返し、左右の位置

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q04r02 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(-2, 1, 8) から pos(-2, 1, 16) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(2, 1, 8) から pos(2, 1, 16) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q04r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q04r02", function () {
    for (let z = 0; z <= 8; z++) {
        blocks.place(LOG_OAK, pos(-2, 2 - 1, (z + -1) + 9))
    }
    for (let z = 0; z <= 8; z++) {
        blocks.place(LOG_OAK, pos(2, 2 - 1, (z + -1) + 9))
    }
})

```
