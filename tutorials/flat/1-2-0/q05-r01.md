## C01 Q05 R01 金庫の箱

**C01 Q05 R01 金庫の箱**

金の金庫と扉を作ろう。

完成するもの: 番号を照合すると金の扉が開く王家の金庫

学ぶこと: くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q05r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(-2, 1, 10) から pos(2, 1, 10) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(-2, 1, 14) から pos(2, 1, 14) まで作ろう。

4. 位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(-2, 1, 10) から pos(-2, 1, 14) まで作ろう。

5. 位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(2, 1, 10) から pos(2, 1, 14) まで作ろう。

6. 金ブロックで pos(-2, 2, 10) から pos(2, 3, 14) まで作ろう。

7. 鉄ブロックで pos(0, 1, 10) から pos(0, 2, 10) まで作ろう。

8. 緑の実行ボタンを押して、Tキーのチャットで q05r01 と入力しよう。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q05r01", function () {
```
