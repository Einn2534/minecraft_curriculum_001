## C09 Q43 R03 安全な手すり

**C09 Q43 R03 安全な手すり**

同じ関数で4辺の手すりを付けて完成させよう。

完成するもの: 落下を防ぐ井戸の柵

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q43r03 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの板で pos(-3, 2, 9) から pos(3, 2, 9) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの板で pos(-3, 2, 15) から pos(3, 2, 15) まで作ろう。

4. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの板で pos(-3, 2, 9) から pos(-3, 2, 15) まで作ろう。

5. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの板で pos(3, 2, 9) から pos(3, 2, 15) まで作ろう。

6. 緑の実行ボタンを押して、Tキーのチャットで q43r03 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q43r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q43r03", function () {
    draw_q43r03(PLANKS_OAK, -3, 2, 9, 3, 2, 9)
    draw_q43r03(PLANKS_OAK, -3, 2, 15, 3, 2, 15)
    draw_q43r03(PLANKS_OAK, -3, 2, 9, -3, 2, 15)
    draw_q43r03(PLANKS_OAK, 3, 2, 9, 3, 2, 15)
})
```
