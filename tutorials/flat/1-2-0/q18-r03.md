## C04 Q18 R03 対称な飾り

**C04 Q18 R03 対称な飾り**

四すみに光る飾りを同じ関数で付けよう。

完成するもの: 水盤・柱・左右対称の飾りがある噴水

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q18r03 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。グロウストーンで pos(-3, 1, 9) から pos(-3, 1, 9) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。グロウストーンで pos(3, 1, 9) から pos(3, 1, 9) まで作ろう。

4. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。グロウストーンで pos(-3, 1, 15) から pos(-3, 1, 15) まで作ろう。

5. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。グロウストーンで pos(3, 1, 15) から pos(3, 1, 15) まで作ろう。

6. 緑の実行ボタンを押して、Tキーのチャットで q18r03 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

}
