## C04 Q18 R02 噴水の柱

**C04 Q18 R02 噴水の柱**

中央の柱と上の水を作ろう。

完成するもの: 水盤・柱・左右対称の飾りがある噴水

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q18r02 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。石レンガで pos(0, 0, 12) から pos(0, 3, 12) まで作ろう。

3. 水で pos(0, 4, 12) から pos(0, 4, 12) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q18r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q18r02(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q18r02", function () {
    draw_q18r02(STONE_BRICKS, 0, 0, 12, 0, 3, 12)
    blocks.fill(WATER, pos(0, 4, 12), pos(0, 4, 12), FillOperation.Replace)
})

```
