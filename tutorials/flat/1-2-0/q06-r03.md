## C02 Q06 R03 王家の飾り

**C02 Q06 R03 王家の飾り**

真ん中の柱と金の飾りを関数で付けよう。

完成するもの: 色ガラスで復元した城の窓

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q06r03 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。金ブロックで pos(0, 0, 13) から pos(0, 4, 13) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。金ブロックで pos(-1, 3, 13) から pos(1, 3, 13) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q06r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q06r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q06r03", function () {
    draw_q06r03(GOLD_BLOCK, 0, 0, 13, 0, 4, 13)
    draw_q06r03(GOLD_BLOCK, -1, 3, 13, 1, 3, 13)
})
```
