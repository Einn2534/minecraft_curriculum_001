## C06 Q29 R02 色を選ぶ

**C06 Q29 R02 色を選ぶ**

チャットの数字で赤・黄・青の信号を選ぼう。

完成するもの: 色を選んで発信できる緊急信号旗

学ぶこと: 関数（まとめた手順）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q29r02 に変えよう。

2. チャットコマンドに数字の引数signalを付けよう。1・2・3を受け取り、赤・黄・青を選ぶ条件を作ろう。

3. 緑の実行ボタンを押して、Tキーのチャットで q29r02 2 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q29r02", function (signal) {
    let color = RED_WOOL
    if (signal == 2) {
        color = YELLOW_WOOL
    } else if (signal == 3) {
        color = BLUE_WOOL
    }
    blocks.fill(color, pos(1, 3, 13), pos(4, 5, 13), FillOperation.Replace)
})

```
