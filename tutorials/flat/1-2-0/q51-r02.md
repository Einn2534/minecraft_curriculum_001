## C11 Q51 R02 面積を計算

**C11 Q51 R02 面積を計算**

幅5・長さ4の区画を作り、面積を計算して伝えよう。

完成するもの: 面積を計算して区画を作る畑

学ぶこと: 変数（数を入れる箱）、かけ算

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q51r02 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。土で pos(-3, -1, 11) から pos(1, -1, 14) まで作ろう。

3. 幅×長さで面積を計算し、メッセージで知らせよう。

4. 緑の実行ボタンを押して、Tキーのチャットで q51r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q51r02", function () {
    for (let x = 0; x <= 4; x++) {
        for (let z = 0; z <= 3; z++) {
            blocks.place(DIRT, pos((x + -3), 0 - 1, (z + 2) + 9))
        }
    }
    let width = 5
    let length = 4
    player.say("面積: " + (width * length))
})

```
