## C04 Q20 R03 2つの時計をそろえる

**C04 Q20 R03 2つの時計をそろえる**

左右の小さな時計も同じ時刻の色にそろえよう。

完成するもの: 時刻を読み、同じ色の表示を出す2つの時計塔

学ぶこと: 関数（まとめた手順）と引数、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q20r03 に変えよう。

2. 時刻の値を変数に保存し、昼か夜かで色を選ぼう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。石レンガで pos(-4, 0, 13) から pos(-4, 2, 13) まで作ろう。

4. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。石レンガで pos(4, 0, 13) から pos(4, 2, 13) まで作ろう。

5. 緑の実行ボタンを押して、Tキーのチャットで q20r03 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q20r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q20r03", function () {
    let value = gameplay.timeQuery(TimeQuery.DayTime)
    let color = WOOL
    if (value >= 12000) {
        color = BLUE_WOOL
    }
    let displays = [-4, 4]
    for (let x of displays) {
        blocks.place(color, pos(x, 2, 12))
    }
    player.say("今の値: " + value)
    draw_q20r03(STONE_BRICKS, -4, 0, 13, -4, 2, 13)
    draw_q20r03(STONE_BRICKS, 4, 0, 13, 4, 2, 13)
})

```
