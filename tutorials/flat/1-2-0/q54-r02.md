## C11 Q54 R02 同じ間隔の木

**C11 Q54 R02 同じ間隔の木**

間隔4で2本目の木を作ろう。

完成するもの: 間隔を計算して植える王立果樹園

学ぶこと: 関数（まとめた手順）と引数、かけ算で間隔を計算、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q54r02 に変えよう。

2. 間隔gapを4にして、1本目のx=-4に足そう。計算したtreeXを関数へ渡そう。

3. 葉の両端もtreeXを基準に、左へ1・右へ1で作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q54r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q54r02(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q54r02", function () {
    let gap = 4
    let treeX = -4 + gap
    draw_q54r02(LOG_OAK, treeX, 0, 12, treeX, 3, 12)
    builder.teleportTo(pos(treeX - 1, 4, 11))
    builder.mark()
    builder.teleportTo(pos(treeX + 1, 5, 13))
    builder.fill(LEAVES_OAK)
})

```
