## C11 Q52 R03 2列を育てる

**C11 Q52 R03 2列を育てる**

2列を耕し、土を確かめながら苗を植えよう。

完成するもの: Agentが耕して種を植える畑

学ぶこと: 二重のくり返し、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q52r03 に変えよう。

2. 調べる手順を関数にまとめよう。位置のリストをくり返し、横と奥、または横と高さの2つのくり返しを組み合わせよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q52r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function check_q52r03_1(x: number, y: number, z: number) {
    agent.teleport(pos(x, y, z + 9), SOUTH)
    agent.till(DOWN)
    if (blocks.testForBlock(FARMLAND, pos(x, -1, z + 9))) {
        blocks.place(CROPS, pos(x, 0, z + 9))
    }
}
player.onChat("q52r03", function () {
    let xValues = [-2, 0]
    let zValues = [2, 3, 4, 5]
    for (let x of xValues) {
        for (let z of zValues) {
            check_q52r03_1(x, 0, z)
        }
    }
})
```
