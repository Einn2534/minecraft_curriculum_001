## C03 Q13 R03 印刷する手順をまとめる

**C03 Q13 R03 印刷する手順をまとめる**

表示板に「AR」の形を描こう。

完成するもの: 魔法の文字を描く印刷機

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q13r03 に変えよう。

2. 1は文字を描く場所、0は空ける場所だよ。文字列のリストを行と列の二重のくり返しで読もう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの板で pos(-7, 0, 14) から pos(6, 0, 14) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q13r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q13r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q13r03", function () {
    let letters = ["0100110", "1010101", "1110110", "1010101", "1010101"]
    for (let row = 0; row < letters.length; row++) {
        for (let column = 0; column < letters[row].length; column++) {
            if (letters[row].charAt(column) == "1") {
                blocks.place(GOLD_BLOCK, pos(-6 + column, 5 - row, 14))
            }
        }
    }
    draw_q13r03(PLANKS_OAK, -7, 0, 14, 6, 0, 14)
})
```
