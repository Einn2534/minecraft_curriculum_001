## C07 Q33 R03 会計を関数にする

**C07 Q33 R03 会計を関数にする**

値段を計算する関数と表示する関数を分けよう。

完成するもの: 値段と個数を計算して表示する商人の会計台

学ぶこと: 関数（まとめた手順）と引数、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q33r03 に変えよう。

2. 数を変数に保存し、足し算かかけ算で合計を計算しよう。個数が3以上なら単価を1引こう。

3. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの板で pos(-5, 1, 13) から pos(5, 1, 13) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q33r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function price_q33r03(price: number, quantity: number): number {
    if (quantity >= 3) {
        price += -1
    }
    return price * quantity
}
function show_q33r03(total: number) {
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
}
player.onChat("q33r03", function () {
    let total = price_q33r03(4, 2)
    show_q33r03(total)
    builder.teleportTo(pos(-5, 1, 13))
    builder.mark()
    builder.teleportTo(pos(5, 1, 13))
    builder.fill(PLANKS_OAK)
})

```
