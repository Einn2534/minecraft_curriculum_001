## C08 Q38 R03 面を点検して片付ける

**C08 Q38 R03 面を点検して片付ける**

指定の干し草を調べ、Agentでこわして集めよう。

完成するもの: 清掃した厩舎

学ぶこと: 二重のくり返し、安全な場所だけをこわす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q38r03 に変えよう。

2. 調べる手順を関数にまとめよう。位置のリストをくり返し、横と奥、または横と高さの2つのくり返しを組み合わせよう。

3. 位置を1ずつ増やすくり返しを作ろう。干し草で pos(4, 0, 13) から pos(4, 0, 14) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q38r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function check_q38r03_1(x: number, y: number, z: number) {
    agent.teleport(pos(x, y - 1, z + 8), SOUTH)
    if (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
}
player.onChat("q38r03", function () {
    let xValues = [-3, -2, -1, 0, 1, 2, 3]
    let zValues = [3, 4, 5]
    for (let x of xValues) {
        for (let z of zValues) {
            check_q38r03_1(x, 1, z)
        }
    }
    for (let z = 0; z <= 1; z++) {
        blocks.place(HAY_BLOCK, pos(4, 1 - 1, (z + 4) + 9))
    }
})
```
