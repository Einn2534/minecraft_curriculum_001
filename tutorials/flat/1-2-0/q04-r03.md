## C01 Q04 R03 安全な門

**C01 Q04 R03 安全な門**

赤い警報の印があるときは門を閉じよう。

完成するもの: 川を渡る木の橋・手すり・開く門

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q04r03 に変えよう。

2. 赤い警報の印を調べ、赤なら門を閉じる「もし」を作ろう。

3. 緑の実行ボタンを押して、Tキーのチャットで q04r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q04r03", function () {
    if (blocks.testForBlock(RED_WOOL, pos(-5, 0, 11))) {
        blocks.fill(PLANKS_OAK, pos(-1, 1, 15), pos(1, 2, 15), FillOperation.Replace)
    }
})

```
