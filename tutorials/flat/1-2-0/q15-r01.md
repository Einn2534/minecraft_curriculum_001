## C03 Q15 R01 1文字を描く

**C03 Q15 R01 1文字を描く**

表示板に「A」の形を描こう。見本の足りないくり返しと位置を直そう。

完成するもの: 直した魔導書の文字

学ぶこと: 配列（順番のあるリスト）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q15r01 に変えよう。

2. 1は文字を描く場所、0は空ける場所だよ。文字列のリストを行と列の二重のくり返しで読もう。

3. 緑の実行ボタンを押して、Tキーのチャットで q15r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

デバッグは、間違いを見つけて直すことだよ。下のコードは、最後の列が足りず、高さも1段ずれているよ。まず試して、くり返しの終わりと高さを直そう。電球に直した完成例があるよ。

```typescript
player.onChat("q15r01", function () {
    let letters = ["010", "101", "111", "101", "101"]
    for (let row = 0; row < letters.length; row++) {
        for (let column = 0; column < letters[row].length - 1; column++) {
            if (letters[row].charAt(column) == "1") {
                blocks.place(GOLD_BLOCK, pos(-6 + column, 6 - row, 14))
            }
        }
    }
})
```

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。
