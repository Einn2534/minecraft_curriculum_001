## C12 Q59 R03 リストで誘導する

**C12 Q59 R03 リストで誘導する**

左の囲いの羊を右へ移そう。ほかの工房の動物は動かさないよ。

完成するもの: 羊を安全な囲いへ誘導する牧場

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q59r03 に変えよう。

2. 種類でMobを選び、さらに自分の工房の左の囲いの近くに絞って移そう。囲いの位置をリストにし、誘導する関数へ渡そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q59r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function guide_q59r03_sheep(x: number) {
    mobs.teleportToPosition(mobs.near(mobs.entitiesByType(SHEEP), pos(-5, 0, 13), 3), pos(x, 0, 13))
}
player.onChat("q59r03", function () {
    let sheepDestinations = [5]
    for (let x of sheepDestinations) {
        guide_q59r03_sheep(x)
    }
})

```
