## C04 Q20 R01 時計塔

**C04 Q20 R01 時計塔**

石の塔に金の時計の針を付けよう。

完成するもの: 時刻を読み、同じ色の表示を出す2つの時計塔

学ぶこと: くり返し、高さ

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q20r01 に変えよう。

2. 石レンガで pos(-2, 0, 13) から pos(2, 4, 14) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(0, 2, 12) から pos(0, 4, 12) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q20r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q20r01", function () {
    blocks.fill(STONE_BRICKS, pos(-2, 0, 13), pos(2, 4, 14), FillOperation.Replace)
    for (let y = 0; y <= 2; y++) {
        blocks.place(GOLD_BLOCK, pos(0, (y + 3) - 1, 3 + 9))
    }
})

```
