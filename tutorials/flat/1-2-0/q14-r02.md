## C03 Q14 R02 天候を読もう

**C03 Q14 R02 天候を読もう**

今の天候を読んで、晴れは金・雨は青・雷は赤で表示しよう。

完成するもの: 天候を読み、晴れ・雨・雷を色で表示する気象台

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q14r02 に変えよう。

2. 天候の値を変数に保存し、晴れ・雨・雷で色を選ぼう。

3. 緑の実行ボタンを押して、Tキーのチャットで q14r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q14r02", function () {
    let value = gameplay.weatherQuery()
    let color = GOLD_BLOCK
    if (value == Weather.Rain) {
        color = BLUE_WOOL
    } else if (value == Weather.Thunder) {
        color = RED_WOOL
    }
    blocks.place(color, pos(0, 3, 12))
    player.say("今の値: " + value)
})

```
