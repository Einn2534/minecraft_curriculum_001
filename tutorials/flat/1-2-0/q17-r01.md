## C04 Q17 R01 1列を片付ける

**C04 Q17 R01 1列を片付ける**

指定の丸石を調べ、Agentでこわして集めよう。

完成するもの: ごみを取り除いた広場

学ぶこと: こわす・集める、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q17r01 に変えよう。

2. まず位置を1つずつ決め、同じ操作を順につなごう。位置ごとに、Agentを1ブロック手前へ呼ぼう。前にブロックがあれば、こわす→集める。

3. 緑の実行ボタンを押して、Tキーのチャットで q17r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q17r01", function () {
    agent.teleport(pos(-1, 1 - 1, 3 + 8), SOUTH)
    if (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
    agent.teleport(pos(0, 1 - 1, 3 + 8), SOUTH)
    if (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
    agent.teleport(pos(1, 1 - 1, 3 + 8), SOUTH)
    if (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
})
```
