## C09 Q43 R01 柵の土台

**C09 Q43 R01 柵の土台**

囲いの形を作ろう。

完成するもの: 落下を防ぐ井戸の柵

学ぶこと: 変数（数を入れる箱）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q43r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-3, 0, 9) から pos(3, 0, 9) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-3, 0, 15) から pos(3, 0, 15) まで作ろう。

4. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-3, 0, 9) から pos(-3, 0, 15) まで作ろう。

5. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(3, 0, 9) から pos(3, 0, 15) まで作ろう。

6. 緑の実行ボタンを押して、Tキーのチャットで q43r01 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q43r01", function () {
    for (let x = 0; x <= 6; x++) {
        blocks.place(STONE_BRICKS, pos((x + -3), 1 - 1, 0 + 9))
    }
    for (let x = 0; x <= 6; x++) {
        blocks.place(STONE_BRICKS, pos((x + -3), 1 - 1, 6 + 9))
    }
    for (let z = 0; z <= 6; z++) {
        blocks.place(STONE_BRICKS, pos(-3, 1 - 1, z + 9))
    }
    for (let z = 0; z <= 6; z++) {
        blocks.place(STONE_BRICKS, pos(3, 1 - 1, z + 9))
    }
})
```
