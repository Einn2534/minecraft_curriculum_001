## C05 Q25 R03 開く・閉じる

**C05 Q25 R03 開く・閉じる**

openで開いて判定し、closeで閉じてもう一度判定しよう。

完成するもの: 開く・閉じるを切り替える2つの水門

学ぶこと: 状態を記録する、関数（まとめた手順）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」を2つ用意し、q25r03open と q25r03close にしよう。

2. チャットで q25r03open → NPCで判定 → q25r03close → NPCで判定、の順に試そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q25r03open と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

player.onChat("q25r03", function () {
})
