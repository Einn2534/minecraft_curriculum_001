## C02 Q06 R02 色ガラス

**C02 Q06 R02 色ガラス**

左右に青と赤の色ガラスを入れよう。

完成するもの: 色ガラスで復元した城の窓

学ぶこと: 二重のくり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q06r02 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。青いガラスで pos(-3, 0, 13) から pos(-1, 4, 13) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。赤いガラスで pos(1, 0, 13) から pos(3, 4, 13) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q06r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q06r02", function () {
    for (let x = 0; x <= 2; x++) {
        for (let y = 0; y <= 4; y++) {
            blocks.place(BLUE_STAINED_GLASS, pos((x + -3), (y + 1) - 1, 4 + 9))
        }
    }
    for (let x = 0; x <= 2; x++) {
        for (let y = 0; y <= 4; y++) {
            blocks.place(RED_STAINED_GLASS, pos((x + 1), (y + 1) - 1, 4 + 9))
        }
    }
})

```
