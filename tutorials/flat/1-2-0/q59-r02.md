## C12 Q59 R02 種類で選ぶ

**C12 Q59 R02 種類で選ぶ**

左の囲いの羊を右へ移そう。ほかの工房の動物は動かさないよ。

完成するもの: 羊を安全な囲いへ誘導する牧場

学ぶこと: 種類と場所で選ぶ、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q59r02 に変えよう。

2. 種類でMobを選び、さらに自分の工房の左の囲いの近くに絞って移そう。左の金の目印と、移す先が空いていることを確かめる条件を入れよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q59r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q59r02", function () {
    if (blocks.testForBlock(GOLD_BLOCK, pos(-5, -1, 13)) && blocks.testForBlock(AIR, pos(5, 0, 13))) {
        mobs.teleportToPosition(mobs.near(mobs.entitiesByType(SHEEP), pos(-5, 0, 13), 3), pos(5, 0, 13))
    }
})

```
