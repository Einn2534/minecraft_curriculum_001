## C05 Q24 R02 橋の柱

**C05 Q24 R02 橋の柱**

関数で橋の柱を4本作ろう。

完成するもの: 荷車が渡れる幅の広い橋

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q24r02 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。石レンガで pos(-3, 0, 9) から pos(-3, 2, 9) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。石レンガで pos(3, 0, 9) から pos(3, 2, 9) まで作ろう。

4. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。石レンガで pos(-3, 0, 15) から pos(-3, 2, 15) まで作ろう。

5. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。石レンガで pos(3, 0, 15) から pos(3, 2, 15) まで作ろう。

6. 緑の実行ボタンを押して、Tキーのチャットで q24r02 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。
