## C06 Q26 R03 面をまとめて点検する

**C06 Q26 R03 面をまとめて点検する**

石レンガがないところを調べて直そう。

完成するもの: 穴と弱い部分を直した城壁

学ぶこと: 二重のくり返し、直した数を数える

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q26r03 に変えよう。

2. 調べる手順を関数にまとめよう。位置のリストをくり返し、横と奥、または横と高さの2つのくり返しを組み合わせよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q26r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function check_q26r03_1(x: number, y: number, z: number): number {
    if (!blocks.testForBlock(STONE_BRICKS, pos(x, y - 1, z + 9))) {
        blocks.place(STONE_BRICKS, pos(x, y - 1, z + 9))
        return 1
    }
    return 0
}
player.onChat("q26r03", function () {
    let repaired = 0
    let xValues = [-3, -2, -1, 0, 1, 2, 3]
    let yValues = [1, 2, 3]
    for (let x of xValues) {
        for (let y of yValues) {
            repaired += check_q26r03_1(x, y, 3)
        }
    }
    player.say("直した数: " + repaired)
})
```
