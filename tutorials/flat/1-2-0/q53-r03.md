## C11 Q53 R03 渡れる橋

**C11 Q53 R03 渡れる橋**

水路の上に橋を付け、畑へ歩けるようにしよう。

完成するもの: 畑へ水を届ける灌漑路

学ぶこと: 関数（まとめた手順）、Builder、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q53r03 に変えよう。

2. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの板で pos(-1, 0, 12) から pos(1, 0, 14) まで作ろう。

3. 緑の実行ボタンを押して、Tキーのチャットで q53r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q53r03", function () {
    builder.teleportTo(pos(-1, 0, 12))
    builder.mark()
    builder.teleportTo(pos(1, 0, 14))
    builder.fill(PLANKS_OAK)
})

```
