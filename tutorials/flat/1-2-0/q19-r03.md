## C04 Q19 R03 2つのグループ

**C04 Q19 R03 2つのグループ**

村人とニワトリを別々に呼び、合計を表示しよう。

完成するもの: 市民を数えて人数を棒グラフにする調査所

学ぶこと: 配列（順番のあるリスト）、集計・足し算

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q19r03 に変えよう。

2. 2を変数に入れ、くり返しでニワトリを呼ぼう。

3. 数を変数に保存し、足し算かかけ算で合計を計算しよう。

4. 緑の実行ボタンを押して、Tキーのチャットで q19r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q19r03", function () {
    let count = 2
    for (let number = 0; number < count; number++) {
        mobs.spawn(CHICKEN, pos(5, 0, 13))
    }
    let groups = [3, 2]
    let total = 0
    for (let group of groups) {
        total += group
    }
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(0 + item, 0, 10))
    }
})

```
