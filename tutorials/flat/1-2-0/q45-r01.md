## C09 Q45 R01 灯りを作る

**C09 Q45 R01 灯りを作る**

時刻を読み、昼は白・夜は青の灯りを付けよう。

完成するもの: 時間で色が変わる夜間灯

学ぶこと: くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q45r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(-4, 0, 12) から pos(-4, 1, 12) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(-2, 0, 12) から pos(-2, 1, 12) まで作ろう。

4. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(0, 0, 12) から pos(0, 1, 12) まで作ろう。

5. 時刻の値を変数に保存し、昼か夜かで色を選ぼう。

6. 緑の実行ボタンを押して、Tキーのチャットで q45r01 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q45r01", function () {
    for (let y = 0; y <= 1; y++) {
        blocks.place(LOG_OAK, pos(-4, (y + 1) - 1, 3 + 9))
    }
    for (let y = 0; y <= 1; y++) {
        blocks.place(LOG_OAK, pos(-2, (y + 1) - 1, 3 + 9))
    }
    for (let y = 0; y <= 1; y++) {
        blocks.place(LOG_OAK, pos(0, (y + 1) - 1, 3 + 9))
    }
    let value = gameplay.timeQuery(TimeQuery.DayTime)
    let color = WOOL
    if (value >= 12000) {
        color = BLUE_WOOL
    }
    blocks.place(color, pos(-4, 2, 12))
    blocks.place(color, pos(-2, 2, 12))
    blocks.place(color, pos(0, 2, 12))
    player.say("今の値: " + value)
})

```
