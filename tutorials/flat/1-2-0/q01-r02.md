## C01 Q01 R02 旗の布を広げよう

**C01 Q01 R02 旗の布を広げよう**

旗柱の右に、赤い旗の布と青いふちを付けよう。

完成するもの: 旗柱・赤い旗・金の王家の印がついた王旗

学ぶこと: くり返し、高さと横の位置

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q01r02 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。赤い羊毛で pos(1, 4, 12) から pos(4, 6, 12) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。青い羊毛で pos(1, 3, 12) から pos(4, 3, 12) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q01r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q01r02", function () {
    for (let x = 0; x <= 3; x++) {
        for (let y = 0; y <= 2; y++) {
            blocks.place(RED_WOOL, pos((x + 1), (y + 5) - 1, 3 + 9))
        }
    }
    for (let x = 0; x <= 3; x++) {
        blocks.place(BLUE_WOOL, pos((x + 1), 4 - 1, 3 + 9))
    }
})

```
