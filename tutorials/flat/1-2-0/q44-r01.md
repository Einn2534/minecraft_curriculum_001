## C09 Q44 R01 1文字を描く

**C09 Q44 R01 1文字を描く**

表示板に「1」の形を描こう。

完成するもの: 住居番号を描く表示板

学ぶこと: 配列（順番のあるリスト）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q44r01 に変えよう。

2. 1は文字を描く場所、0は空ける場所だよ。文字列のリストを行と列の二重のくり返しで読もう。

3. 緑の実行ボタンを押して、Tキーのチャットで q44r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q44r01", function () {
    let letters = ["010", "110", "010", "010", "111"]
    for (let row = 0; row < letters.length; row++) {
        for (let column = 0; column < letters[row].length; column++) {
            if (letters[row].charAt(column) == "1") {
                blocks.place(BLUE_WOOL, pos(-6 + column, 5 - row, 14))
            }
        }
    }
})

```
