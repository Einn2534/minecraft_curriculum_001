## C11 Q52 R01 土を耕す

**C11 Q52 R01 土を耕す**

Agentで土の1列を耕そう。

完成するもの: Agentが耕して種を植える畑

学ぶこと: Agentで耕す、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q52r01 に変えよう。

2. まず位置を1つずつ決め、同じ操作を順につなごう。土の位置を決めて、Agentで下の土を耕そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q52r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q52r01", function () {
    agent.teleport(pos(-2, 0, 2 + 9), SOUTH)
    agent.till(DOWN)
    agent.teleport(pos(-2, 0, 3 + 9), SOUTH)
    agent.till(DOWN)
    agent.teleport(pos(-2, 0, 4 + 9), SOUTH)
    agent.till(DOWN)
    agent.teleport(pos(-2, 0, 5 + 9), SOUTH)
    agent.till(DOWN)
})

```
