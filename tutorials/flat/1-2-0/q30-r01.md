## C06 Q30 R01 柵の土台

**C06 Q30 R01 柵の土台**

囲いの形を作ろう。

完成するもの: 城を守る木の防衛柵

学ぶこと: 変数（数を入れる箱）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q30r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-5, 0, 7) から pos(5, 0, 7) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-5, 0, 17) から pos(5, 0, 17) まで作ろう。

4. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-5, 0, 7) から pos(-5, 0, 17) まで作ろう。

5. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(5, 0, 7) から pos(5, 0, 17) まで作ろう。

6. 緑の実行ボタンを押して、Tキーのチャットで q30r01 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。
