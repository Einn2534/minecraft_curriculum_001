## C05 Q25 R02 2つの水門

**C05 Q25 R02 2つの水門**

左右の水門を関数で開こう。

完成するもの: 開く・閉じるを切り替える2つの水門

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q25r02 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。pos(-4, 0, 13) から pos(-2, 1, 13) までを空けよう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。pos(2, 0, 13) から pos(4, 1, 13) までを空けよう。

4. 緑の実行ボタンを押して、Tキーのチャットで q25r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q25r02(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q25r02", function () {
    draw_q25r02(AIR, -4, 0, 13, -2, 1, 13)
    draw_q25r02(AIR, 2, 0, 13, 4, 1, 13)
})

```
