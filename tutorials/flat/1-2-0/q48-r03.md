## C10 Q48 R03 選んだ場所を調べる

**C10 Q48 R03 選んだ場所を調べる**

花壇の各場所に、ポピーかタンポポをくじ引きで植えよう。

完成するもの: 種類をくじ引きで選ぶ花壇

学ぶこと: 配列（順番のあるリスト）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q48r03 に変えよう。

2. 候補をリストにして、乱数で番号を選ぼう。範囲は0から「リストの長さ−1」だよ。

3. 緑の実行ボタンを押して、Tキーのチャットで q48r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q48r03", function () {
    let places = [-6, -3, 0, 3, 6]
    for (let x of places) {
        if (blocks.testForBlock(GRASS, pos(x, -1, 13))) {
            if (randint(0, 1) == 0) {
                blocks.place(POPPY, pos(x, 0, 13))
            } else {
                blocks.place(YELLOW_FLOWER, pos(x, 0, 13))
            }
        }
    }
})

```
