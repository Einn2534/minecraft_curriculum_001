## C01 Q05 R02 暗号で開けよう

**C01 Q05 R02 暗号で開けよう**

暗号が7なら、鉄の扉を開けよう。

完成するもの: 番号を照合すると金の扉が開く王家の金庫

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q05r02 に変えよう。

2. 暗号を変数に入れよう。正しい数字と一致したときだけ金庫を開こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q05r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q05r02", function () {
    let password = 7
    if (password == 7) {
        blocks.fill(AIR, pos(0, 1, 10), pos(0, 2, 10), FillOperation.Replace)
    }
})

```
