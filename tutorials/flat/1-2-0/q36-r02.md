## C08 Q36 R02 列で分ける

**C08 Q36 R02 列で分ける**

見本の金と鉄を調べ、同じ種類を右の棚に分けよう。

完成するもの: 合格品を分けた鍛冶の検査台

学ぶこと: 条件（もし〜なら）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q36r02 に変えよう。

2. 見本を調べる位置をリストにしよう。金なら金の棚、そうでなければ鉄の棚に置こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q36r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q36r02", function () {
    let points = [[-5, 1, 1], [-5, 1, 2], [-5, 1, 3]]
    for (let point of points) {
        if (blocks.testForBlock(GOLD_BLOCK, pos(point[0], 0, point[2] + 9))) {
            blocks.place(GOLD_BLOCK, pos(4, 0, point[2] + 9))
        } else {
            blocks.place(IRON_BLOCK, pos(4, 0, point[2] + 9))
        }
    }
})

```
