## C08 Q40 R01 床とカウンター

**C08 Q40 R01 床とカウンター**

変数で幅を決め、床とカウンターを作ろう。

完成するもの: 床・柱・屋根を組み立てる設計機

学ぶこと: 変数（数を入れる箱）、Builder、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q40r01 に変えよう。

2. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの板で pos(-3, 0, 10) から pos(3, 0, 15) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。石レンガで pos(-2, 1, 11) から pos(2, 1, 11) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q40r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q40r01(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q40r01", function () {
    builder.teleportTo(pos(-3, 0, 10))
    builder.mark()
    builder.teleportTo(pos(3, 0, 15))
    builder.fill(PLANKS_OAK)
    draw_q40r01(STONE_BRICKS, -2, 1, 11, 2, 1, 11)
})
```
