## C03 Q14 R01 観測台

**C03 Q14 R01 観測台**

石の観測台と空を見る窓を作ろう。

完成するもの: 天候を読み、晴れ・雨・雷を色で表示する気象台

学ぶこと: 座標、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q14r01 に変えよう。

2. 石レンガで pos(-2, 0, 12) から pos(2, 1, 14) まで作ろう。

3. ガラスで pos(-2, 2, 12) から pos(2, 2, 12) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q14r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q14r01", function () {
    blocks.fill(STONE_BRICKS, pos(-2, 0, 12), pos(2, 1, 14), FillOperation.Replace)
    blocks.fill(GLASS, pos(-2, 2, 12), pos(2, 2, 12), FillOperation.Replace)
})

```
