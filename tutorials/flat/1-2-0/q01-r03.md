## C01 Q01 R03 王家の印を入れよう

**C01 Q01 R03 王家の印を入れよう**

王家の印の手順を関数にまとめて、王旗を完成させよう。

完成するもの: 旗柱・赤い旗・金の王家の印がついた王旗

学ぶこと: くり返し、関数（まとめた手順）、2つの手順を組み合わせる

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q01r03 に変えよう。

2. 手順を1つの関数にまとめ、チャットコマンドから呼び出そう。位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(2, 5, 12) から pos(4, 5, 12) まで作ろう。

3. 手順を1つの関数にまとめ、チャットコマンドから呼び出そう。位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(3, 4, 12) から pos(3, 6, 12) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q01r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function pattern_q01r03_1() {
    for (let x = 0; x <= 2; x++) {
        blocks.place(GOLD_BLOCK, pos((x + 2), 6 - 1, 3 + 9))
    }
}
function pattern_q01r03_2() {
    for (let y = 0; y <= 2; y++) {
        blocks.place(GOLD_BLOCK, pos(3, (y + 5) - 1, 3 + 9))
    }
}
player.onChat("q01r03", function () {
    pattern_q01r03_1()
    pattern_q01r03_2()
})

```
