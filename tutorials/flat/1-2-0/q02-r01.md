## C01 Q02 R01 紋章のふち

**C01 Q02 R01 紋章のふち**

青い正方形のふちを作ろう。

完成するもの: 玉座へ続く左右対称の床の紋章

学ぶこと: くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q02r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。青い羊毛で pos(-3, 0, 9) から pos(3, 0, 9) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。青い羊毛で pos(-3, 0, 15) から pos(3, 0, 15) まで作ろう。

4. 位置を1ずつ増やすくり返しを作ろう。青い羊毛で pos(-3, 0, 9) から pos(-3, 0, 15) まで作ろう。

5. 位置を1ずつ増やすくり返しを作ろう。青い羊毛で pos(3, 0, 9) から pos(3, 0, 15) まで作ろう。

6. 緑の実行ボタンを押して、Tキーのチャットで q02r01 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q02r01", function () {
    for (let x = 0; x <= 6; x++) {
        blocks.place(BLUE_WOOL, pos((x + -3), 1 - 1, 0 + 9))
    }
    for (let x = 0; x <= 6; x++) {
        blocks.place(BLUE_WOOL, pos((x + -3), 1 - 1, 6 + 9))
    }
    for (let z = 0; z <= 6; z++) {
        blocks.place(BLUE_WOOL, pos(-3, 1 - 1, z + 9))
    }
    for (let z = 0; z <= 6; z++) {
        blocks.place(BLUE_WOOL, pos(3, 1 - 1, z + 9))
    }
})

```
