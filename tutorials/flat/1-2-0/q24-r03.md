## C05 Q24 R03 手すりと屋根

**C05 Q24 R03 手すりと屋根**

引数で長さを指定し、手すりと屋根を仕上げよう。

完成するもの: 荷車が渡れる幅の広い橋

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q24r03 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(-3, 2, 8) から pos(-3, 2, 16) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(3, 2, 8) から pos(3, 2, 16) まで作ろう。

4. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの板で pos(-3, 3, 8) から pos(3, 3, 16) まで作ろう。

5. 緑の実行ボタンを押して、Tキーのチャットで q24r03 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q24r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q24r03", function () {
    draw_q24r03(LOG_OAK, -3, 2, 8, -3, 2, 16)
    draw_q24r03(LOG_OAK, 3, 2, 8, 3, 2, 16)
    builder.teleportTo(pos(-3, 3, 8))
    builder.mark()
    builder.teleportTo(pos(3, 3, 16))
    builder.fill(PLANKS_OAK)
})
```
