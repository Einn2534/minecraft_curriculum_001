## C11 Q51 R03 道と2区画

**C11 Q51 R03 道と2区画**

道を挟んで2つの畑を関数で作ろう。

完成するもの: 面積を計算して区画を作る畑

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q51r03 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。土で pos(3, -1, 11) から pos(5, -1, 14) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。丸石で pos(2, -1, 10) から pos(2, -1, 15) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q51r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q51r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q51r03", function () {
    draw_q51r03(DIRT, 3, -1, 11, 5, -1, 14)
    draw_q51r03(COBBLESTONE, 2, -1, 10, 2, -1, 15)
})

```
