## C04 Q20 R02 時刻の表示

**C04 Q20 R02 時刻の表示**

ゲームの時刻を読み、昼は白・夜は青の表示を出そう。

完成するもの: 時刻を読み、同じ色の表示を出す2つの時計塔

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q20r02 に変えよう。

2. 時刻の値を変数に保存し、昼か夜かで色を選ぼう。

3. 緑の実行ボタンを押して、Tキーのチャットで q20r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q20r02", function () {
    let value = gameplay.timeQuery(TimeQuery.DayTime)
    let color = WOOL
    if (value >= 12000) {
        color = BLUE_WOOL
    }
    blocks.place(color, pos(0, 1, 12))
    player.say("今の値: " + value)
})

```
