## C01 Q02 R03 交互の模様

**C01 Q02 R03 交互の模様**

四すみに赤と白の市松模様を足そう。

完成するもの: 玉座へ続く左右対称の床の紋章

学ぶこと: 二重のくり返し、余りで色を選ぶ

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q02r03 に変えよう。

2. 横と奥の2つのくり返しを重ねよう。x+zを2で割った余りで色を選ぼう。

3. 緑の実行ボタンを押して、Tキーのチャットで q02r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q02r03", function () {
    for (let x = 0; x <= 4; x++) {
        for (let z = 0; z <= 4; z++) {
            if ((x + -2) != 0 && (z + 1) != 3) {
                if (((x + -2) + (z + 1)) % 2 == 0) {
                    blocks.place(RED_WOOL, pos((x + -2), 0, (z + 1) + 9))
                } else {
                    blocks.place(WOOL, pos((x + -2), 0, (z + 1) + 9))
                }
            }
        }
    }
})

```
