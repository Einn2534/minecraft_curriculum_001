## C06 Q28 R02 矢のイベント

**C06 Q28 R02 矢のイベント**

矢を放ったら的のまんなかを金に変えよう。

完成するもの: 弓を使うと反応する3つの的

学ぶこと: 矢を放ったときのイベント、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q28r02 に変えよう。

2. 「矢を放ったとき」の中に的の色を変える手順をつなごう。

3. 緑の実行ボタンを押して、Tキーのチャットで q28r02 と入力しよう。

4. 入口の金の床から、用意した弓で矢を放とう。矢を放ったイベントで的の色が変わるよ。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q28r02", function () {
    eventOrigin = player.position()
    eventReady = true
})
player.onArrowShot(function () {
    if (eventReady) {
        blocks.fill(GOLD_BLOCK, positions.add(eventOrigin, pos(0, 2, 13)), positions.add(eventOrigin, pos(0, 2, 13)), FillOperation.Replace)
    }
})

```
