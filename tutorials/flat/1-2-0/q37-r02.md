## C08 Q37 R02 場所を調べて片付ける

**C08 Q37 R02 場所を調べて片付ける**

2本の木の幹を切り出して、落ちた木材を集めよう。

完成するもの: 切り出した木材と切り株

学ぶこと: 条件（もし〜なら）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q37r02 に変えよう。

2. 位置のリストをくり返し、Agentを1ブロック手前へ呼ぼう。前にブロックがあれば、こわす→集める。

3. 緑の実行ボタンを押して、Tキーのチャットで q37r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q37r02", function () {
    let points = [[-3, 1, 4], [-3, 2, 4], [-3, 3, 4], [-3, 4, 4], [0, 1, 4], [0, 2, 4], [0, 3, 4], [0, 4, 4]]
    for (let point of points) {
        agent.teleport(pos(point[0], point[1] - 1, point[2] + 8), SOUTH)
        if (agent.detect(AgentDetection.Block, FORWARD)) {
            agent.destroy(FORWARD)
            agent.collectAll()
        }
    }
})

```
