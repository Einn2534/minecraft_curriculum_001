## C06 Q29 R01 信号の旗柱

**C06 Q29 R01 信号の旗柱**

信号旗の柱と赤い旗を作ろう。

完成するもの: 色を選んで発信できる緊急信号旗

学ぶこと: 関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q29r01 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(0, 0, 13) から pos(0, 5, 13) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。赤い羊毛で pos(1, 3, 13) から pos(4, 5, 13) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q29r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q29r01(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q29r01", function () {
    draw_q29r01(LOG_OAK, 0, 0, 13, 0, 5, 13)
    for (let x = 0; x <= 3; x++) {
        for (let y = 0; y <= 2; y++) {
            blocks.place(RED_WOOL, pos((x + 1), (y + 4) - 1, 4 + 9))
        }
    }
})

```
