## 課題

縦横の値から長方形の柵と1か所の門を作る

工房中心から [[-6, 1, -6], [-6, 1, 6], [-4, 1, -6], [-4, 1, 6], [-6, 1, -4], [6, 1, -4], [-2, 1, -6], [-2, 1, 6], [-6, 1, -2], [6, 1, -2], [0, 1, -6], [0, 1, 6], [-6, 1, 0], [6, 1, 0], [2, 1, -6], [2, 1, 6], [-6, 1, 2], [6, 1, 2], [4, 1, -6], [4, 1, 6], [-6, 1, 4], [6, 1, 4], [6, 1, -6], [6, 1, 6]] の位置に苔むした石レンガを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q56 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q56", function () {
    agent.setSlot(1)
    agent.teleport(pos(-6, 1, 3), EAST)
    for (let side = 0; side < 4; side++) {
        for (let step = 0; step < 6; step++) {
            agent.place(DOWN)
            agent.move(FORWARD, 2)
        }
        agent.turn(RIGHT_TURN)
    }
})
```
