# Q46 パン屋の配達路

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

配達先の座標配列を巡り、各家で荷物を1個ずつ下ろす

工房中心から [[-4, 2, 4], [-2, 4, 4], [0, 3, 4], [2, 1, 4], [4, 5, 4]] の位置に金ブロックを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q46 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q46", function () {
    agent.setSlot(1)
    agent.teleport(pos(-4, 1, 12), SOUTH)
    agent.place(FORWARD)
    agent.teleport(pos(-2, 3, 12), SOUTH)
    agent.place(FORWARD)
    agent.teleport(pos(0, 2, 12), SOUTH)
    agent.place(FORWARD)
    agent.teleport(pos(2, 0, 12), SOUTH)
    agent.place(FORWARD)
    agent.teleport(pos(4, 4, 12), SOUTH)
    agent.place(FORWARD)
})
```
