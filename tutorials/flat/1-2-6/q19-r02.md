## C04 / Q04 / R02 人数の表示

**C04 / Q04 / R02 人数の表示**

村人3人と、同じ数の金の棒グラフを作ろう。

完成するもの: 呼んだ人数と金の棒グラフを照らし合わせる市民調査所

学ぶこと: 変数（数を入れる箱）、くり返し、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q19r02 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に villagerType と入力して「OK」を押すと、villagerType のブロックが出るよ。

4. チャットコマンド「q19r02」の中に、「変数villagerTypeを「すべての 村人」（モブ）にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に villagerGroup と入力して「OK」を押すと、villagerGroup のブロックが出るよ。

6. チャットコマンド「q19r02」の中に、「変数villagerGroupを「ある位置から一定の範囲内にいるvillagerType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。

7. チャットコマンド「q19r02」の中に、「villagerGroup」（モブ）をつなごう。

8. チャットコマンド「q19r02」の中に、「くりかえし3回」（ループ）をつなごう。

9. 3回のくり返しの中に、「村人 を~-5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

10. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に price と入力して「OK」を押すと、price のブロックが出るよ。

11. チャットコマンド「q19r02」の中に、「変数priceを3にする」（変数）をつなごう。

12. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に quantity と入力して「OK」を押すと、quantity のブロックが出るよ。

13. チャットコマンド「q19r02」の中に、「変数quantityを1にする」（変数）をつなごう。

14. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に total と入力して「OK」を押すと、total のブロックが出るよ。

15. チャットコマンド「q19r02」の中に、「変数totalをprice * quantityにする」（変数）をつなごう。

16. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に endX と入力して「OK」を押すと、endX のブロックが出るよ。

17. チャットコマンド「q19r02」の中に、「変数endXを2 + total - 1にする」（変数）をつなごう。

18. チャットコマンド「q19r02」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

19. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~2 ~0 ~13、「範囲の終わり」は ~endX ~0 ~13 にするよ。

20. 緑の実行ボタンを押して、Tキーのチャットで q19r02 と入力しよう。

21. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q19r02", function () {
    let villagerType = mobs.entitiesByType(VILLAGER)
    let villagerGroup = mobs.near(villagerType, pos(-5, 0, 13), 3)
    mobs.kill(villagerGroup)
    for (let number = 0; number < 3; number++) {
        mobs.spawn(VILLAGER, pos(-5, 0, 13))
    }
    let price = 3
    let quantity = 1
    let total = price * quantity
    let endX = 2 + total - 1
    blocks.fill(GOLD_BLOCK, pos(2, 0, 13), pos(endX, 0, 13), FillOperation.Replace)
})

```
