## C07 / Q02 / R02 繰り返しで仕上げる

**C07 / Q02 / R02 繰り返しで仕上げる**

幅を変えられる商店の見本を仕上げよう。Agentで2か所に材料を置こう。同じ操作をリストの繰り返しで動かそう。

完成するもの: 幅を変えられる商店

学ぶこと: Agentの材料と位置、順次処理、位置のリスト、繰り返し

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q32r02 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q32r02」の中に、「エージェントのスロット番号 1 を 有効にする」（エージェント）をつなごう。

4. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に places と入力して「OK」を押すと、places のブロックが出るよ。

5. チャットコマンド「q32r02」の中に、「変数placesを「配列を作成」に ~-3 ~5 ~10、~-3 ~5 ~11 を順に入れるにする」（変数）をつなごう。

6. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に place と入力して「OK」を押すと、place のブロックが出るよ。

7. チャットコマンド「q32r02」の中に、「配列placesの値を変数placeに入れてくりかえす」（ループ）をつなごう。

8. 配列placesのくり返し（place）の中に、「エージェントを place へ 南 (Zのプラス方向) 向きにテレポートさせる」（エージェント）をつなごう。

9. 配列placesのくり返し（place）の中に、「エージェントに 下 へ 置かせる」（エージェント）をつなごう。

10. 緑の実行ボタンを押して、Tキーのチャットで q32r02 と入力しよう。

11. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q32r02", function () {
    agent.setSlot(1)
    let places = [pos(-3, 5, 10), pos(-3, 5, 11)]
    for (let place of places) {
        agent.teleport(place, SOUTH)
        agent.place(DOWN)
    }
})
```
