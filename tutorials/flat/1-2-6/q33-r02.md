## C07 / Q03 / R02 まとめ買い

**C07 / Q03 / R02 まとめ買い**

3個以上なら単価を1引き、代金を計算しよう。

完成するもの: 値段と個数を計算して表示する商人の会計台

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q33r02 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に price と入力して「OK」を押すと、price のブロックが出るよ。

4. チャットコマンド「q33r02」の中に、「変数priceを3にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に quantity と入力して「OK」を押すと、quantity のブロックが出るよ。

6. チャットコマンド「q33r02」の中に、「変数quantityを3にする」（変数）をつなごう。

7. チャットコマンド「q33r02」の中に、「もし quantity >= 3 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 条件の「なら」の中に、「変数priceを-1だけ増やす」（変数）をつなごう。

9. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に total と入力して「OK」を押すと、total のブロックが出るよ。

10. チャットコマンド「q33r02」の中に、「変数totalをprice * quantityにする」（変数）をつなごう。

11. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に endX と入力して「OK」を押すと、endX のブロックが出るよ。

12. チャットコマンド「q33r02」の中に、「変数endXを-4 + total - 1にする」（変数）をつなごう。

13. チャットコマンド「q33r02」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

14. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~-4 ~0 ~12、「範囲の終わり」は ~endX ~0 ~12 にするよ。

15. 緑の実行ボタンを押して、Tキーのチャットで q33r02 と入力しよう。

16. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q33r02", function () {
    let price = 3
    let quantity = 3
    if (quantity >= 3) {
        price += -1
    }
    let total = price * quantity
    let endX = -4 + total - 1
    blocks.fill(GOLD_BLOCK, pos(-4, 0, 12), pos(endX, 0, 12), FillOperation.Replace)
})

```
