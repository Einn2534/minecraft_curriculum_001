## C02 / Q05 / R03 3区間の迷宮の出口

**C02 / Q05 / R03 3区間の迷宮の出口**

はじめの位置から3か所を順にたどり、ゴールへ移動しよう。

完成するもの: 迷宮の出口の道とゴール

学ぶこと: 座標を足す、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q10r03 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に origin と入力して「OK」を押すと、origin のブロックが出るよ。

4. チャットコマンド「q10r03」の中に、「変数originを「プレイヤーの位置」（プレイヤー）にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に stop1 と入力して「OK」を押すと、stop1 のブロックが出るよ。

6. チャットコマンド「q10r03」の中に、「変数stop1を「origin + ~-6 ~0 ~14」（ポジション）にする」（変数）をつなごう。

7. チャットコマンド「q10r03」の中に、「stop1 にテレポートする」（プレイヤー）をつなごう。

8. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に stop2 と入力して「OK」を押すと、stop2 のブロックが出るよ。

9. チャットコマンド「q10r03」の中に、「変数stop2を「origin + ~6 ~0 ~14」（ポジション）にする」（変数）をつなごう。

10. チャットコマンド「q10r03」の中に、「stop2 にテレポートする」（プレイヤー）をつなごう。

11. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に stop3 と入力して「OK」を押すと、stop3 のブロックが出るよ。

12. チャットコマンド「q10r03」の中に、「変数stop3を「origin + ~6 ~0 ~16」（ポジション）にする」（変数）をつなごう。

13. チャットコマンド「q10r03」の中に、「stop3 にテレポートする」（プレイヤー）をつなごう。

14. チャットコマンド「q10r03」の中に、「コマンド "function grandfort/course/arrival/r030" を 実行する」（プレイヤー）をつなごう。

15. 緑の実行ボタンを押して、Tキーのチャットで q10r03 と入力しよう。

16. 「ゴールに到着！」が出たら、緑の道で工房NPCへ戻ろう。到着の記録は残るよ。

17. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q10r03", function () {
    let origin = player.position()
    let stop1 = positions.add(origin, pos(-6, 0, 14))
    player.teleport(stop1)
    let stop2 = positions.add(origin, pos(6, 0, 14))
    player.teleport(stop2)
    let stop3 = positions.add(origin, pos(6, 0, 16))
    player.teleport(stop3)
    player.execute("function grandfort/course/arrival/r030")
})

```
