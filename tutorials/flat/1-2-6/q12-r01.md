## C03 / Q02 / R01 見本を調べる

**C03 / Q02 / R01 見本を調べる**

1つの見本を調べ、同じ材料を棚に置こう。

完成するもの: 素材別の錬金棚

学ぶこと: 条件（もし〜なら）、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q12r01 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に gold1 と入力して「OK」を押すと、gold1 のブロックが出るよ。

4. チャットコマンド「q12r01」の中に、「変数gold1を「金ブロック が~-5 ~0 ~10 に存在する」（ブロック）にする」（変数）をつなごう。

5. チャットコマンド「q12r01」の中に、「もし gold1 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

6. 条件の「なら」の中に、「金ブロック を~4 ~0 ~10 に置く」（ブロック）をつなごう。

7. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

8. 「でなければ」の中に、「鉄ブロック を~4 ~0 ~10 に置く」（ブロック）をつなごう。

9. 緑の実行ボタンを押して、Tキーのチャットで q12r01 と入力しよう。

10. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q12r01", function () {
    let gold1 = blocks.testForBlock(GOLD_BLOCK, pos(-5, 0, 10))
    if (gold1) {
        blocks.place(GOLD_BLOCK, pos(4, 0, 10))
    } else {
        blocks.place(IRON_BLOCK, pos(4, 0, 10))
    }
})
```
