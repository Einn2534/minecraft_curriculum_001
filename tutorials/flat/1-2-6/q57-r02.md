## C12 / Q02 / R02 種類で選ぶ

**C12 / Q02 / R02 種類で選ぶ**

金の目印があることを確かめてから移そう。

完成するもの: 牛と羊を別の囲いへ分ける牧場

学ぶこと: 種類と場所で選ぶ、条件（もし〜なら）、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q57r02 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に cowType と入力して「OK」を押すと、cowType のブロックが出るよ。

4. チャットコマンド「q57r02」の中に、「変数cowTypeを「すべての ウシ」（モブ）にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に cowGroup と入力して「OK」を押すと、cowGroup のブロックが出るよ。

6. チャットコマンド「q57r02」の中に、「変数cowGroupを「ある位置から一定の範囲内にいるcowType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。

7. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に cowMarker と入力して「OK」を押すと、cowMarker のブロックが出るよ。

8. チャットコマンド「q57r02」の中に、「変数cowMarkerを「金ブロック が~-5 ~-1 ~13 に存在する」（ブロック）にする」（変数）をつなごう。

9. チャットコマンド「q57r02」の中に、「もし cowMarker なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

10. 条件の「なら」の中に、「cowGroup を~5 ~0 ~13 にテレポートさせる」（モブ）をつなごう。

11. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に sheepType と入力して「OK」を押すと、sheepType のブロックが出るよ。

12. チャットコマンド「q57r02」の中に、「変数sheepTypeを「すべての 羊」（モブ）にする」（変数）をつなごう。

13. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に sheepGroup と入力して「OK」を押すと、sheepGroup のブロックが出るよ。

14. チャットコマンド「q57r02」の中に、「変数sheepGroupを「ある位置から一定の範囲内にいるsheepType 位置~0 ~0 ~6 半径3」（モブ）にする」（変数）をつなごう。

15. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に sheepMarker と入力して「OK」を押すと、sheepMarker のブロックが出るよ。

16. チャットコマンド「q57r02」の中に、「変数sheepMarkerを「金ブロック が~0 ~-1 ~6 に存在する」（ブロック）にする」（変数）をつなごう。

17. チャットコマンド「q57r02」の中に、「もし sheepMarker なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

18. 条件の「なら」の中に、「sheepGroup を~0 ~0 ~15 にテレポートさせる」（モブ）をつなごう。

19. 緑の実行ボタンを押して、Tキーのチャットで q57r02 と入力しよう。

20. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q57r02", function () {
    let cowType = mobs.entitiesByType(COW)
    let cowGroup = mobs.near(cowType, pos(-5, 0, 13), 3)
    let cowMarker = blocks.testForBlock(GOLD_BLOCK, pos(-5, -1, 13))
    if (cowMarker) {
        mobs.teleportToPosition(cowGroup, pos(5, 0, 13))
    }
    let sheepType = mobs.entitiesByType(SHEEP)
    let sheepGroup = mobs.near(sheepType, pos(0, 0, 6), 3)
    let sheepMarker = blocks.testForBlock(GOLD_BLOCK, pos(0, -1, 6))
    if (sheepMarker) {
        mobs.teleportToPosition(sheepGroup, pos(0, 0, 15))
    }
})

```
