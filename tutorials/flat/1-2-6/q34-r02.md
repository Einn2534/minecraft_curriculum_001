## C07 / Q04 / R02 3つから選ぶ

**C07 / Q04 / R02 3つから選ぶ**

3つの候補のリストの長さから、くじの最大番号を計算しよう。番号は0から始まるよ。

完成するもの: くじ引きで小包を隠す倉庫

学ぶこと: 乱数、順番に動かす、変数（値を覚える箱）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q34r02 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に places と入力して「OK」を押すと、places のブロックが出るよ。

4. チャットコマンド「q34r02」の中に、「変数placesを「配列を作成」に -4、0、4 を順に入れるにする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に last と入力して「OK」を押すと、last のブロックが出るよ。

6. チャットコマンド「q34r02」の中に、「変数lastを「配列の長さ places」 - 1にする」（変数）をつなごう。

7. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に choice と入力して「OK」を押すと、choice のブロックが出るよ。

8. チャットコマンド「q34r02」の中に、「変数choiceを「ランダムな数字を選択: 0 から last まで」（計算）にする」（変数）をつなごう。

9. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に x と入力して「OK」を押すと、x のブロックが出るよ。

10. チャットコマンド「q34r02」の中に、「変数xを「placesのchoice番目の値」にする」（変数）をつなごう。

11. チャットコマンド「q34r02」の中に、「チェスト を~x ~0 ~13 に置く」（ブロック）をつなごう。

12. 緑の実行ボタンを押して、Tキーのチャットで q34r02 と入力しよう。

13. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q34r02", function () {
    let places = [-4, 0, 4]
    let last = places.length - 1
    let choice = randint(0, last)
    let x = places[choice]
    blocks.place(CHEST, pos(x, 0, 13))
})

```
