## C03 / Q04 / R01 観測台

**C03 / Q04 / R01 観測台**

石の台と空を見る窓を作ろう。

完成するもの: 天候を読み、晴れ・雨・雷を色で表示する気象台

学ぶこと: 座標、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q14r01 を入力した時」（プレイヤー）を置こう。

3. チャットコマンド「q14r01」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

4. いまつないだ「ブロックを並べる」の材料を「石レンガ」にしよう。「範囲の始まり」は ~-2 ~0 ~12、「範囲の終わり」は ~2 ~1 ~14 にするよ。

5. チャットコマンド「q14r01」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

6. いまつないだ「ブロックを並べる」の材料を「ガラス」にしよう。「範囲の始まり」は ~-2 ~2 ~12、「範囲の終わり」は ~2 ~2 ~12 にするよ。

7. 緑の実行ボタンを押して、Tキーのチャットで q14r01 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

player.onChat("q14r01", function () {
    blocks.fill(STONE_BRICKS, pos(-2, 0, 12), pos(2, 1, 14), FillOperation.Replace)
    blocks.fill(GLASS, pos(-2, 2, 12), pos(2, 2, 12), FillOperation.Replace)
})
