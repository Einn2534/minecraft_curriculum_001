## C06 / Q03 / R03 ランダムな的

**C06 / Q03 / R03 ランダムな的**

矢を放ったとき、くじで3つの的から1つを選んで金にしよう。

完成するもの: 弓を使うと反応する3つの的

学ぶこと: 乱数（くじ引き）、条件（もし〜なら）、順番に動かす、変数（値を覚える箱）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

「配列を作成」（配列）は、数や位置を順に入れるリストだよ。＋で入力する場所を増やそう。最初の番号は0、次は1だよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に eventOrigin と入力して「OK」を押すと、eventOrigin のブロックが出るよ。

3. 「変数eventOriginを「プレイヤーの位置」（プレイヤー）にする」（変数）をつなごう。

4. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に eventReady と入力して「OK」を押すと、eventReady のブロックが出るよ。

5. 「変数eventReadyを偽にする」（変数）をつなごう。

6. 「チャットコマンド q28r03 を入力した時」（プレイヤー）を置こう。

7. チャットコマンド「q28r03」の中に、「変数eventOriginを「プレイヤーの位置」（プレイヤー）にする」（変数）をつなごう。

8. チャットコマンド「q28r03」の中に、「変数eventReadyを真にする」（変数）をつなごう。

9. チャットコマンド「q28r03」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

10. いまつないだ「ブロックを並べる」の材料を「白色の羊毛」にしよう。「範囲の始まり」は ~-6 ~1 ~14、「範囲の終わり」は ~-4 ~3 ~14 にするよ。

11. チャットコマンド「q28r03」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

12. いまつないだ「ブロックを並べる」の材料を「白色の羊毛」にしよう。「範囲の始まり」は ~4 ~1 ~14、「範囲の終わり」は ~6 ~3 ~14 にするよ。

13. 「プレイヤーが矢を放った時」（プレイヤー）を、チャットコマンドの外に置こう。

14. イベントの中に、「もし eventReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

15. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に places と入力して「OK」を押すと、places のブロックが出るよ。

16. 条件の「なら」の中に、「変数placesを「配列を作成」に -5、0、5 を順に入れるにする」（変数）をつなごう。

17. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に last と入力して「OK」を押すと、last のブロックが出るよ。

18. 条件の「なら」の中に、「変数lastを「配列の長さ places」 - 1にする」（変数）をつなごう。

19. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に choice と入力して「OK」を押すと、choice のブロックが出るよ。

20. 条件の「なら」の中に、「変数choiceを「ランダムな数字を選択: 0 から last まで」（計算）にする」（変数）をつなごう。

21. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に x と入力して「OK」を押すと、x のブロックが出るよ。

22. 条件の「なら」の中に、「変数xを「placesのchoice番目の値」にする」（変数）をつなごう。

23. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に eventPoint1 と入力して「OK」を押すと、eventPoint1 のブロックが出るよ。

24. 条件の「なら」の中に、「変数eventPoint1を「eventOrigin + ~x ~2 ~13」（ポジション）にする」（変数）をつなごう。

25. 条件の「なら」の中に、「金ブロック をeventPoint1 に置く」（ブロック）をつなごう。

26. 緑の実行ボタンを押して、Tキーのチャットで q28r03 と入力しよう。

27. 入口の金の床から、用意した弓で矢を放とう。矢を放ったイベントで的の色が変わるよ。

28. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q28r03", function () {
    eventOrigin = player.position()
    eventReady = true
    blocks.fill(WOOL, pos(-6, 1, 14), pos(-4, 3, 14), FillOperation.Replace)
    blocks.fill(WOOL, pos(4, 1, 14), pos(6, 3, 14), FillOperation.Replace)
})
player.onArrowShot(function () {
    if (eventReady) {
        let places = [-5, 0, 5]
        let last = places.length - 1
        let choice = randint(0, last)
        let x = places[choice]
        let eventPoint1 = positions.add(eventOrigin, pos(x, 2, 13))
        blocks.place(GOLD_BLOCK, eventPoint1)
    }
})
```
