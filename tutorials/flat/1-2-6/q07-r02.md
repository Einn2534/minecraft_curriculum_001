## C02 / Q02 / R02 鐘を並べる

**C02 / Q02 / R02 鐘を並べる**

鐘を並べ、3つの高さの音を順に鳴らそう。

完成するもの: 音符ブロックが並ぶ鐘楼とチャットで鳴る旋律

学ぶこと: くり返し、音を鳴らす、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q07r02 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に offset と入力して「OK」を押すと、offset のブロックが出るよ。

4. チャットコマンド「q07r02」の中に、「変数offsetを0～4に変えてくりかえす」（ループ）をつなごう。

5. くり返し（offset）の中に、「音符ブロック を~-2 + offset ~1 ~12 に置く」（ブロック）をつなごう。

6. チャットコマンド「q07r02」の中に、「コマンド "playsound note.bell @s ~ ~ ~ 1 1" を 実行する」（プレイヤー）をつなごう。

7. チャットコマンド「q07r02」の中に、「一時停止（ミリ秒） 300」（ループ）をつなごう。

8. チャットコマンド「q07r02」の中に、「コマンド "playsound note.bell @s ~ ~ ~ 1 2" を 実行する」（プレイヤー）をつなごう。

9. チャットコマンド「q07r02」の中に、「一時停止（ミリ秒） 300」（ループ）をつなごう。

10. チャットコマンド「q07r02」の中に、「コマンド "playsound note.bell @s ~ ~ ~ 1 3" を 実行する」（プレイヤー）をつなごう。

11. チャットコマンド「q07r02」の中に、「一時停止（ミリ秒） 300」（ループ）をつなごう。

12. 緑の実行ボタンを押して、Tキーのチャットで q07r02 と入力しよう。

13. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q07r02", function () {
    for (let offset = 0; offset <= 4; offset++) {
        blocks.place(NOTE_BLOCK, pos(-2 + offset, 1, 12))
    }
    player.execute("playsound note.bell @s ~ ~ ~ 1 1")
    loops.pause(300)
    player.execute("playsound note.bell @s ~ ~ ~ 1 2")
    loops.pause(300)
    player.execute("playsound note.bell @s ~ ~ ~ 1 3")
    loops.pause(300)
})

```
