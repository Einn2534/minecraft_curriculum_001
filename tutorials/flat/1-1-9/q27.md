## Q27 夜警の巡回路

**Q27 夜警の巡回路**

Agentを動かして、奥の金の床のまんなかへ連れていこう。

自分のAgentが、奥の金の床のまんなかに着いたらクリア。ブロックを置く課題ではないよ。

コードの位置は、入口の金の床に立った自分を基準にするよ。

1. 新しい「チャットコマンド」を置いて、run を q27 に変えよう。

2. Agentを位置 (-8,0,1)・南向きへ呼ぼう。

3. 「前に12ブロックすすむ」→「ひだりまわり」→「前に8ブロックすすむ」をつなごう。

4. 入口の金の床に立とう。緑の実行ボタンを押して、Tキーのチャットで q27 と入力しよう。

5. できたら工房NPCを右クリックし、「Q27 夜警の巡回路」の画面にある「完成した・判定」を押そう。床の印はこわさないでね。

ヒントは電球を押してみよう。

```blocks
player.onChat("q27", function () {
    agent.teleport(pos(-8, 0, 1), SOUTH)
    agent.move(FORWARD, 12)
    agent.turn(LEFT_TURN)
    agent.move(FORWARD, 8)
})
```
