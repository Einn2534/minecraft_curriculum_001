## C09 / Q05 / R02 欠けた灯りを見つける

**C09 / Q05 / R02 欠けた灯りを見つける**

![今回の完成イメージ](https://raw.githubusercontent.com/Einn2534/minecraft_curriculum_001/54a56103b578190f11d77c8477664af4d2f2108e/assets/flat/1-2-8/q45-r02.png)

まず図を見て、作る形・場所・数を考えよう。図と見比べながら組み立てよう。

灯りの列を4か所に広げ、同じ色にしよう。

完成するもの: 時間で色が変わる夜間灯

学ぶこと: 条件（もし〜なら）、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q45r02 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に value と入力して「OK」を押すと、value のブロックが出るよ。

4. チャットコマンド「q45r02」の中に、「変数valueを「現在の時間」（ゲームプレイ）にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に color と入力して「OK」を押すと、color のブロックが出るよ。

6. チャットコマンド「q45r02」の中に、「変数colorを白色の羊毛にする」（変数）をつなごう。

7. チャットコマンド「q45r02」の中に、「もし value >= 12000 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 条件の「なら」の中に、「変数colorを青色の羊毛にする」（変数）をつなごう。

9. チャットコマンド「q45r02」の中に、「color を~-4 ~2 ~12 に置く」（ブロック）をつなごう。

10. チャットコマンド「q45r02」の中に、「color を~-2 ~2 ~12 に置く」（ブロック）をつなごう。

11. チャットコマンド「q45r02」の中に、「color を~0 ~2 ~12 に置く」（ブロック）をつなごう。

12. チャットコマンド「q45r02」の中に、「color を~2 ~2 ~12 に置く」（ブロック）をつなごう。

13. 緑の実行ボタンを押して、Tキーのチャットで q45r02 と入力しよう。

14. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

#### ~ tutorialhint

ヒントは電球を押してみよう。

```blocks
player.onChat("q45r02", function () {
    let value = gameplay.timeQuery(TimeQuery.DayTime)
    let color = WOOL
    if (value >= 12000) {
        color = BLUE_WOOL
    }
    blocks.place(color, pos(-4, 2, 12))
    blocks.place(color, pos(-2, 2, 12))
    blocks.place(color, pos(0, 2, 12))
    blocks.place(color, pos(2, 2, 12))
})

```
