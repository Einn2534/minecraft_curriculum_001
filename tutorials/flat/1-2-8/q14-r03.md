まず図を見て、作る形・場所・数を考えよう。図と見比べながら組み立てよう。

同じ天気の色を3か所に表示して、屋根を付けよう。

完成するもの: 天候を読み、晴れ・雨・雷を色で表示する気象台

学ぶこと: 条件（もし〜なら）、順番に動かす、変数（値を覚える箱）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q14r03 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に value と入力して「OK」を押すと、value のブロックが出るよ。

4. チャットコマンド「q14r03」の中に、「変数valueを「現在の天気」（ゲームプレイ）にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に color と入力して「OK」を押すと、color のブロックが出るよ。

6. チャットコマンド「q14r03」の中に、「変数colorを金ブロックにする」（変数）をつなごう。

7. チャットコマンド「q14r03」の中に、「もし value  =  Weather.Rain なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

8. 条件の「なら」の中に、「変数colorを青色の羊毛にする」（変数）をつなごう。

9. チャットコマンド「q14r03」の中に、「でなければもし value  =  Weather.Thunder なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

10. 条件の「なら」の中に、「変数colorを赤色の羊毛にする」（変数）をつなごう。

11. チャットコマンド「q14r03」の中に、「color を~-1 ~3 ~12 に置く」（ブロック）をつなごう。

12. チャットコマンド「q14r03」の中に、「color を~0 ~3 ~12 に置く」（ブロック）をつなごう。

13. チャットコマンド「q14r03」の中に、「color を~1 ~3 ~12 に置く」（ブロック）をつなごう。

14. チャットコマンド「q14r03」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

15. いまつないだ「ブロックを並べる」の材料を「オークの板材」にしよう。「範囲の始まり」は ~-3 ~4 ~12、「範囲の終わり」は ~3 ~4 ~14 にするよ。

16. 緑の実行ボタンを押して、Tキーのチャットで q14r03 と入力しよう。

17. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

#### ~ tutorialhint

ヒントは電球を押してみよう。

```blocks
player.onChat("q14r03", function () {
    let value = gameplay.weatherQuery()
    let color = GOLD_BLOCK
    if (value == Weather.Rain) {
        color = BLUE_WOOL
    } else if (value == Weather.Thunder) {
        color = RED_WOOL
    }
    blocks.place(color, pos(-1, 3, 12))
    blocks.place(color, pos(0, 3, 12))
    blocks.place(color, pos(1, 3, 12))
    blocks.fill(PLANKS_OAK, pos(-3, 4, 12), pos(3, 4, 14), FillOperation.Replace)
})

```
