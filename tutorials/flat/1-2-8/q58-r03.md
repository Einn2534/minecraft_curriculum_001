## C12 / Q03 / R03 繁殖計画ボード

**C12 / Q03 / R03 繁殖計画ボード**

![今回の完成イメージ](https://raw.githubusercontent.com/Einn2534/minecraft_curriculum_001/54a56103b578190f11d77c8477664af4d2f2108e/assets/flat/1-2-8/q58-r03.png)

まず図を見て、作る形・場所・数を考えよう。図と見比べながら組み立てよう。

6頭の組数と余りを計算しよう。余りの有無でメッセージを分け、計画ボードを仕上げよう。

完成するもの: 親の組数と必要なえさを計算する繁殖計画の牧場

学ぶこと: 変数（数を入れる箱）、割り算・余り、順番に動かす、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q58r03 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に cowType と入力して「OK」を押すと、cowType のブロックが出るよ。

4. チャットコマンド「q58r03」の中に、「変数cowTypeを「すべての ウシ」（モブ）にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に cowGroup と入力して「OK」を押すと、cowGroup のブロックが出るよ。

6. チャットコマンド「q58r03」の中に、「変数cowGroupを「ある位置から一定の範囲内にいるcowType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。

7. チャットコマンド「q58r03」の中に、「cowGroup」（モブ）をつなごう。

8. チャットコマンド「q58r03」の中に、「くりかえし6回」（ループ）をつなごう。

9. 6回のくり返しの中に、「ウシ を~-5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

10. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に heads と入力して「OK」を押すと、heads のブロックが出るよ。

11. チャットコマンド「q58r03」の中に、「変数headsを6にする」（変数）をつなごう。

12. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に total と入力して「OK」を押すと、total のブロックが出るよ。

13. チャットコマンド「q58r03」の中に、「変数totalを「整数の÷」に heads と 2 を入れるにする」（変数）をつなごう。

14. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に leftOver と入力して「OK」を押すと、leftOver のブロックが出るよ。

15. チャットコマンド「q58r03」の中に、「変数leftOverをheads % 2にする」（変数）をつなごう。

16. チャットコマンド「q58r03」の中に、「もし leftOver > 0 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

17. 条件の「なら」の中に、「メッセージ 「文字列をつなげる」に "組に入らない頭数: " と leftOver を入れる を 送信する」（プレイヤー）をつなごう。

18. 「もし」の＋を押して「でなければ」を出そう。次の手順は「でなければ」の中に入れるよ。

19. 「でなければ」の中に、「メッセージ "すべての牛が2頭の組になったよ。" を 送信する」（プレイヤー）をつなごう。

20. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に endX と入力して「OK」を押すと、endX のブロックが出るよ。

21. チャットコマンド「q58r03」の中に、「変数endXを2 + total - 1にする」（変数）をつなごう。

22. チャットコマンド「q58r03」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

23. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~2 ~0 ~11、「範囲の終わり」は ~endX ~0 ~11 にするよ。

24. チャットコマンド「q58r03」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

25. いまつないだ「ブロックを並べる」の材料を「干草の俵」にしよう。「範囲の始まり」は ~3 ~0 ~12、「範囲の終わり」は ~5 ~0 ~12 にするよ。

26. 緑の実行ボタンを押して、Tキーのチャットで q58r03 と入力しよう。

27. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q58r03", function () {
    let cowType = mobs.entitiesByType(COW)
    let cowGroup = mobs.near(cowType, pos(-5, 0, 13), 3)
    mobs.kill(cowGroup)
    for (let number = 0; number < 6; number++) {
        mobs.spawn(COW, pos(-5, 0, 13))
    }
    let heads = 6
    let total = Math.idiv(heads, 2)
    let leftOver = heads % 2
    if (leftOver > 0) {
        player.say("組に入らない頭数: " + leftOver)
    } else {
        player.say("すべての牛が2頭の組になったよ。")
    }
    let endX = 2 + total - 1
    blocks.fill(GOLD_BLOCK, pos(2, 0, 11), pos(endX, 0, 11), FillOperation.Replace)
    blocks.fill(HAY_BLOCK, pos(3, 0, 12), pos(5, 0, 12), FillOperation.Replace)
})

```
