完成するもの: 羊を安全な囲いへ誘導する牧場

学ぶこと: 順番に動かす、変数（値を覚える箱）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q59r03 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に sheepType と入力して「OK」を押すと、sheepType のブロックが出るよ。

4. チャットコマンド「q59r03」の中に、「変数sheepTypeを「すべての 羊」（モブ）にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に sheepGroup と入力して「OK」を押すと、sheepGroup のブロックが出るよ。

6. チャットコマンド「q59r03」の中に、「変数sheepGroupを「ある位置から一定の範囲内にいるsheepType 位置~-5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。

7. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に sheepMarker と入力して「OK」を押すと、sheepMarker のブロックが出るよ。

8. チャットコマンド「q59r03」の中に、「変数sheepMarkerを「金ブロック が~-5 ~-1 ~13 に存在する」（ブロック）にする」（変数）をつなごう。

9. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に sheepSafe と入力して「OK」を押すと、sheepSafe のブロックが出るよ。

10. チャットコマンド「q59r03」の中に、「変数sheepSafeを「空気 が~5 ~0 ~13 に存在する」（ブロック）にする」（変数）をつなごう。

11. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に sheepReady と入力して「OK」を押すと、sheepReady のブロックが出るよ。

12. チャットコマンド「q59r03」の中に、「変数sheepReadyをsheepMarker  かつ  sheepSafeにする」（変数）をつなごう。

13. チャットコマンド「q59r03」の中に、「もし sheepReady なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

14. 条件の「なら」の中に、「sheepGroup を~5 ~0 ~13 にテレポートさせる」（モブ）をつなごう。

15. 緑の実行ボタンを押して、Tキーのチャットで q59r03 と入力しよう。

16. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

ヒントは電球を押してみよう。

player.onChat("q59r03", function () {
    let sheepType = mobs.entitiesByType(SHEEP)
    let sheepGroup = mobs.near(sheepType, pos(-5, 0, 13), 3)
    let sheepMarker = blocks.testForBlock(GOLD_BLOCK, pos(-5, -1, 13))
    let sheepSafe = blocks.testForBlock(AIR, pos(5, 0, 13))
    let sheepReady = sheepMarker && sheepSafe
    if (sheepReady) {
        mobs.teleportToPosition(sheepGroup, pos(5, 0, 13))
    }
})
