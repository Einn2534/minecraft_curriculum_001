## C04 / Q04 / R03 2つのグループ

**C04 / Q04 / R03 2つのグループ**

![今回の完成イメージ](https://raw.githubusercontent.com/Einn2534/minecraft_curriculum_001/54a56103b578190f11d77c8477664af4d2f2108e/assets/flat/1-2-8/q19-r03.png)

まず図を見て、作る形・場所・数を考えよう。図と見比べながら組み立てよう。

村人とニワトリの数を足し、合計が5のときにグラフを作ろう。

完成するもの: 呼んだ人数と金の棒グラフを照らし合わせる市民調査所

学ぶこと: 集計・足し算、順番に動かす、変数（値を覚える箱）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。位置のブロックの「~」の数は、左からx（東西）・y（上下）・z（南北）。そこに立った自分から何ブロックはなすかを入れるよ。

左のツールボックスは、カテゴリ名を押すとブロックが出るよ。見つからないカテゴリは「高度なブロック」を開こう。「変数」で名前を作ってから、その名前のブロックを使おう。数の入力に英字の名前があるときは、「変数」から同じ名前の小さなブロックをはめるよ。「変数を〜にする」の名前は▼から選べるよ。

計算がある入力には、「計算」の「+」「-」「×」など、式と同じ記号を選んだブロックをはめよう。左と右に、式の左の値と右の値を入れるよ。

1. 前の課題のコードは保存しておこう。この課題では新しいプロジェクトを使い、次の順に作ろう。位置は入口の金の床に立った自分が基準だよ。

2. 「チャットコマンド q19r03 を入力した時」（プレイヤー）を置こう。

3. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に chickenType と入力して「OK」を押すと、chickenType のブロックが出るよ。

4. チャットコマンド「q19r03」の中に、「変数chickenTypeを「すべての ニワトリ」（モブ）にする」（変数）をつなごう。

5. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に chickenGroup と入力して「OK」を押すと、chickenGroup のブロックが出るよ。

6. チャットコマンド「q19r03」の中に、「変数chickenGroupを「ある位置から一定の範囲内にいるchickenType 位置~5 ~0 ~13 半径3」（モブ）にする」（変数）をつなごう。

7. チャットコマンド「q19r03」の中に、「chickenGroup」（モブ）をつなごう。

8. チャットコマンド「q19r03」の中に、「くりかえし2回」（ループ）をつなごう。

9. 2回のくり返しの中に、「ニワトリ を~5 ~0 ~13 にスポーンさせる」（モブ）をつなごう。

10. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に price と入力して「OK」を押すと、price のブロックが出るよ。

11. チャットコマンド「q19r03」の中に、「変数priceを3にする」（変数）をつなごう。

12. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に quantity と入力して「OK」を押すと、quantity のブロックが出るよ。

13. チャットコマンド「q19r03」の中に、「変数quantityを2にする」（変数）をつなごう。

14. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に total と入力して「OK」を押すと、total のブロックが出るよ。

15. チャットコマンド「q19r03」の中に、「変数totalをprice + quantityにする」（変数）をつなごう。

16. ツールボックスの「変数」を開き、「変数を追加する...」を押そう。名前に endX と入力して「OK」を押すと、endX のブロックが出るよ。

17. チャットコマンド「q19r03」の中に、「変数endXを0 + total - 1にする」（変数）をつなごう。

18. チャットコマンド「q19r03」の中に、「もし total  =  5 なら」（論理）を置こう。条件の場所に、表示した条件のブロックを入れよう。

19. 条件の「なら」の中に、「ブロックを並べる」（ブロック）をつなごう。「モード」は「置き換え (replace)」を選ぼう。

20. いまつないだ「ブロックを並べる」の材料を「金ブロック」にしよう。「範囲の始まり」は ~0 ~0 ~10、「範囲の終わり」は ~endX ~0 ~10 にするよ。

21. 緑の実行ボタンを押して、Tキーのチャットで q19r03 と入力しよう。

22. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q19r03", function () {
    let chickenType = mobs.entitiesByType(CHICKEN)
    let chickenGroup = mobs.near(chickenType, pos(5, 0, 13), 3)
    mobs.kill(chickenGroup)
    for (let number = 0; number < 2; number++) {
        mobs.spawn(CHICKEN, pos(5, 0, 13))
    }
    let price = 3
    let quantity = 2
    let total = price + quantity
    let endX = 0 + total - 1
    if (total == 5) {
        blocks.fill(GOLD_BLOCK, pos(0, 0, 10), pos(endX, 0, 10), FillOperation.Replace)
    }
})
```
