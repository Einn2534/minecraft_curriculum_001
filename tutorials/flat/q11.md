# Q11 座標術の試験

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

相対座標と絶対座標を使い分けて複数の印を置く

工房中心から [[-5, 1, 3], [0, 1, 5], [5, 1, 3]] の位置にレンガを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q11 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q11", function () {
    agent.setSlot(1)
    agent.teleport(pos(-5, 1, 12), EAST)
    agent.place(DOWN)
    agent.teleport(pos(0, 1, 14), EAST)
    agent.place(DOWN)
    agent.teleport(pos(5, 1, 12), EAST)
    agent.place(DOWN)
})
```
