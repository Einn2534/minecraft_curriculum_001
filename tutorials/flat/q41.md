# Q41 石畳の穴探し

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

道路を走査し、穴だけを同じ舗装材で埋める

工房中心から [[-5, 1, 3], [0, 1, 5], [5, 1, 3]] の位置に石レンガを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q41 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q41", function () {
    agent.setSlot(1)
    agent.teleport(pos(-5, 1, 12), EAST)
    agent.place(DOWN)
    agent.teleport(pos(0, 1, 14), EAST)
    agent.place(DOWN)
    agent.teleport(pos(5, 1, 12), EAST)
    agent.place(DOWN)
})
```
