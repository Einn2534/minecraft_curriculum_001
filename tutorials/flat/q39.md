# Q39 薬棚の在庫整理

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

素材を種類別スロットへ移し、不足数を表示する

Agentを奥の金ブロック中央へ移動します。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q39 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q39", function () {
    agent.setSlot(1)
    agent.teleport(pos(-8, 0, 1), SOUTH)
    agent.move(FORWARD, 12)
    agent.turn(LEFT_TURN)
    agent.move(FORWARD, 10)
})
```
