# Q16 消えた街灯

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

街灯列を検査し、欠けた光源だけを置き直す

工房中心から [[-4, 2, 4], [-2, 4, 4], [0, 3, 4], [2, 1, 4], [4, 5, 4]] の位置に苔むした石レンガを置きます。床の印は残してください。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q16 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q16", function () {
    agent.setSlot(1)
    agent.teleport(pos(-4, 1, 12), SOUTH)
    agent.place(FORWARD)
    agent.teleport(pos(-2, 3, 12), SOUTH)
    agent.place(FORWARD)
    agent.teleport(pos(0, 2, 12), SOUTH)
    agent.place(FORWARD)
    agent.teleport(pos(2, 0, 12), SOUTH)
    agent.place(FORWARD)
    agent.teleport(pos(4, 4, 12), SOUTH)
    agent.place(FORWARD)
})
```
