## C03 / Q04 / R03 予報パネル｜3/10 相対座標を確かめる

**［3/10］相対座標を確かめる**

**自分の足元が出発点（原点）**。`~0 ~0 ~0` は、今立っている自分の足元です。3つの数は、そこから「どの方向に、何ブロック離れた場所か」を表します。

| 数の場所 | ＋で進む方向 | −で進む方向 |
| --- | --- | --- |
| 左：x | 東 | 西 |
| 真ん中：y | 上 | 下 |
| 右：z | 南 | 北 |

**南を向いているとき**は、前へ進むと右端のzが増え、上へ行くと真ん中のyが増え、左（東）へ行くと左端のxが増えます。右（西）へ行くとxは減ります。

**向きを変えても、東・西・南・北の基準は変わりません。**「前・左」は南を向いた場合の覚え方です。

**この課題の例：** `~-1 ~3 ~12` は、足元から西へ1ブロック、上へ3ブロック、南へ12ブロックの場所です。0の方向には動かしません。

**実行する前に入口の金の床へ戻ろう。** 自分が移動すると、相対座標の出発点も移動します。Agentを動かす `前・後ろ・左・右` はAgent自身の向きが基準なので、位置のx・y・zと分けて考えよう。

```blocks
player.onChat("q14r03", function () {
    let value = gameplay.weatherQuery()
    let color = GOLD_BLOCK
    if (value == Weather.Rain) {
        color = BLUE_WOOL
    } else if (value == Weather.Thunder) {
        color = RED_WOOL
    }
    blocks.place(color, pos(-1, 3, 12))
    blocks.place(color, pos(0, 3, 12))
    blocks.place(color, pos(1, 3, 12))
    blocks.fill(PLANKS_OAK, pos(-3, 4, 12), pos(3, 4, 14), FillOperation.Replace)
})

```
