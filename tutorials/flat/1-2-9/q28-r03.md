## C06 / Q03 / R03 ランダムな的｜3/13 相対座標を確かめる

**［3/13］相対座標を確かめる**

**自分の足元が出発点（原点）**。`~0 ~0 ~0` は、今立っている自分の足元です。3つの数は、そこから「どの方向に、何ブロック離れた場所か」を表します。

| 数の場所 | ＋で進む方向 | −で進む方向 |
| --- | --- | --- |
| 左：x | 東 | 西 |
| 真ん中：y | 上 | 下 |
| 右：z | 南 | 北 |

**南を向いているとき**は、前へ進むと右端のzが増え、上へ行くと真ん中のyが増え、左（東）へ行くと左端のxが増えます。右（西）へ行くとxは減ります。

**向きを変えても、東・西・南・北の基準は変わりません。**「前・左」は南を向いた場合の覚え方です。

**この課題の例：** `~-6 ~1 ~14` は、足元から西へ6ブロック、上へ1ブロック、南へ14ブロックの場所です。0の方向には動かしません。

**実行する前に入口の金の床へ戻ろう。** 自分が移動すると、相対座標の出発点も移動します。Agentを動かす `前・後ろ・左・右` はAgent自身の向きが基準なので、位置のx・y・zと分けて考えよう。

## C06 / Q03 / R03 ランダムな的｜4/13 ブロックを探す

**［4/13］ブロックを探す**

**ブロックの探し方**

左のカテゴリ名を押してブロックを探します。見つからないカテゴリは「高度なブロック」を開こう。

数の入力に英字の名前があるときは「変数」から同じ名前を入れます。「変数を〜にする」の名前は▼から選びます。

式には「計算」の同じ記号（+・−・×など）を選び、左右の値を入れよう。

「配列を作成」は順番に値を入れるリストです。＋で入力欄を増やせます。最初の番号は0、次は1です。

**完成コードの見本**

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q28r03", function () {
    eventOrigin = player.position()
    eventReady = true
    blocks.fill(WOOL, pos(-6, 1, 14), pos(-4, 3, 14), FillOperation.Replace)
    blocks.fill(WOOL, pos(4, 1, 14), pos(6, 3, 14), FillOperation.Replace)
})
player.onArrowShot(function () {
    if (eventReady) {
        let places = [-5, 0, 5]
        let last = places.length - 1
        let choice = randint(0, last)
        let x = places[choice]
        let eventPoint1 = positions.add(eventOrigin, pos(x, 2, 13))
        blocks.place(GOLD_BLOCK, eventPoint1)
    }
})
```
