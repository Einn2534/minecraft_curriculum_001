## C11 / Q05 / R03 面をまとめて点検する｜3/12 相対座標を確かめる

**［3/12］相対座標を確かめる**

**自分の足元が出発点（原点）**。`~0 ~0 ~0` は、今立っている自分の足元です。3つの数は、そこから「どの方向に、何ブロック離れた場所か」を表します。

| 数の場所 | ＋で進む方向 | −で進む方向 |
| --- | --- | --- |
| 左：x | 東 | 西 |
| 真ん中：y | 上 | 下 |
| 右：z | 南 | 北 |

**南を向いているとき**は、前へ進むと右端のzが増え、上へ行くと真ん中のyが増え、左（東）へ行くと左端のxが増えます。右（西）へ行くとxは減ります。

**向きを変えても、東・西・南・北の基準は変わりません。**「前・左」は南を向いた場合の覚え方です。

**この課題の例：** `~-3 ~0 ~12` は、足元から西へ3ブロック、南へ12ブロックの場所です。0の方向には動かしません。

**実行する前に入口の金の床へ戻ろう。** 自分が移動すると、相対座標の出発点も移動します。Agentを動かす `前・後ろ・左・右` はAgent自身の向きが基準なので、位置のx・y・zと分けて考えよう。

```blocks
player.onChat("q55r03", function () {
    let repaired = 0
    let found1 = blocks.testForBlock(CROPS, pos(-3, 0, 12))
    if (!found1) {
        blocks.place(CROPS, pos(-3, 0, 12))
        repaired += 1
    }
    let found2 = blocks.testForBlock(CROPS, pos(0, 0, 13))
    if (!found2) {
        blocks.place(CROPS, pos(0, 0, 13))
        repaired += 1
    }
    let found3 = blocks.testForBlock(CROPS, pos(3, 0, 14))
    if (!found3) {
        blocks.place(CROPS, pos(3, 0, 14))
        repaired += 1
    }
    player.say("直した数: " + repaired)
})

```
