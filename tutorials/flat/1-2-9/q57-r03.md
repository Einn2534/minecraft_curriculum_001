## C12 / Q02 / R03 安全を確かめて移す｜3/14 相対座標を確かめる

**［3/14］相対座標を確かめる**

**自分の足元が出発点（原点）**。`~0 ~0 ~0` は、今立っている自分の足元です。3つの数は、そこから「どの方向に、何ブロック離れた場所か」を表します。

| 数の場所 | ＋で進む方向 | −で進む方向 |
| --- | --- | --- |
| 左：x | 東 | 西 |
| 真ん中：y | 上 | 下 |
| 右：z | 南 | 北 |

**南を向いているとき**は、前へ進むと右端のzが増え、上へ行くと真ん中のyが増え、左（東）へ行くと左端のxが増えます。右（西）へ行くとxは減ります。

**向きを変えても、東・西・南・北の基準は変わりません。**「前・左」は南を向いた場合の覚え方です。

**この課題の例：** `~-5 ~0 ~13` は、足元から西へ5ブロック、南へ13ブロックの場所です。0の方向には動かしません。

**実行する前に入口の金の床へ戻ろう。** 自分が移動すると、相対座標の出発点も移動します。Agentを動かす `前・後ろ・左・右` はAgent自身の向きが基準なので、位置のx・y・zと分けて考えよう。

player.onChat("q57r03", function () {
    let cowType = mobs.entitiesByType(COW)
    let cowGroup = mobs.near(cowType, pos(-5, 0, 13), 3)
    let cowMarker = blocks.testForBlock(GOLD_BLOCK, pos(-5, -1, 13))
    let cowSafe = blocks.testForBlock(AIR, pos(5, 0, 13))
    let cowReady = cowMarker && cowSafe
    if (cowReady) {
        mobs.teleportToPosition(cowGroup, pos(5, 0, 13))
    }
    let sheepType = mobs.entitiesByType(SHEEP)
    let sheepGroup = mobs.near(sheepType, pos(0, 0, 6), 3)
    let sheepMarker = blocks.testForBlock(GOLD_BLOCK, pos(0, -1, 6))
    let sheepSafe = blocks.testForBlock(AIR, pos(0, 0, 15))
    let sheepReady = sheepMarker && sheepSafe
    if (sheepReady) {
        mobs.teleportToPosition(sheepGroup, pos(0, 0, 15))
    }
})
