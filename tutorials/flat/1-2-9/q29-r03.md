## C06 / Q04 / R03 操作する道具｜3/10 相対座標を確かめる

**［3/10］相対座標を確かめる**

**自分の足元が出発点（原点）**。`~0 ~0 ~0` は、今立っている自分の足元です。3つの数は、そこから「どの方向に、何ブロック離れた場所か」を表します。

| 数の場所 | ＋で進む方向 | −で進む方向 |
| --- | --- | --- |
| 左：x | 東 | 西 |
| 真ん中：y | 上 | 下 |
| 右：z | 南 | 北 |

**南を向いているとき**は、前へ進むと右端のzが増え、上へ行くと真ん中のyが増え、左（東）へ行くと左端のxが増えます。右（西）へ行くとxは減ります。

**向きを変えても、東・西・南・北の基準は変わりません。**「前・左」は南を向いた場合の覚え方です。

**この課題の例：** `~2 ~4 ~13` は、足元から東へ2ブロック、上へ4ブロック、南へ13ブロックの場所です。0の方向には動かしません。

**実行する前に入口の金の床へ戻ろう。** 自分が移動すると、相対座標の出発点も移動します。Agentを動かす `前・後ろ・左・右` はAgent自身の向きが基準なので、位置のx・y・zと分けて考えよう。

**完成コードの見本**

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q29r03", function () {
    eventOrigin = player.position()
    eventReady = true
})
player.onItemInteracted(STICK, function () {
    if (eventReady) {
        let eventPoint1 = positions.add(eventOrigin, pos(2, 4, 13))
        let eventPoint2 = positions.add(eventOrigin, pos(3, 4, 13))
        blocks.fill(GOLD_BLOCK, eventPoint1, eventPoint2, FillOperation.Replace)
    }
})
```
