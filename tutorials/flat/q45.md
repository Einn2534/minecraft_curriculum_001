# Q45 夜間照明当番

### @flyoutOnly true
### @hideIteration true
### @hideDone true

## 課題

夜だけ街灯を点灯し、朝になったら元へ戻す

Agentを奥の金ブロック中央へ移動します。 工房入口の金の床から動かずに実行します。

緑の実行ボタンを押し、ゲームのチャットで q45 と入力します。工房NPCの「完成した・判定」で確認してください。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("q45", function () {
    agent.setSlot(1)
    agent.teleport(pos(-8, 0, 1), SOUTH)
    agent.move(FORWARD, 12)
    agent.turn(LEFT_TURN)
    agent.move(FORWARD, 6)
})
```
