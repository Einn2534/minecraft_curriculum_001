## 課題

チャットコマンドの run を hello に変え、中に「発言する（player.say）」をつないで「王都へようこそ！」と入力します。

緑の実行ボタンを押し、ゲームのチャットで hello と入力してください。表示できたら工房NPCの「表示できた」で完了します。

ヒントが必要なときは、電球を押してください。

```blocks
player.onChat("hello", function () {
    player.say("王都へようこそ！")
})
```
