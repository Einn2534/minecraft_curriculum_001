## C06 Q28 R03 ランダムな的

**C06 Q28 R03 ランダムな的**

矢を放つたび、3つの的のどれかを金に変えよう。

完成するもの: 弓を使うと反応する3つの的

学ぶこと: 配列（順番のあるリスト）、乱数（くじ引き）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q28r03 に変えよう。

2. 白い羊毛で pos(-6, 1, 14) から pos(-4, 3, 14) まで作ろう。

3. 白い羊毛で pos(4, 1, 14) から pos(6, 3, 14) まで作ろう。

4. 候補をリストにして、乱数で番号を選ぼう。範囲は0から「リストの長さ−1」だよ。

5. 緑の実行ボタンを押して、Tキーのチャットで q28r03 と入力しよう。

6. 入口の金の床から、用意した弓で矢を放とう。矢を放ったイベントで的の色が変わるよ。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q28r03", function () {
    eventOrigin = player.position()
    eventReady = true
    blocks.fill(WOOL, pos(-6, 1, 14), pos(-4, 3, 14), FillOperation.Replace)
    blocks.fill(WOOL, pos(4, 1, 14), pos(6, 3, 14), FillOperation.Replace)
})
player.onArrowShot(function () {
    if (eventReady) {
        let places = [-5, 0, 5]
        let index = randint(0, places.length - 1)
        let x = places[index]
        blocks.place(GOLD_BLOCK, positions.add(eventOrigin, pos(x, 2, 13)))
    }
})

```
