## C03 Q11 R03 3区間の座標のゴール

**C03 Q11 R03 3区間の座標のゴール**

自分を曲がり角に沿って金のゴールへ動かそう。

完成するもの: 座標のゴールの道とゴール

学ぶこと: 配列（順番のあるリスト）、座標を足す、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q11r03 に変えよう。

2. 最初の自分の位置をoriginに保存し、そこからの座標を足して順にテレポートしよう。移動する手順を関数にまとめ、位置のリストからx・y・zを渡そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q11r03 と入力しよう。

4. 「ゴールに到着！」が出たら、緑の道で工房NPCへ戻ろう。到着の記録は残るよ。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let travelOrigin_q11r03 = player.position()
function travel_q11r03(x: number, y: number, z: number) {
    player.teleport(positions.add(travelOrigin_q11r03, pos(x, y, z)))
}
player.onChat("q11r03", function () {
    travelOrigin_q11r03 = player.position()
    let destinations = [[-6, 0, 14], [5, 0, 14], [5, 0, 15]]
    for (let destination of destinations) {
        travel_q11r03(destination[0], destination[1], destination[2])
    }
    player.execute("function grandfort/course/arrival/r033")
})

```
