## C08 Q40 R01 床とカウンター

**C08 Q40 R01 床とカウンター**

変数で幅を決め、床とカウンターを作ろう。

完成するもの: 床・柱・屋根を組み立てる設計機

学ぶこと: 変数（数を入れる箱）、Builder、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q40r01 に変えよう。

2. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの板で pos(-3, 0, 10) から pos(3, 0, 15) まで作ろう。

3. 石レンガで pos(-2, 1, 11) から pos(2, 1, 11) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q40r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q40r01", function () {
    builder.teleportTo(pos(-3, 0, 10))
    builder.mark()
    let width = 7
    builder.teleportTo(pos(-3 + width - 1, 0, 15))
    builder.fill(PLANKS_OAK)
    blocks.fill(STONE_BRICKS, pos(-2, 1, 11), pos(2, 1, 11), FillOperation.Replace)
})

```
