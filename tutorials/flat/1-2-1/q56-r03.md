## C12 Q56 R03 安全な手すり

**C12 Q56 R03 安全な手すり**

高さのリストをくり返し読み、同じ関数で4辺をつないで、すき間のない手すりにしよう。

完成するもの: 動物を囲う放牧柵

学ぶこと: 関数（まとめた手順）と引数、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q56r03 に変えよう。

2. 高さのリストをくり返し読み、両端の位置をdrawの関数へ渡して手すりをつなごう。

3. 緑の実行ボタンを押して、Tキーのチャットで q56r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q56r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q56r03", function () {
    let heights = [2, 3]
    for (let height of heights) {
        draw_q56r03(PLANKS_OAK, -6, height - 1, 6, -6, height - 1, 18)
        draw_q56r03(PLANKS_OAK, 6, height - 1, 6, 6, height - 1, 18)
        draw_q56r03(PLANKS_OAK, -6, height - 1, 6, 6, height - 1, 6)
        draw_q56r03(PLANKS_OAK, -6, height - 1, 18, 6, height - 1, 18)
    }
})
```
