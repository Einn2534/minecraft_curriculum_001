## 工房で課題をはじめよう！

**工房で課題をはじめよう！**

工房NPCで課題を選び、「開始する」「開始位置へ」「はじめる」のどれかを押そう。

Cキーで、今はじめた課題のタイトルと作り方が開くよ。

違う説明が出たら、工房NPCの「コードの説明をひらく」を押そう。続きのコードはMakeCodeの保存したプロジェクトからも開けるよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("run", function () {

})
```
