## C06 Q30 R02 柵の柱

**C06 Q30 R02 柵の柱**

四すみの柱を関数で立てよう。

完成するもの: 城を守る木の防衛柵

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q30r02 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(-5, 1, 7) から pos(-5, 3, 7) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(5, 1, 7) から pos(5, 3, 7) まで作ろう。

4. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(-5, 1, 17) から pos(-5, 3, 17) まで作ろう。

5. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(5, 1, 17) から pos(5, 3, 17) まで作ろう。

6. 緑の実行ボタンを押して、Tキーのチャットで q30r02 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

}
