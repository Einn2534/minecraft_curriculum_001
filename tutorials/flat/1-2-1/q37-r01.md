## C08 Q37 R01 1列を片付ける

**C08 Q37 R01 1列を片付ける**

1本の幹を切り出そう。根元の1段を切り株として残し、落ちた木材を集めよう。

完成するもの: 切り出した木材と切り株

学ぶこと: こわす・集める、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q37r01 に変えよう。

2. まず位置を1つずつ決め、同じ操作を順につなごう。位置ごとに、Agentを1ブロック手前へ呼ぼう。前を調べ、オークの原木のときだけ、こわす→集める。ほかの材料はこわさないよ。

3. 緑の実行ボタンを押して、Tキーのチャットで q37r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q37r01", function () {
    agent.teleport(pos(-3, 2 - 1, 4 + 8), SOUTH)
    if (agent.inspect(AgentInspection.Block, FORWARD) == LOG_OAK) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
    agent.teleport(pos(-3, 3 - 1, 4 + 8), SOUTH)
    if (agent.inspect(AgentInspection.Block, FORWARD) == LOG_OAK) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
    agent.teleport(pos(-3, 4 - 1, 4 + 8), SOUTH)
    if (agent.inspect(AgentInspection.Block, FORWARD) == LOG_OAK) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
})
```
