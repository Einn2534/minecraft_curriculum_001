## C10 Q46 R02 2軒へ配達

**C10 Q46 R02 2軒へ配達**

2つの配達先をリストにして順に届けよう。

完成するもの: パン屋から3つの配達先へ運ぶ配達路

学ぶこと: 配列（順番のあるリスト）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q46r02 に変えよう。

2. 配達先をリストにしてAgentを順に動かそう。配達台にケーキを置こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q46r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q46r02", function () {
    let destinations = [[-4, 2, 3], [0, 2, 6]]
    for (let destination of destinations) {
        agent.teleport(pos(destination[0], destination[1], destination[2] + 9), SOUTH)
        blocks.place(CAKE, pos(destination[0], destination[1] - 1, destination[2] + 9))
    }
})

```
