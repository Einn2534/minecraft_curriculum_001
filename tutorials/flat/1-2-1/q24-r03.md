## C05 Q24 R03 手すりと屋根

**C05 Q24 R03 手すりと屋根**

引数で長さを指定し、手すりと屋根を仕上げよう。

完成するもの: 荷車が渡れる幅の広い橋

学ぶこと: 関数（まとめた手順）と引数、配列（順番のあるリスト）、Builder

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q24r03 に変えよう。

2. 高さのリストをくり返し読み、両端の位置をdrawの関数へ渡して手すりをつなごう。

3. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの板で pos(-3, 3, 8) から pos(3, 3, 16) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q24r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q24r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q24r03", function () {
    let heights = [3]
    for (let height of heights) {
        draw_q24r03(PLANKS_OAK, -3, height - 1, 8, -3, height - 1, 16)
        draw_q24r03(PLANKS_OAK, 3, height - 1, 8, 3, height - 1, 16)
    }
    builder.teleportTo(pos(-3, 3, 8))
    builder.mark()
    builder.teleportTo(pos(3, 3, 16))
    builder.fill(PLANKS_OAK)
})

```
