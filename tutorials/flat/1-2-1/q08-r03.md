## C02 Q08 R03 まとめて点検する

**C02 Q08 R03 まとめて点検する**

柱の上の灯りを調べて、道を照らそう。

完成するもの: 祈りの道の灯列

学ぶこと: 条件（もし〜なら）、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q08r03 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(-4, 0, 12) から pos(-4, 1, 12) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(-2, 0, 12) から pos(-2, 1, 12) まで作ろう。

4. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(0, 0, 12) から pos(0, 1, 12) まで作ろう。

5. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(2, 0, 12) から pos(2, 1, 12) まで作ろう。

6. 位置を1ずつ増やすくり返しを作ろう。オークの原木で pos(4, 0, 12) から pos(4, 1, 12) まで作ろう。

7. 調べる手順を関数にまとめよう。位置のリストをくり返し、横と奥、または横と高さの2つのくり返しを組み合わせよう。

8. 緑の実行ボタンを押して、Tキーのチャットで q08r03 と入力しよう。

9. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。
