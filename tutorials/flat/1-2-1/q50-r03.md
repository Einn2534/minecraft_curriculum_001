## C10 Q50 R03 選んだ場所を調べる

**C10 Q50 R03 選んだ場所を調べる**

用意した安全な候補から、くじ引きで1か所を選ぼう。

完成するもの: 安全な場所から選ぶAgentかくれんぼ

学ぶこと: 配列（順番のあるリスト）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q50r03 に変えよう。

2. 候補をリストにして、乱数で番号を選ぼう。範囲は0から「リストの長さ−1」だよ。

3. 緑の実行ボタンを押して、Tキーのチャットで q50r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q50r03", function () {
    let hiding = [-6, -3, 0, 3, 6]
    let index = randint(0, hiding.length - 1)
    let x = hiding[index]
    if (blocks.testForBlock(AIR, pos(x, 0, 13))) {
        agent.teleport(pos(x, 0, 13), SOUTH)
    }
})

```
