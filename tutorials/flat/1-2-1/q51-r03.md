## C11 Q51 R03 道と2区画

**C11 Q51 R03 道と2区画**

幅と長さを引数にした関数で、道を挟んだ2つの畑を作ろう。

完成するもの: 面積を計算して区画を作る畑

学ぶこと: 関数（まとめた手順）と引数、二重のくり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q51r03 に変えよう。

2. 幅・長さ・開始位置を引数にしたplotの関数を作ろう。左と右で数を変えて同じ関数を呼ぼう。

3. 幅・長さ・開始位置を引数にしたplotの関数を作ろう。左と右で数を変えて同じ関数を呼ぼう。

4. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。丸石で pos(2, -1, 10) から pos(2, -1, 15) まで作ろう。

5. 緑の実行ボタンを押して、Tキーのチャットで q51r03 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

function plot_q51r03(width: number, length: number, startX: number, startZ: number) {
    for (let row = 0; row < length; row++) {
        for (let column = 0; column < width; column++) {
            blocks.place(DIRT, pos(startX + column, -1, startZ + row + 9))
        }
    }
}
function draw_q51r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q51r03", function () {

    plot_q51r03(3, 4, 3, 2)
