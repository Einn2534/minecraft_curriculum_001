## C02 Q06 R01 窓の額

**C02 Q06 R01 窓の額**

石の窓枠を立てよう。

完成するもの: 色ガラスで復元した城の窓

学ぶこと: 座標、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q06r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-4, 0, 13) から pos(-4, 5, 13) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(4, 0, 13) から pos(4, 5, 13) まで作ろう。

4. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-4, 5, 13) から pos(4, 5, 13) まで作ろう。

5. 緑の実行ボタンを押して、Tキーのチャットで q06r01 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q06r01", function () {
    for (let y = 0; y <= 5; y++) {
        blocks.place(STONE_BRICKS, pos(-4, (y + 1) - 1, 4 + 9))
    }
    for (let y = 0; y <= 5; y++) {
        blocks.place(STONE_BRICKS, pos(4, (y + 1) - 1, 4 + 9))
    }
    for (let x = 0; x <= 8; x++) {
        blocks.place(STONE_BRICKS, pos((x + -4), 6 - 1, 4 + 9))
    }
})
```
