## C11 Q54 R01 1本の木

**C11 Q54 R01 1本の木**

幹と葉を関数で組み立てよう。

完成するもの: 間隔を計算して植える王立果樹園

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q54r01 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(-4, 0, 12) から pos(-4, 3, 12) まで作ろう。

3. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの葉で pos(-5, 4, 11) から pos(-3, 5, 13) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q54r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q54r01(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q54r01", function () {
    draw_q54r01(LOG_OAK, -4, 0, 12, -4, 3, 12)
    builder.teleportTo(pos(-5, 4, 11))
    builder.mark()
    builder.teleportTo(pos(-3, 5, 13))
    builder.fill(LEAVES_OAK)
})

```
