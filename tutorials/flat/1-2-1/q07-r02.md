## C02 Q07 R02 鐘を並べる

**C02 Q07 R02 鐘を並べる**

音符ブロックを5個並べて、チャットから鐘の音を鳴らそう。

完成するもの: 音符ブロックが並ぶ鐘楼とチャットで鳴る旋律

学ぶこと: くり返し、音を鳴らす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q07r02 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。音符ブロックで pos(-2, 1, 12) から pos(2, 1, 12) まで作ろう。

3. くり返しで鐘の音を鳴らそう。音の高さを変え、少し待つ手順を入れよう。

4. 緑の実行ボタンを押して、Tキーのチャットで q07r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q07r02", function () {
    for (let x = 0; x <= 4; x++) {
        blocks.place(NOTE_BLOCK, pos((x + -2), 2 - 1, 3 + 9))
    }
    for (let note = 0; note < 3; note++) {
        player.execute("playsound note.bell @s ~ ~ ~ 1 " + (1 + (note % 3)))
        loops.pause(300)
    }
})

```
