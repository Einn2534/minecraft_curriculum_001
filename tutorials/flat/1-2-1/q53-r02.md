## C11 Q53 R02 支流をつなぐ

**C11 Q53 R02 支流をつなぐ**

水路から左右の支流をつなごう。

完成するもの: 畑へ水を届ける灌漑路

学ぶこと: 関数（まとめた手順）と引数、座標、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q53r02 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。水で pos(-3, -1, 13) から pos(3, -1, 13) まで作ろう。

3. 緑の実行ボタンを押して、Tキーのチャットで q53r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q53r02(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q53r02", function () {
    draw_q53r02(WATER, -3, -1, 13, 3, -1, 13)
})

```
