## C04 Q18 R03 対称な飾り

**C04 Q18 R03 対称な飾り**

四すみの位置をリストにして、同じ関数で光る飾りを付けよう。

完成するもの: 水盤・柱・左右対称の飾りがある噴水

学ぶこと: 関数（まとめた手順）と引数、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q18r03 に変えよう。

2. 四すみの位置をリストにし、くり返しでdrawの関数へ渡そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q18r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q18r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q18r03", function () {
    let corners = [[-3, 2, 0], [3, 2, 0], [-3, 2, 6], [3, 2, 6]]
    for (let corner of corners) {
        draw_q18r03(GLOWSTONE, corner[0], corner[1] - 1, corner[2] + 9, corner[0], corner[1] - 1, corner[2] + 9)
    }
})

```
