## C10 Q47 R01 1列を片付ける

**C10 Q47 R01 1列を片付ける**

指定の丸石を調べ、Agentでこわして集めよう。

完成するもの: 煙の通り道がある煙突

学ぶこと: こわす・集める、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q47r01 に変えよう。

2. まず位置を1つずつ決め、同じ操作を順につなごう。位置ごとに、Agentを1ブロック上へ呼ぼう。下を調べ、丸石のときだけ、こわす→集める。ほかの材料はこわさないよ。

3. 緑の実行ボタンを押して、Tキーのチャットで q47r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q47r01", function () {
    agent.teleport(pos(-1, 3, 3 + 9), SOUTH)
    if (agent.inspect(AgentInspection.Block, DOWN) == COBBLESTONE) {
        agent.destroy(DOWN)
        agent.collectAll()
    }
    agent.teleport(pos(0, 3, 3 + 9), SOUTH)
    if (agent.inspect(AgentInspection.Block, DOWN) == COBBLESTONE) {
        agent.destroy(DOWN)
        agent.collectAll()
    }
    agent.teleport(pos(1, 3, 3 + 9), SOUTH)
    if (agent.inspect(AgentInspection.Block, DOWN) == COBBLESTONE) {
        agent.destroy(DOWN)
        agent.collectAll()
    }
})

```
