## C08 Q36 R01 見本を調べる

**C08 Q36 R01 見本を調べる**

金と鉄は合格品として棚へ。丸石は不合格の赤い印に分けよう。

完成するもの: 合格品を分けた鍛冶の検査台

学ぶこと: 条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q36r01 に変えよう。

2. まず位置を1つずつ決め、同じ操作を順につなごう。金・鉄は合格品として棚に分けよう。どちらでもない丸石は不合格の赤い印にしよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q36r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q36r01", function () {
    if (blocks.testForBlock(GOLD_BLOCK, pos(-5, 0, 1 + 9))) {
        blocks.place(GOLD_BLOCK, pos(4, 0, 1 + 9))
    } else if (blocks.testForBlock(IRON_BLOCK, pos(-5, 0, 1 + 9))) {
        blocks.place(IRON_BLOCK, pos(4, 0, 1 + 9))
    } else {
        blocks.place(RED_WOOL, pos(4, 0, 1 + 9))
    }
    if (blocks.testForBlock(GOLD_BLOCK, pos(-5, 0, 2 + 9))) {
        blocks.place(GOLD_BLOCK, pos(4, 0, 2 + 9))
    } else if (blocks.testForBlock(IRON_BLOCK, pos(-5, 0, 2 + 9))) {
        blocks.place(IRON_BLOCK, pos(4, 0, 2 + 9))
    } else {
        blocks.place(RED_WOOL, pos(4, 0, 2 + 9))
    }
})

```
