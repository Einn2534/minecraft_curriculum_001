## C05 Q22 R03 棚へ運ぶ計画

**C05 Q22 R03 棚へ運ぶ計画**

リストから3つの在庫を合計し、棚を完成させよう。

完成するもの: 荷物の数に合わせて積む港の荷役台

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q22r03 に変えよう。

2. スロットの持ち物の数を調べ、totalに足して合計しよう。

3. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの板で pos(-5, 1, 13) から pos(5, 1, 13) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q22r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function stock_q22r03(lastSlot: number): number {
    let slots = [1, 2, 3]
    let total = 0
    for (let slot of slots) {
        if (slot <= lastSlot) {
            total += agent.getItemCount(slot)
        }
    }
    return total
}
player.onChat("q22r03", function () {
    let total = stock_q22r03(3)
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
    builder.teleportTo(pos(-5, 1, 13))
    builder.mark()
    builder.teleportTo(pos(5, 1, 13))
    builder.fill(PLANKS_OAK)
})

```
