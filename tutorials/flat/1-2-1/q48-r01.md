## C10 Q48 R01 2つから選ぶ

**C10 Q48 R01 2つから選ぶ**

花壇の各場所に、ポピーかタンポポをくじ引きで植えよう。

完成するもの: 種類をくじ引きで選ぶ花壇

学ぶこと: 乱数（くじ引き）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q48r01 に変えよう。

2. まず1か所ずつ、くじで0ならポピー・1ならタンポポを植えよう。次のRでリストにまとめるよ。

3. 緑の実行ボタンを押して、Tキーのチャットで q48r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q48r01", function () {
    if (randint(0, 1) == 0) {
        blocks.place(POPPY, pos(-4, 0, 13))
    } else {
        blocks.place(YELLOW_FLOWER, pos(-4, 0, 13))
    }
    if (randint(0, 1) == 0) {
        blocks.place(POPPY, pos(0, 0, 13))
    } else {
        blocks.place(YELLOW_FLOWER, pos(0, 0, 13))
    }
})

```
