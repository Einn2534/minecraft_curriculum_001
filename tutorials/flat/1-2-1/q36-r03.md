## C08 Q36 R03 リストでまとめる

**C08 Q36 R03 リストでまとめる**

金と鉄は合格品として棚へ。丸石は不合格の赤い印に分けよう。

完成するもの: 合格品を分けた鍛冶の検査台

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q36r03 に変えよう。

2. 調べる手順を関数にまとめよう。位置のリストをくり返し、横と奥、または横と高さの2つのくり返しを組み合わせよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q36r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function check_q36r03_1(x: number, y: number, z: number) {
    if (blocks.testForBlock(GOLD_BLOCK, pos(x, 0, z + 9))) {
        blocks.place(GOLD_BLOCK, pos(4, 0, z + 9))
    } else if (blocks.testForBlock(IRON_BLOCK, pos(x, 0, z + 9))) {
        blocks.place(IRON_BLOCK, pos(4, 0, z + 9))
    } else {
        blocks.place(RED_WOOL, pos(4, 0, z + 9))
    }
}
player.onChat("q36r03", function () {
    let zValues = [1, 2, 3, 4]
    for (let z of zValues) {
        check_q36r03_1(-5, 1, z)
    }
})
```
