## C02 Q07 R03 旋律をくり返す

**C02 Q07 R03 旋律をくり返す**

鐘楼の屋根を付け、3つの高さの音を2回鳴らそう。

完成するもの: 音符ブロックが並ぶ鐘楼とチャットで鳴る旋律

学ぶこと: 関数（まとめた手順）と引数、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q07r03 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの板で pos(-3, 3, 12) から pos(3, 3, 12) まで作ろう。

3. くり返しで鐘の音を鳴らそう。音の高さを変え、少し待つ手順を入れよう。

4. オークの原木で pos(-3, 1, 12) から pos(-3, 2, 12) まで作ろう。

5. オークの原木で pos(3, 1, 12) から pos(3, 2, 12) まで作ろう。

6. 緑の実行ボタンを押して、Tキーのチャットで q07r03 と入力しよう。

7. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q07r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q07r03", function () {
    draw_q07r03(PLANKS_OAK, -3, 3, 12, 3, 3, 12)
    let melody = [1, 2, 3]
    for (let times = 0; times < 2; times++) {
        for (let pitch of melody) {
            player.execute("playsound note.bell @s ~ ~ ~ 1 " + pitch)
            loops.pause(300)
        }
    }
    blocks.fill(LOG_OAK, pos(-3, 1, 12), pos(-3, 2, 12), FillOperation.Replace)
    blocks.fill(LOG_OAK, pos(3, 1, 12), pos(3, 2, 12), FillOperation.Replace)
})
```
