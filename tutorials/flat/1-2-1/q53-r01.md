## C11 Q53 R01 水路を掘る

**C11 Q53 R01 水路を掘る**

土を掘って、畑の横に水路を作ろう。

完成するもの: 畑へ水を届ける灌漑路

学ぶこと: くり返し、土を水へ変える

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q53r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。水で pos(-3, -1, 10) から pos(-3, -1, 16) まで作ろう。

3. 緑の実行ボタンを押して、Tキーのチャットで q53r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q53r01", function () {
    for (let z = 0; z <= 6; z++) {
        blocks.place(WATER, pos(-3, 0 - 1, (z + 1) + 9))
    }
})

```
