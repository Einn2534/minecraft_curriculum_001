## C10 Q46 R03 3軒の配達

**C10 Q46 R03 3軒の配達**

3つの配達先を1つの関数で回ろう。

完成するもの: パン屋から3つの配達先へ運ぶ配達路

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q46r03 に変えよう。

2. 1か所に届ける手順をdeliverの関数にまとめよう。配達先リストをくり返し読み、x・y・zを引数に渡そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q46r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function deliver_q46r03(x: number, y: number, z: number) {
    agent.teleport(pos(x, y, z + 9), SOUTH)
    blocks.place(CAKE, pos(x, y - 1, z + 9))
}
player.onChat("q46r03", function () {
    let destinations = [[-4, 2, 3], [0, 2, 6], [4, 2, 3]]
    for (let destination of destinations) {
        deliver_q46r03(destination[0], destination[1], destination[2])
    }
})

```
