## C03 Q14 R03 予報パネル

**C03 Q14 R03 予報パネル**

天候の色を3か所へ表示して、観測台を完成させよう。

完成するもの: 天候を読み、晴れ・雨・雷を色で表示する気象台

学ぶこと: 条件（もし〜なら）、関数（まとめた手順）と引数、配列（順番のあるリスト）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q14r03 に変えよう。

2. 天候の値を変数に保存し、晴れ・雨・雷で色を選ぼう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの板で pos(-3, 4, 12) から pos(3, 4, 14) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q14r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q14r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q14r03", function () {
    let value = gameplay.weatherQuery()
    let color = GOLD_BLOCK
    if (value == Weather.Rain) {
        color = BLUE_WOOL
    } else if (value == Weather.Thunder) {
        color = RED_WOOL
    }
    let displays = [-1, 0, 1]
    for (let x of displays) {
        blocks.place(color, pos(x, 3, 12))
    }
    player.say("今の値: " + value)
    draw_q14r03(PLANKS_OAK, -3, 4, 12, 3, 4, 14)
})

```
