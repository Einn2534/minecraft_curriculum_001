## C12 Q57 R01 近くのグループ

**C12 Q57 R01 近くのグループ**

左の囲いの牛を右へ移そう。ほかの工房の動物は動かさないよ。

完成するもの: 牛と羊を別の囲いへ分ける牧場

学ぶこと: 近くのMobを選ぶ、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q57r01 に変えよう。

2. 種類でMobを選び、さらに自分の工房の左の囲いの近くに絞って移そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q57r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q57r01", function () {
    mobs.teleportToPosition(mobs.near(mobs.entitiesByType(COW), pos(-5, 0, 13), 3), pos(5, 0, 13))
})

```
