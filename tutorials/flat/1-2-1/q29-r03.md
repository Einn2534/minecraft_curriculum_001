## C06 Q29 R03 操作する道具

**C06 Q29 R03 操作する道具**

棒を右クリックすると金の救助信号を出そう。

完成するもの: 色を選んで発信できる緊急信号旗

学ぶこと: 道具を使ったときのイベント、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q29r03 に変えよう。

2. 「棒が使われたとき」の中に信号の色を変える手順をつなごう。入口の金の床で棒を右クリックしよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q29r03 と入力しよう。

4. 入口の金の床で、用意した棒を持って右クリックしよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
let eventOrigin = player.position()
let eventReady = false
player.onChat("q29r03", function () {
    eventOrigin = player.position()
    eventReady = true
})
player.onItemInteracted(STICK, function () {
    if (eventReady) {
        blocks.fill(GOLD_BLOCK, positions.add(eventOrigin, pos(2, 4, 13)), positions.add(eventOrigin, pos(3, 4, 13)), FillOperation.Replace)
    }
})

```
