## C01 Q03 R03 3区間の衛兵の巡回

**C01 Q03 R03 3区間の衛兵の巡回**

Agentを曲がり角に沿って金のゴールへ動かそう。

完成するもの: 衛兵の巡回の道とゴール

学ぶこと: 座標を足す

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q03r03 に変えよう。

2. 最初の位置にAgentを呼び、各区間の向きと歩数を決めて進もう。前にブロックがないかを調べる条件も入れよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q03r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q03r03", function () {
    agent.teleport(pos(-6, 0, 9), SOUTH)
    agent.teleport(agent.getPosition(), SOUTH)
    let steps1 = 5
    while (steps1 > 0 && !agent.detect(AgentDetection.Block, FORWARD)) {
        agent.move(FORWARD, 1)
        steps1 += -1
    }
    agent.teleport(agent.getPosition(), EAST)
    let steps2 = 12
    while (steps2 > 0 && !agent.detect(AgentDetection.Block, FORWARD)) {
        agent.move(FORWARD, 1)
        steps2 += -1
    }
    agent.teleport(agent.getPosition(), SOUTH)
    let steps3 = 3
    while (steps3 > 0 && !agent.detect(AgentDetection.Block, FORWARD)) {
        agent.move(FORWARD, 1)
        steps3 += -1
    }
})

```
