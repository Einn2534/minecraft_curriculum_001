## C07 Q33 R02 まとめ買い

**C07 Q33 R02 まとめ買い**

単価3・個数3なら1円引きの単価2で計算しよう。

完成するもの: 値段と個数を計算して表示する商人の会計台

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q33r02 に変えよう。

2. 数を変数に保存し、足し算かかけ算で合計を計算しよう。個数が3以上なら単価を1引こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q33r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q33r02", function () {
    let price = 3
    let quantity = 3
    if (quantity >= 3) {
        price += -1
    }
    let total = price * quantity
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
})

```
