## C11 Q54 R03 3本の果樹

**C11 Q54 R03 3本の果樹**

リストとくり返しで3本目を作り、赤い実を飾ろう。

完成するもの: 間隔を計算して植える王立果樹園

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q54r03 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(4, 0, 12) から pos(4, 3, 12) まで作ろう。

3. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの葉で pos(3, 4, 11) から pos(5, 5, 13) まで作ろう。

4. 位置のリストをくり返し、同じ飾りを順に付けよう。

5. 緑の実行ボタンを押して、Tキーのチャットで q54r03 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q54r03(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q54r03", function () {
    draw_q54r03(LOG_OAK, 4, 0, 12, 4, 3, 12)
    builder.teleportTo(pos(3, 4, 11))
    builder.mark()
    builder.teleportTo(pos(5, 5, 13))
    builder.fill(LEAVES_OAK)
    let places = [-4, 0, 4]
    for (let x of places) {
        blocks.place(RED_WOOL, pos(x, 4, 11))
    }
})

```
