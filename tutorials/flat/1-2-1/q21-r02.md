## C05 Q21 R02 場所を調べて片付ける

**C05 Q21 R02 場所を調べて片付ける**

指定のオークの原木を調べ、Agentでこわして集めよう。

完成するもの: 漂流物を取り除いた運河

学ぶこと: 条件（もし〜なら）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q21r02 に変えよう。

2. 位置のリストをくり返し、Agentを1ブロック手前へ呼ぼう。前を調べ、オークの原木のときだけ、こわす→集める。ほかの材料はこわさないよ。

3. 緑の実行ボタンを押して、Tキーのチャットで q21r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q21r02", function () {
    let points = [[-2, 1, 3], [-2, 1, 4], [-1, 1, 3], [-1, 1, 4], [0, 1, 3], [0, 1, 4], [1, 1, 3], [1, 1, 4], [2, 1, 3], [2, 1, 4]]
    for (let point of points) {
        agent.teleport(pos(point[0], point[1] - 1, point[2] + 8), SOUTH)
        if (agent.inspect(AgentInspection.Block, FORWARD) == LOG_OAK) {
            agent.destroy(FORWARD)
            agent.collectAll()
        }
    }
})
```
