## C04 Q19 R01 調査所

**C04 Q19 R01 調査所**

囲いの中に2人の村人を呼ぼう。

完成するもの: 呼んだ人数と金の棒グラフを照らし合わせる市民調査所

学ぶこと: 変数（数を入れる箱）、動物・村人を呼ぶ

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q19r01 に変えよう。

2. 同じ種類・同じ囲いの近くに絞って前の見本を消そう。2を変数に入れ、くり返しで村人を呼ぼう。くり返し動かしても増えすぎないよ。

3. 緑の実行ボタンを押して、Tキーのチャットで q19r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q19r01", function () {
    mobs.kill(mobs.near(mobs.entitiesByType(VILLAGER), pos(-5, 0, 13), 3))
    let count = 2
    for (let number = 0; number < count; number++) {
        mobs.spawn(VILLAGER, pos(-5, 0, 13))
    }
})

```
