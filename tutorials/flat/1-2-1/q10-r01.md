## C02 Q10 R01 1区間の迷宮の出口

**C02 Q10 R01 1区間の迷宮の出口**

自分を曲がり角に沿って金のゴールへ動かそう。

完成するもの: 迷宮の出口の道とゴール

学ぶこと: 順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q10r01 に変えよう。

2. 最初の自分の位置をoriginに保存し、そこからの座標を足して順にテレポートしよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q10r01 と入力しよう。

4. 「ゴールに到着！」が出たら、緑の道で工房NPCへ戻ろう。到着の記録は残るよ。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q10r01", function () {
    player.teleport(pos(-6, 0, 12))
    player.execute("function grandfort/course/arrival/r028")
})

```
