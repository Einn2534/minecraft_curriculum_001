## C06 Q28 R01 的を作ろう

**C06 Q28 R01 的を作ろう**

赤と白の的を作ろう。

完成するもの: 弓を使うと反応する3つの的

学ぶこと: 順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q28r01 に変えよう。

2. 白い羊毛で pos(-1, 1, 14) から pos(1, 3, 14) まで作ろう。

3. 赤い羊毛で pos(0, 2, 13) から pos(0, 2, 13) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q28r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q28r01", function () {
    blocks.fill(WOOL, pos(-1, 1, 14), pos(1, 3, 14), FillOperation.Replace)
    blocks.fill(RED_WOOL, pos(0, 2, 13), pos(0, 2, 13), FillOperation.Replace)
})

```
