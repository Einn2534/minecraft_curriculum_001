## C04 Q18 R01 水盤

**C04 Q18 R01 水盤**

石の水盤に水を入れよう。

完成するもの: 水盤・柱・左右対称の飾りがある噴水

学ぶこと: 座標、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q18r01 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-3, 0, 9) から pos(3, 0, 9) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-3, 0, 15) から pos(3, 0, 15) まで作ろう。

4. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(-3, 0, 9) から pos(-3, 0, 15) まで作ろう。

5. 位置を1ずつ増やすくり返しを作ろう。石レンガで pos(3, 0, 9) から pos(3, 0, 15) まで作ろう。

6. 水で pos(-2, 0, 10) から pos(2, 0, 14) まで作ろう。

7. 緑の実行ボタンを押して、Tキーのチャットで q18r01 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q18r01", function () {

    }
```
