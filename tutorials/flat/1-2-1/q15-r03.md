## C03 Q15 R03 印刷する手順をまとめる

**C03 Q15 R03 印刷する手順をまとめる**

表示板に「AR」の形を描こう。見本の足りないくり返しと位置を直そう。

完成するもの: 直した魔導書の文字

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q15r03 に変えよう。

2. 文字を空けて描く二重のくり返しをprintの関数にまとめよう。左端の位置startXを引数で渡して呼ぼう。

3. オークの板で pos(-7, 0, 14) から pos(6, 0, 14) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q15r03 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

デバッグは、間違いを見つけて直すことだよ。下のブロック見本は、最後の列が足りず、高さも1段ずれているよ。まず試して、くり返しの終わりと高さを直そう。電球に直した完成例があるよ。

```blocks
function print_q15r03(startX: number) {
    blocks.fill(AIR, pos(-6, 1, 14), pos(6, 6, 14), FillOperation.Replace)
    let letters = ["0100110", "1010101", "1110110", "1010101", "1010101"]
    for (let row = 0; row < letters.length; row++) {
        for (let column = 0; column < letters[row].length - 1; column++) {
            if (letters[row].charAt(column) == "1") {
                blocks.place(GOLD_BLOCK, pos(startX + column, 6 - row, 14))
            }
        }
    }
}
player.onChat("q15r03", function () {
    print_q15r03(-6)
    blocks.fill(PLANKS_OAK, pos(-7, 0, 14), pos(6, 0, 14), FillOperation.Replace)
})
```
