## C01 Q05 R03 宝物と照合

**C01 Q05 R03 宝物と照合**

3つの数字を配列で照合し、金庫の中の宝物を表示しよう。

完成するもの: 番号を照合すると金の扉が開く王家の金庫

学ぶこと: 配列（順番のあるリスト）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q05r03 に変えよう。

2. 暗号を変数に入れよう。正しい数字と一致したときだけ金庫を開こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q05r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q05r03", function () {
    let password = [2, 4, 6]
    if (password[0] == 2 && password[1] == 4 && password[2] == 6) {
        blocks.fill(GLOWSTONE, pos(-1, 1, 12), pos(1, 1, 12), FillOperation.Replace)
    }
})
```
