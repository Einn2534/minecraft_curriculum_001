## C01 Q01 R01 旗柱を立てよう

**C01 Q01 R01 旗柱を立てよう**

石の台の上に、木の旗柱を6段立てよう。

完成するもの: 旗柱・赤い旗・金の王家の印がついた王旗

学ぶこと: 順番に動かす、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q01r01 に変えよう。

2. 石レンガで pos(-1, 0, 11) から pos(1, 0, 13) まで作ろう。

3. Agentのスロット1を選ぼう。高さを0から5までくり返す中で、原木がないときだけ、Agentを位置(-1, 高さ+1, 12)・東向きへ呼ぶ→前に置く、をつなごう。柱の横から作るので、もう一度動かしても柱にぶつからないよ。

4. 緑の実行ボタンを押して、Tキーのチャットで q01r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q01r01", function () {
    blocks.fill(STONE_BRICKS, pos(-1, 0, 11), pos(1, 0, 13), FillOperation.Replace)
    agent.setSlot(1)
    for (let height = 0; height <= 5; height++) {
        if (!blocks.testForBlock(LOG_OAK, pos(0, (height + 2) - 1, 12))) {
            agent.teleport(pos(-1, (height + 2) - 1, 12), EAST)
            agent.place(FORWARD)
        }
    }
})

```
