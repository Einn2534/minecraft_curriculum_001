## C01 Q04 R03 橋を上げよう

**C01 Q04 R03 橋を上げよう**

赤い警報の印があるときは、橋の中央の板を上げて川を通れなくしよう。

完成するもの: 青い羊毛の川にかける、警報で板が上がる跳ね橋

学ぶこと: 条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q04r03 に変えよう。

2. 赤い警報の印を調べる「もし」を作ろう。赤なら中央の板を空け、板をたてに並べて橋を上げよう。これは川の模型だよ。判定は赤い警報の状態で行うよ。

3. 緑の実行ボタンを押して、Tキーのチャットで q04r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q04r03", function () {
    if (blocks.testForBlock(RED_WOOL, pos(-5, 0, 11))) {
        blocks.fill(AIR, pos(-1, 0, 13), pos(1, 0, 16), FillOperation.Replace)
        blocks.fill(PLANKS_OAK, pos(-1, 1, 13), pos(1, 4, 13), FillOperation.Replace)
    }
})
```
