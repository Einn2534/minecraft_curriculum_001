## C12 Q60 R02 2か所の在庫

**C12 Q60 R02 2か所の在庫**

残りの在庫を調べ、2か所へ順番に補充しよう。

完成するもの: 在庫を調べてえさ置き場へ補充する牧場の巡回

学ぶこと: 配列（順番のあるリスト）、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q60r02 に変えよう。

2. 配達先をリストにしてAgentを順に動かそう。在庫があるか調べてから下に置こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q60r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q60r02", function () {
    let destinations = [[-4, 2, 3], [0, 2, 6]]
    for (let destination of destinations) {
        agent.teleport(pos(destination[0], destination[1], destination[2] + 9), SOUTH)
        if (agent.getItemCount(1) > 0) {
            agent.setSlot(1)
            agent.place(DOWN)
        }
    }
})
```
