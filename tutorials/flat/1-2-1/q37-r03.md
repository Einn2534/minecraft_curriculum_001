## C08 Q37 R03 面を点検して片付ける

**C08 Q37 R03 面を点検して片付ける**

3本の幹を切り出そう。根元の1段を切り株として残し、落ちた木材を集めよう。

完成するもの: 切り出した木材と切り株

学ぶこと: 二重のくり返し、安全な場所だけをこわす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q37r03 に変えよう。

2. 調べる手順を関数にまとめよう。位置のリストをくり返し、横と奥、または横と高さの2つのくり返しを組み合わせよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q37r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function check_q37r03_1(x: number, y: number, z: number) {
    agent.teleport(pos(x, y - 1, z + 8), SOUTH)
    if (agent.inspect(AgentInspection.Block, FORWARD) == LOG_OAK) {
        agent.destroy(FORWARD)
        agent.collectAll()
    }
}
player.onChat("q37r03", function () {
    let xValues = [-3, 0, 3]
    let yValues = [2, 3, 4]
    for (let x of xValues) {
        for (let y of yValues) {
            check_q37r03_1(x, y, 4)
        }
    }
})
```
