## C05 Q24 R01 広い橋の床

**C05 Q24 R01 広い橋の床**

Builderで荷車の橋の床を作ろう。

完成するもの: 荷車が渡れる幅の広い橋

学ぶこと: Builder（見えない建築カーソル）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q24r01 に変えよう。

2. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。オークの板で pos(-3, 0, 8) から pos(3, 0, 16) まで作ろう。

3. 緑の実行ボタンを押して、Tキーのチャットで q24r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q24r01", function () {
    builder.teleportTo(pos(-3, 0, 8))
    builder.mark()
    builder.teleportTo(pos(3, 0, 16))
    builder.fill(PLANKS_OAK)
})

```
