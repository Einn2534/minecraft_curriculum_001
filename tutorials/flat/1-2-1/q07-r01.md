## C02 Q07 R01 小さな鐘

**C02 Q07 R01 小さな鐘**

台の上に音符ブロックを置いて鐘を作ろう。

完成するもの: 音符ブロックが並ぶ鐘楼とチャットで鳴る旋律

学ぶこと: 順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q07r01 に変えよう。

2. 石レンガで pos(-2, 0, 12) から pos(2, 0, 12) まで作ろう。

3. 音符ブロックで pos(0, 1, 12) から pos(0, 1, 12) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q07r01 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q07r01", function () {
    blocks.fill(STONE_BRICKS, pos(-2, 0, 12), pos(2, 0, 12), FillOperation.Replace)
    blocks.fill(NOTE_BLOCK, pos(0, 1, 12), pos(0, 1, 12), FillOperation.Replace)
})

```
