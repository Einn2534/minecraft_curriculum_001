## C09 Q41 R01 穴を見つける

**C09 Q41 R01 穴を見つける**

丸石がないところを調べて直そう。

完成するもの: 穴のない石畳

学ぶこと: 条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q41r01 に変えよう。

2. まず位置を1つずつ決め、同じ操作を順につなごう。調べる位置を決めよう。「丸石がないなら置く」をくり返そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q41r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q41r01", function () {
    if (!blocks.testForBlock(COBBLESTONE, pos(-1, 0 - 1, 3 + 9))) {
        blocks.place(COBBLESTONE, pos(-1, 0 - 1, 3 + 9))
    }
    if (!blocks.testForBlock(COBBLESTONE, pos(0, 0 - 1, 3 + 9))) {
        blocks.place(COBBLESTONE, pos(0, 0 - 1, 3 + 9))
    }
    if (!blocks.testForBlock(COBBLESTONE, pos(1, 0 - 1, 3 + 9))) {
        blocks.place(COBBLESTONE, pos(1, 0 - 1, 3 + 9))
    }
})

```
