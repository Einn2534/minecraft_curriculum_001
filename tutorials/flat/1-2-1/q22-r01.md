## C05 Q22 R01 1つの在庫

**C05 Q22 R01 1つの在庫**

Agentの1番の持ち物を数え、金の棒にして表示しよう。

完成するもの: 荷物の数に合わせて積む港の荷役台

学ぶこと: 変数（数を入れる箱）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q22r01 に変えよう。

2. スロットの持ち物の数を調べ、totalに足して合計しよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q22r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q22r01", function () {
    let total = agent.getItemCount(1)
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
})
```
