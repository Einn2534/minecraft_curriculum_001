## C08 Q40 R02 柱と屋根

**C08 Q40 R02 柱と屋根**

4本の柱と屋根を関数で組み立てよう。

完成するもの: 床・柱・屋根を組み立てる設計機

学ぶこと: 関数（まとめた手順）と引数、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q40r02 に変えよう。

2. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(-3, 1, 10) から pos(-3, 3, 10) まで作ろう。

3. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(3, 1, 10) から pos(3, 3, 10) まで作ろう。

4. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(-3, 1, 15) から pos(-3, 3, 15) まで作ろう。

5. 同じ手順を「draw」の関数にまとめ、材料と両端の位置を引数に渡そう。オークの原木で pos(3, 1, 15) から pos(3, 3, 15) まで作ろう。

6. Builderを1つ目の位置へ→マーク→2つ目の位置へ→塗りつぶす。赤い羊毛で pos(-3, 4, 10) から pos(3, 4, 15) まで作ろう。

7. 緑の実行ボタンを押して、Tキーのチャットで q40r02 と入力しよう。

8. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function draw_q40r02(material: number, x1: number, y1: number, z1: number, x2: number, y2: number, z2: number) {
    blocks.fill(material, pos(x1, y1, z1), pos(x2, y2, z2), FillOperation.Replace)
}
player.onChat("q40r02", function () {
    draw_q40r02(LOG_OAK, -3, 1, 10, -3, 3, 10)
    draw_q40r02(LOG_OAK, 3, 1, 10, 3, 3, 10)
    draw_q40r02(LOG_OAK, -3, 1, 15, -3, 3, 15)
    draw_q40r02(LOG_OAK, 3, 1, 15, 3, 3, 15)
    builder.teleportTo(pos(-3, 4, 10))
    builder.mark()
    builder.teleportTo(pos(3, 4, 15))
    builder.fill(RED_WOOL)
})
```
