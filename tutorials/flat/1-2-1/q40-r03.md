## C08 Q40 R03 窓と飾り

**C08 Q40 R03 窓と飾り**

左右の窓と看板の部品を関数で付けて完成させよう。

完成するもの: 床・柱・屋根を組み立てる設計機

学ぶこと: 関数（まとめた手順）、手順を部品に分ける

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q40r03 に変えよう。

2. 手順を1つの関数にまとめ、チャットコマンドから呼び出そう。位置を1ずつ増やすくり返しを作ろう。ガラスで pos(-3, 1, 12) から pos(-3, 2, 14) まで作ろう。

3. 手順を1つの関数にまとめ、チャットコマンドから呼び出そう。位置を1ずつ増やすくり返しを作ろう。ガラスで pos(3, 1, 12) から pos(3, 2, 14) まで作ろう。

4. 手順を1つの関数にまとめ、チャットコマンドから呼び出そう。位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(-1, 3, 10) から pos(1, 3, 10) まで作ろう。

5. 緑の実行ボタンを押して、Tキーのチャットで q40r03 と入力しよう。

6. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function pattern_q40r03_1() {
    for (let y = 0; y <= 1; y++) {
        for (let z = 0; z <= 2; z++) {
            blocks.place(GLASS, pos(-3, (y + 2) - 1, (z + 3) + 9))
        }
    }
}
function pattern_q40r03_2() {
    for (let y = 0; y <= 1; y++) {
        for (let z = 0; z <= 2; z++) {
            blocks.place(GLASS, pos(3, (y + 2) - 1, (z + 3) + 9))
        }
    }
}
function pattern_q40r03_3() {
    for (let x = 0; x <= 2; x++) {
        blocks.place(GOLD_BLOCK, pos((x + -1), 4 - 1, 1 + 9))
    }
}
player.onChat("q40r03", function () {
    pattern_q40r03_1()
    pattern_q40r03_2()
    pattern_q40r03_3()
})
```
