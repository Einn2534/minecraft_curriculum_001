## C07 Q33 R01 かけ算で計算

**C07 Q33 R01 かけ算で計算**

単価2・個数2の代金を金の棒グラフで表示しよう。

完成するもの: 値段と個数を計算して表示する商人の会計台

学ぶこと: 変数（数を入れる箱）、かけ算

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q33r01 に変えよう。

2. 数を変数に保存し、足し算かかけ算で合計を計算しよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q33r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q33r01", function () {
    let price = 2
    let quantity = 2
    let total = price * quantity
    for (let item = 0; item < total; item++) {
        blocks.place(GOLD_BLOCK, pos(-4 + item, 0, 12))
    }
})

```
