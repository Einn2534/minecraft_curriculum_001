## C12 Q60 R03 牧場の巡回を完成

**C12 Q60 R03 牧場の巡回を完成**

3か所を関数で回り、置き忘れがないか確認しよう。

完成するもの: 在庫を調べてえさ置き場へ補充する牧場の巡回

学ぶこと: 配列（順番のあるリスト）、関数（まとめた手順）と引数、条件（もし〜なら）

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q60r03 に変えよう。

2. 1か所に届ける手順をdeliverの関数にまとめよう。配達先リストをくり返し読み、x・y・zを引数に渡そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q60r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
function deliver_q60r03(x: number, y: number, z: number) {
    agent.teleport(pos(x, y, z + 9), SOUTH)
    if (agent.getItemCount(1) > 0) {
        agent.setSlot(1)
        agent.place(DOWN)
    }
}
player.onChat("q60r03", function () {
    let destinations = [[-4, 2, 3], [0, 2, 6], [4, 2, 3]]
    for (let destination of destinations) {
        deliver_q60r03(destination[0], destination[1], destination[2])
    }
})
```
