## C12 Q60 R01 1か所に補充

**C12 Q60 R01 1か所に補充**

在庫があるとき、Agentを動かしてえさ置き場へ干し草を届けよう。

完成するもの: 在庫を調べてえさ置き場へ補充する牧場の巡回

学ぶこと: 変数（数を入れる箱）、条件（もし〜なら）、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q60r01 に変えよう。

2. 1か所の位置を指定してAgentを呼ぼう。在庫があるときだけ下に干し草を置こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q60r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q60r01", function () {
        agent.teleport(pos(-4, 2, 3 + 9), SOUTH)
        if (agent.getItemCount(1) > 0) {
            agent.setSlot(1)
            agent.place(DOWN)
        }
})
```
