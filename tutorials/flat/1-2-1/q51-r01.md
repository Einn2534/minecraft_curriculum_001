## C11 Q51 R01 長方形の区画

**C11 Q51 R01 長方形の区画**

幅3・長さ3の区画を変数で作ろう。

完成するもの: 面積を計算して区画を作る畑

学ぶこと: 変数（数を入れる箱）、二重のくり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q51r01 に変えよう。

2. 幅widthと長さlengthを変数に入れ、その数だけ横と奥の2つのくり返しで土を置こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q51r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q51r01", function () {
    let width = 3
    let length = 3
    let startX = -3
    let startZ = 2
    for (let row = 0; row < length; row++) {
        for (let column = 0; column < width; column++) {
            blocks.place(DIRT, pos(startX + column, -1, startZ + row + 9))
        }
    }
})

```
