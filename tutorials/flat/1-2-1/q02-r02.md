## C01 Q02 R02 金の十字

**C01 Q02 R02 金の十字**

ふちの中に金の十字を入れよう。

完成するもの: 玉座へ続く左右対称の床の紋章

学ぶこと: くり返し、対称な形

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q02r02 に変えよう。

2. 位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(-2, 0, 12) から pos(2, 0, 12) まで作ろう。

3. 位置を1ずつ増やすくり返しを作ろう。金ブロックで pos(0, 0, 10) から pos(0, 0, 14) まで作ろう。

4. 緑の実行ボタンを押して、Tキーのチャットで q02r02 と入力しよう。

5. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q02r02", function () {
    for (let x = 0; x <= 4; x++) {
        blocks.place(GOLD_BLOCK, pos((x + -2), 1 - 1, 3 + 9))
    }
    for (let z = 0; z <= 4; z++) {
        blocks.place(GOLD_BLOCK, pos(0, 1 - 1, (z + 1) + 9))
    }
})

```
