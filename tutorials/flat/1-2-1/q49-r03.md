## C10 Q49 R03 3区間の郵便の経路

**C10 Q49 R03 3区間の郵便の経路**

Agentを曲がり角に沿って金のゴールへ動かそう。

完成するもの: 郵便の経路の道とゴール

学ぶこと: 配列（順番のあるリスト）、座標を足す

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q49r03 に変えよう。

2. 最初の位置にAgentを呼び、各区間の向きと歩数を決めて進もう。各区間をリストにして順に読もう。

3. 緑の実行ボタンを押して、Tキーのチャットで q49r03 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q49r03", function () {
    agent.teleport(pos(-6, 0, 9), SOUTH)
    let legs = [[0, 5], [12, 0], [0, 3]]
    for (let leg of legs) {
        let direction = SOUTH
        if (leg[0] > 0) {
            direction = EAST
        } else if (leg[0] < 0) {
            direction = WEST
        } else if (leg[1] < 0) {
            direction = NORTH
        }
        agent.teleport(agent.getPosition(), direction)
        agent.move(FORWARD, Math.abs(leg[0]) + Math.abs(leg[1]))
    }
})

```
