## C06 Q26 R02 列を点検する

**C06 Q26 R02 列を点検する**

石レンガがないところを調べて直そう。

完成するもの: 穴と弱い部分を直した城壁

学ぶこと: 条件（もし〜なら）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q26r02 に変えよう。

2. 調べる位置をリストに入れよう。「石レンガがないなら置く」をくり返そう。

3. 緑の実行ボタンを押して、Tキーのチャットで q26r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q26r02", function () {
    let points = [[-2, 1, 3], [-2, 2, 3], [-1, 1, 3], [-1, 2, 3], [0, 1, 3], [0, 2, 3], [1, 1, 3], [1, 2, 3], [2, 1, 3], [2, 2, 3]]
    for (let point of points) {
        if (!blocks.testForBlock(STONE_BRICKS, pos(point[0], point[1] - 1, point[2] + 9))) {
            blocks.place(STONE_BRICKS, pos(point[0], point[1] - 1, point[2] + 9))
        }
    }
})

```
