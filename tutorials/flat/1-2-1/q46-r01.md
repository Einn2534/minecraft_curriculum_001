## C10 Q46 R01 1軒へ配達

**C10 Q46 R01 1軒へ配達**

Agentを動かし、1つ目の配達台にケーキを届けよう。

完成するもの: パン屋から3つの配達先へ運ぶ配達路

学ぶこと: 座標、順番に動かす

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q46r01 に変えよう。

2. 1か所の位置を指定してAgentを呼ぼう。ケーキを配達台へ置こう。

3. 緑の実行ボタンを押して、Tキーのチャットで q46r01 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q46r01", function () {
        agent.teleport(pos(-4, 2, 3 + 9), SOUTH)
        blocks.place(CAKE, pos(-4, 2 - 1, 3 + 9))
})

```
