## C11 Q52 R02 小麦を植える

**C11 Q52 R02 小麦を植える**

耕した土へ小麦の苗を植えよう。

完成するもの: Agentが耕して種を植える畑

学ぶこと: 条件（もし〜なら）、くり返し

「はじめる」を押したら、入口の金の床に立って作ろう。コードの位置は、そこに立った自分が基準だよ。

1. 「チャットコマンド」のrunを q52r02 に変えよう。

2. 土の位置をリストにして、Agentで下の土を耕そう。耕した土かを確かめてから苗を植えよう。

3. 緑の実行ボタンを押して、Tキーのチャットで q52r02 と入力しよう。

4. 工房NPCを右クリックし、このRの「完成した・判定」を押そう。

R01→R02→R03で同じテーマを練習するよ。制作課題では、前のRの完成部分を用意するよ。移動や調査では、そのRの練習場を用意するよ。

ヒントは電球を押してみよう。

```blocks
player.onChat("q52r02", function () {
    let points = [[-2, 0, 2], [-2, 0, 3], [-2, 0, 4], [-2, 0, 5]]
    for (let point of points) {
        agent.teleport(pos(point[0], point[1], point[2] + 9), SOUTH)
        agent.till(DOWN)
        if (blocks.testForBlock(FARMLAND, pos(point[0], -1, point[2] + 9))) {
            blocks.place(CROPS, pos(point[0], 0, point[2] + 9))
        }
    }
})

```
